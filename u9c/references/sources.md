## 6. 已知存疑点（不要采信）

| # | 存疑内容 | 两套说法 | 结论 |
|---|---|---|---|
| 1 | **U9 物理表前缀** | `CBO_` / `SM_` / `PM_` / `InvTrans_`（与 UBF 实体命名空间对应） vs `T_BAS_` / `T_SO_` | **均未经权威验证，部分来源标注 AI 生成。在拿到元数据库之前不要采信任何一套** |
| 2 | **扩展表命名** | 默认带 `_EXT` 后缀 / 按扩展包命名 | `【待核实】` |
| 3 | **扩展字段元数据 XML 格式** | 示意 `<Field Name=... TransferFlag="true" />` | `【待核实】`，非官方 schema，仅作格式示意 |
| 4 | **UI 插件细节**（`Extension.xml` 结构、扩展点、CHelper/CommonFunction） | 单一 CSDN 来源 | `【待核实】`，该来源标注 AI 生成，**以官方 Extension Schema 文档为准** |
| 5 | **公网"U9 二次开发全解析/实战指南"类长文** | 编造出 `U9.Platform.Plugin.IBusinessPlugin`、`PluginEventType.BeforeSave`、`U9Exception`、`U9.Common.LogHelper`、`U9\WebSite\bin\Plugin`、`BusinessService.svc`、"基于 **BEAS** 开发平台" | **判定为 AI 生成的幻觉**（`BEAS` 不是 U9 的平台，U9 是 UBF/UAP；命名空间应为 `UFSoft.UBF.*` / `UFIDA.U9.*`）。**完整对照表见 [6.1](#61-ai-幻觉-api-对照表)** |
| 6 | **插件日志类**（`U9.Common.LogHelper.LogInfo`） | 与上条同源，疑为幻觉 | **未验证，不要照抄**。正确类名待查《U9研发体系（数据库访问API参考手册）》（见 5.2 节） |
| 7 | **UI 插件的 `CHelper` / `CommonFunction` 具体 API** | 单一 CSDN 来源，且该来源标注 AI 生成 | 保留但**整体标 `【待核实】`**，以官方 Extension Schema 文档为准 |

### 6.1 AI 幻觉 API 对照表

**本知识库判断**（基于多源交叉验证）

搜索 U9 插件开发时，会命中大量 2026 年发布的"全解析""实战指南"长文。**其中一部分是 AI 生成的，API 体系是编造的**。识别方法：

| 特征 | 幻觉写法（❌ 假） | 真实写法（✅ 真） |
|---|---|---|
| **命名空间根** | `U9.Platform.*`、`U9.BO`、`U9.Common`、`U9.DB` | **`UFSoft.UBF.*`**、**`UFIDA.U9.*`** |
| **平台名** | "基于 **BEAS** 开发平台" | **UBF**（UAP Business Framework） |
| 插件接口 | `IBusinessPlugin` + `PluginContext` + `PluginDescriptor` | `EntityEvent` + `EntityKey` + `*.sub.xml` 订阅 |
| 事件枚举 | `PluginEventType.BeforeSave` / `AfterAudit` | `sub.xml` 里的事件名（如 `Updating`），**由 UBF Studio 向导列出** |
| 异常类型 | `U9Exception` | 未验证（**不要照抄**） |
| 日志类 | `U9.Common.LogHelper.LogInfo` | 未验证（**不要照抄**） |
| 部署路径 | `U9\WebSite\bin\Plugin` + "插件管理"注册 | `Portal\...` 目录 + **补丁包**（见 `references/environment.md` 第 7 章） |
| 对外服务 | `BusinessService.svc` + `LoginInfo` | **ISV 代理** `*ISVProxy`；轻量服务 `RestServices/*.svc` |

> **一句话判据**：**看命名空间**。真实 U9 客开代码的命名空间只可能是 `UFSoft.UBF.*` 或 `UFIDA.U9.*`。出现 `U9.Platform`、`U9.BO`、`U9.Common`、`BEAS` 的，**直接丢弃**。
