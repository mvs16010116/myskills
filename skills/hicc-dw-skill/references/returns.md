# 退货域

## 模块结构

| 目录 | 层级 | 说明 |
|------|------|------|
| 退货dwd | DWD | 退货明细层 |
| 退货dws | DWS | 退货汇总层 |

## 执行顺序

```
销售dws → 退货dwd → 退货dws
```

退货域依赖销售域先执行完成。

## 关键特性

- **退货金额修正**: 修正了退货金额的计算逻辑（`fix` 提交，2026-07-02）
- **退货日期修正**: 修正了退货日期的计算逻辑
- **Walmart 维度**: 为 Walmart 订单表添加维度字段，修正聚合逻辑
- **多店铺**: 支持 Walmart 多店铺退货数据

## 退货指标

退货数据需要与销售数据结合使用，计算净销售额和退货率：

```
净销售额 = 销售额 - 退货额
退货率 = 退货额 / 销售额
```
