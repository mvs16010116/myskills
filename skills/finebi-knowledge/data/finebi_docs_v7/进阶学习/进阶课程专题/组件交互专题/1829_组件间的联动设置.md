### 1.1 应用场景
制作完若干组件后，我们希望能通过通过组件之间的联动，筛选出所需要的信息。 FineBI 支持自由控制联动范围。
例如，点击饼图的不同类别的产品，即可筛选出对应的销售情况。然而，点击指标卡、地图等组件并不产生联动效果。如下图所示：
![2022-04-28_15-28-52.gif](https://help.fanruan.com/core/style/lod.png)
### 1.2 实现思路
1）上传「办公用品数据」表；
2）使用数据表制作分析产品销售额的多个组件（饼图、指标卡、地图、分组表）；
3）查看组件之间的默认联动效果；
4）设置每个组件的联动的范围。

## 3\. 联动设置
### 3.1 默认联动
1）默认联动的产生  

默认联动条件：当多个组件使用的数据表是同一张数据表，或者使用的数据表之间有关联关系。那么这多个组件之间有系统默认设置的联动。
例如，点击地图的「新疆」省，其他组件即可过滤出新建的对应数据。如下图所示：  

**更详细的功能介绍请参见文档：**[**组件设置联动**](<https://help.fanruan.com/finebi7.0/doc-view-150.html>)
![45.png](https://help.fanruan.com/core/style/lod.png)
### 3.2 手动设置联动
FineBI 中，联动是可以自己手动控制匹配的。例如默认联动的效果不是我们想要的，或者组件之间不能自动产生联动（没有使用同一张表，且表之间没有关联关系），这时候我们就需要手动设置联动。
**更详细的功能介绍请参见** ：[手动设置联动](<https://help.fanruan.com/finebi7.0/doc-view-150.html#5>)
例如我只希望点击「饼图」时会产生联动，那么取消指标卡、地图等其他组件的联动效果即可。
在仪表板编辑界面，点击地图组件，下拉点击「联动设置」。取消地图对其他组件的联动，如下图所示：
![47.png](https://help.fanruan.com/core/style/lod.png)
![48.png](https://help.fanruan.com/core/style/lod.png)
此外，销售额指标卡、利润指标卡、数量指标卡、分组表都重复如上操作步骤，即可清除除「饼图」外的其他的组件联动。
效果预览参见本文 1.1 节。 
### 3.3 清除联动&取消联动
A：取消勾选「开启默认联动」，可以将系统默认产生的联动清除，只留下用户手动设置的联动。
B：点击清除所有联动，即可清除当前仪表板的所有联动效果。
C：清除当前组件产生的联动效果。
