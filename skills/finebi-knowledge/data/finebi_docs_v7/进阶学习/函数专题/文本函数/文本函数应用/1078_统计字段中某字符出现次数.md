## 1\. 概述
  

  * 在线预览：[统计字段中某字符出现次数](<https://pcdemo.finebi.com/webroot/decision/v5/conf/subject/page/edit/bf8c41703ace4a2aaf16707aded4e0a7/report/3f72410713ad40c79f9f20635c175a82>)
  * 用户可点击「另存为主题」，自己操作一遍或查看内部编辑步骤。


### 1.1 预期效果
统计同一字符在字段中的出现次数。例如统计「账号」字段中的“/”出现次数。如下图所示：
![效果预览.png](https://help.fanruan.com/core/style/lod.png)
### 1.2 实现思路
1）新建分析主题，上传数据。
2）然后在新增列中添加公式，组合使用 [SUBSTITUTE](<https://help.fanruan.com/finebi7.0/doc-view-1458.html>) 函数或 [REPLACE](<https://help.fanruan.com/finebi7.0/doc-view-1469.html>) 函数和 [LEN](<https://help.fanruan.com/finebi7.0/doc-view-1472.html>) 函数的嵌套公式实现效果，本文以 [SUBSTITUTE](<https://help.fanruan.com/finebi7.0/doc-view-1458.html>) 函数和 [LEN](<https://help.fanruan.com/finebi7.0/doc-view-1472.html>) 函数的嵌套公式为例。
3）保存并更新数据即可查看效果。
## 2\. 操作步骤
示例使用数据：[统计相同字符个数.rar](<doc-download-/uploads/file/20200930/统计相同字符个数.rar> "下载资料")
### 2.1上传数据
1）在「我的分析」中点击「新建分析主题」，上传下载的示例数据，如下图所示：
![上传数据表888.png](https://help.fanruan.com/core/style/lod.png)
2）上传「用户权限表」后，选择「sheet2」，根据需要修改字段类型，示例中修改「密码」字段类型为「文本」，点击「确定」，完成上传。如下图所示：
![修改字段格式000.png](https://help.fanruan.com/core/style/lod.png)
### 2.2 选字段
默认选择所有字段，新建分析主题重命名为「统计相同字符」，如下图所示：
![修改主题名.png](https://help.fanruan.com/core/style/lod.png)
### 2.3 新增列
1）添加「新增公式列」，如下图所示：
![新增公式列.png](https://help.fanruan.com/core/style/lod.png)
2）新增列对「账号」字段中的「/」统计个数。输入公式：LEN(账号)-LEN(SUBSTITUTE(账号,"/",""))，其中「账号」字段需点击左侧文本字段添加才有效。完成点击「确定」。如下图所示：
![公式.png](https://help.fanruan.com/core/style/lod.png)
公式说明如下表所示：
公式  
| 说明| 函数  
---|---|---  
LEN(账号)| 统计「账号」字段的字符串长度。| [LEN](<https://help.fanruan.com/finebi7.0/doc-view-1472.html>)(args)：返回文本串中的字符数或者数组的长度。  
SUBSTITUTE(账号,"/","")| 将「账号」字段中的「/」替换成空值，达到去除「/」的效果。| [SUBSTITUTE](<https://help.fanruan.com/finebi7.0/doc-view-1458.html>)(text,old_text,new_text,instance_num)：用 new_text 替换文本串中的 old_text 。  
LEN(SUBSTITUTE(账号,"/",""))| 去除了「/」的「账号」字段字符串长度。| -  
LEN(账号)-LEN(SUBSTITUTE(账号,"/",""))| 「账号」字段的长度减去去除了「/」的「账号」字段长度，得出「/」的个数。| -  
3）新增「统计"/"个数」列后，点击「保存并更新」，保存并更新创建的分析主题。如下图所示：
![保存并更新.png](https://help.fanruan.com/core/style/lod.png)
