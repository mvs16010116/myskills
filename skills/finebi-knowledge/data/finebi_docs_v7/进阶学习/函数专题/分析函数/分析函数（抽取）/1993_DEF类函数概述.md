## 概述
DEF 函数帮助用户修改或控制计算的详细级别，明确指标计算的粒度。

## 函数列表
函数| 说明  
---|---  
[DEF](<https://help.fanruan.com/finebi7.0/doc-view-1986.html>)| 只有函数里的维度  
  
[DEF_ADD](<https://help.fanruan.com/finebi7.0/doc-view-1987.html>)| 分析区域的维度 + 函数的维度基于分析区域中维度以及 [DEF_ADD](<https://help.fanruan.com/finebi7.0/doc-view-1987.html>) 函数中指定维度执行运算例如，求不同门店销售额平均值的情况，维度使用省份、城市进行分析。使用 DEF_ADD 求出不同门店销售额平均值，然后拖入需要分析的维度，对门店的销售额平均值进行分析  
[DEF_SUB](<https://help.fanruan.com/finebi7.0/doc-view-1990.html>)| 分析区域的维度 - 函数的维度忽略 [DEF_SUB](<https://help.fanruan.com/finebi7.0/doc-view-1990.html>) 函数中指定的维度，基于分析区域的维度进行计算例如，查看每年已交货的订单销售额平均值，而不考虑每个订单的销售额，即使是按订单进行分组显示的。  
[EARLIER](<https://help.fanruan.com/finebi7.0/doc-view-1991.html>)| 使用在 DEF 类分析函数中，作为参数使用，用于行间过滤计算
