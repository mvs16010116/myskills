## 1\. 概述
### 1.1 预期效果
将「地区」、「客户经理」、「区域经理」三个字段用 「/」进行拼接，如果拼接字段为空，则不需要分隔符，效果如下图所示：
**![](https://help.fanruan.com/core/style/lod.png)**  

### 1.2 实现思路
使用 [CONCATENATE](<https://help.fanruan.com/finebi7.0/doc-view-1470.html>) 函数进行拼接；
嵌套 [](<https://help.fanruan.com/finebi7.0/doc-view-3.html#3>)[IF](<https://help.fanruan.com/finebi7.0/doc-view-1377.html>) 函数增加「/」进行拼接分割。
## 2\. 操作步骤
示例数据：[拼接.xlsx](<doc-download-/finebi5.1/uploads/file/20201201/拼接.xlsx> "下载资料")
### 2.1 新建分析主题
新建分析主题，上传下载的示例数据「拼接」，默认勾选所有字段，如下图所示：
![](https://help.fanruan.com/core/style/lod.png)
### 2.2 拼接字段
新增「新增公式列」步骤，命名为「拼接」并输入公式：CONCATENATE(地区,IF (ISNULL(区域经理),"","/"),区域经理,IF(ISNULL(客户经理),"","/"),客户经理)，点击「确定」，如下图所示：
![](https://help.fanruan.com/core/style/lod.png)
保存并更新数据。
公式说明：
公式  
| 说明  
---|---  
IF (ISNULL(区域经理),"","/")| 如果区域经理字段为空，则输出空值，否则输出分隔符/  
IF(ISNULL(客户经理),"","/")| 如果客户经理字段为空，则输出空值，否则输出分隔符/  
CONCATENATE(地区,IF (ISNULL(区域经理),"","/"),区域经理,IF(ISNULL(客户经理),"","/"),客户经理)| 拼接地区 空值或者/ 区域经理 空值或者/ 客户经理  
### 2.3 效果查看
详情参见本文 1.1 节。
