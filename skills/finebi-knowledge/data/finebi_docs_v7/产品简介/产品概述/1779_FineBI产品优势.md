## 1\. 概述
FineBI 是新一代大数据分析的 BI 工具，旨在帮助企业的业务人员充分了解和利用企业自身的数据。FineBI 凭借强劲的大数据引擎，用户只需简单拖拽便能制作出丰富多样的数据可视化信息，自由地对数据进行分析和探索，让数据释放出更多未知潜能。
## 2\. 企业为什么需要 FineBI
### 2.1 企业数据化建设的背景与痛点
随着市场竞争愈发激烈，企业数字化建设经历了多阶段演进：从早期 “搭建业务系统，让业务从手工化转向数字化运转”，到中期 “整合多系统数据，看清业务整体面貌”，再到如今 “要求数据深度融入业务分析，直接推动业务改善”。
![](https://help.fanruan.com/core/style/lod.png)
但现在的数字化模式下，多角色面临明显痛点：
  * 战略 / 经营层：当业务出现问题时，数据零散难获取，数据口径不统一，决策缺乏精准依据。
  * IT 层：做了很多数据梳理工作，但业务实际使用率很低，指标和口径频繁调整。  

  * 业务层：做大量的数据分析工作，且看不懂指标计算逻辑，部门间口径未对齐，汇报时各执一词。


![](https://help.fanruan.com/core/style/lod.png)
这些痛点最终导致 “业务循环” 与 “管理循环” 相互脱节（即 “双轮空转”）：战略难以拆解到业务执行中，业务也无法真正支撑战略落地，进而让企业决策缺乏可靠依据。
### 2.2 FineBI 如何解决企业痛点
FineBI 作为指标驱动的数据智能分析平台，能针对多角色痛点提供解决方案，助力企业数据与业务、管理高效联动。
#### 2.2.1 面向战略层
  * **指标定义全局管控** ：统一定义指标口径，避免 “同名不同义”“同义不同名” 问题，实现 “一次定义，处处引用”，构建企业级指标管理体系；
  * **明确业务 owner** ：由业务部门自主管理指标、解释与报表，指标定义 “业务说了算”，保障指标体系贴合业务发展需求；
  * **指标树归因、分析、预警** ：支持指标监测与反馈机制，既能基于指标血缘关系分析，也能从相关维度展开分析，还可对异常指标主动预警。


#### 2.2.2 面向IT层
  * 不再建设新宽表，统一数据取用：一次定义指标后，各类数据应用（FineReport、FineBI、FVS、chatBI）可直接选用指标数据，无需重复加工大量宽表，既能确保数据一致性，还能对外提供数据服务。
  * 数据血缘追溯：能帮助用户快速理清数据在整个数据链路中的流转情况（包括数据来源、引用逻辑、影响场景），保障数据分析师思路透明，提升业务协同效率。
  * 充分释放历史生产数据：指标字典等内容向业务人员开放，业务人员可在看板直接查看相关指标的定义、计算逻辑等信息，快速理解数据口径，方便上手使用。


#### 2.2.3 面向业务层
  * **自助取数** ：业务人员能借助产品功能，快速查找业务所需数据，完成简单的数据汇总、查询，还能把数据分享或导出到线下。
  * **敏捷开发** ：分析人员可根据业务诉求，从核心经营内容入手，快速搭建分析看板来敏捷分析业务，且能随业务变化快速调整分析内容。
  * **探索分析** ：从数据可视化向业务分析深入，让业务分析思路线上化，把业务分析、问题定位的思路融入 AI 看板中。
  * **智能问数** ：业务人员通过问答形式就能快速检索数据、获取结果，满足日常数据查询 / 检索需求，未来还能进一步支持问答分析类诉求。

## 3\. FineBI 核心场景
### 3.1 一站式数据分析和处理平台
大数据时代下，企业数据分散沉淀于 ERP、OA、MES 等各类业务系统及外部渠道，难以有效提取与整合，制约了数据价值的挖掘。
FineBI 作为一站式平台，从源头打通数据链路：先提取多源数据，经 ETL 处理、数据清洗等环节后汇入企业级数据仓库，形成全局数据视图；再将数据转化为管理驾驶舱、复杂报表、自助分析、多维分析等可视化应用，为企业管理者与运营人员提供决策支撑，助力企业真正将数据转化为经营能力。
![](https://help.fanruan.com/core/style/lod.png)
### 3.2 赋能业务人员，灵活定义 IT 与业务协同模式
从实际应用来看，财务、营销等数据分析需求旺盛的部门已普遍采用 “自助分析” 模式，而生产制造等需求较少的部门仍以 IT 主导为主。
FineBI 以低门槛特性赋能不同能力的业务人员：入门级可快速完成数据获取与图表可视化，中级可实现数据处理与多维分析，高级可开展高阶计算与复杂分析；同时支持协作功能，用户可随时邀请他人共同解决分析卡点。基于此，企业可根据业务人员的需求与能力，灵活搭建高效的 IT 与业务协同体系。
![](https://help.fanruan.com/core/style/lod.png)
### 3.3 辅助制定经营策略，实现目标拆解与闭环执行
经营分析是企业高效运营的核心管理手段，其对业务现状反馈、问题定位及决策支撑的价值随企业规模扩大愈发凸显。
FineBI 通过管理驾驶舱、专题分析报告、自定义指标看板等工具，实现战略监测、经营监控、业务执行跟踪的全流程覆盖；并通过 “明确方向 — 发现问题 — 分析根源 — 落实整改 — 预警回顾” 的闭环机制，将战略目标层层拆解落地，持续提升企业数据化管理水平。
### 3.4 洞察业务波动，快速定位问题并响应解决
区别于常规的数据查询，探索性分析以 “问题导向” 开展假设 - 验证流程，助力企业挖掘业务规律与商机。
FineBI 满足业务部门快速取数、敏捷分析及报表开发需求，支持通过指标拆解诊断现状、同环比分析识别目标差距；再借助多维联动、可视化图表等工具反复验证假设，精准定位核心问题与关键影响因素，最终输出针对性解决方案并跟踪执行效果，形成业务问题的快速响应闭环。
![](https://help.fanruan.com/core/style/lod.png)
![](https://help.fanruan.com/core/style/lod.png)
### 3.5 助力 IT 团队，构建可复用的指标血缘数据底座
企业数据分析需求的复杂性，导致 IT 团队常面临系统维护成本高、指标口径不统一、复用难度大等问题 —— 传统模式下业务指标与应用层割裂，各报表需重复计算，既影响数据一致性，又增加运维负担。
FineBI V7.0 通过 “统一指标定义、一次配置全域复用” 的机制，无需反复开发宽表，且支持从基础数据表到最终分析结果的全链路指标血缘追溯；同时开放指标字典给业务人员，降低沟通成本，大幅减轻 IT 团队的维护与迭代压力，构建高效可复用的数据消费底座。
## 4\. FineBI 核心能力
### 4.1 广泛的数据源对接能力
FineBI 具备广泛且高效的数据源对接能力，具体表现为：
  * 数据源类型丰富：支持关系型数据库、大数据平台、接口协议、文本数据、国产化数据库、消息队列、NoSQL 数据库等 7 类数据源；
  * 接口与文本处理灵活：接口数据可可视化获取，支持多种解析方式并勾选所需字段；文本数据支持 FTP/sFTP、本地文件对接，符合筛选条件的多文件可自动合并；
  * 对接场景全面：覆盖 “数据库类系统对接” 与 “平台接口类数据对接”（包含一方、二方、三方数据，适配金蝶、ERP 等众多主流平台）；

### 4.3 统一的企业数据管理能力
帆软具备统一的企业数据管理能力，优势突出：
  * 统一数据口径：在数据层强化权限管控，确保数据口径唯一且清晰；
  * 规范数据架构：打造面向业务分析的数据目录，让数据组织更有序；
  * 支持复用与自动同步：数据指标集可重复引用，若指标逻辑变更，所有引用该指标的报表会自动调整。


这些能力能实现 “-80% 重复数据集、1 分钟找到所需数据”，且100% 前端应用数据从数据目录获取，大幅提升企业数据管理与使用效率。
![](https://help.fanruan.com/core/style/lod.png)
### 4.4 专业的指标管理能力
面向 IT 数据与业务团队提供从指标定义到发布分析的全链路指标管理，通过模型建设实现跨表指标维度定义，助力构建企业指标资产体系并支持后续分析，还能降低 60% 用户上手成本、提升 60% 运维调整效率。具体具备多项核心能力：
  * 媲美数仓的模型管理能力：实现多表多字段的管理与关联；
  * 跨表指标定义能力：数据读写计算性能优秀且稳定，支持并发处理，易于线性扩展；
  * 全链路血缘能力：基于指标，打通从基础数据表到最终分析仪表板的全链路数据血缘，数据关系清晰；
  * 指标权限管理能力：可全局检索指标，按权限隔离指标数据内容，支持权限申请取用；
  * 多场景指标消费能力：完成指标定义发布后，能打通 BI 分析能力做指标预警，还提供指标 API 功能对外提供指标数据。


![](https://help.fanruan.com/core/style/lod.png)
### 4.5 零 SQL 的数据编辑能力
使用类 Excel交互页面，代替 SQL 数据集代码开发方式，逻辑易懂，业务人员即可使用。
![](https://help.fanruan.com/core/style/lod.png)
### 4.6 高易用性的数据分析能力
  * 可视化与交互便捷：通过拖拉拽形式即可快速生成图表。
  * 应用模板服用能力：拥有“即取即用”的数据分析应用平台，用户无需从零搭建，零门槛复用行业标杆模板。  



![](https://help.fanruan.com/core/style/lod.png)
### 4.7 多场景数据消费能力
  * 智能问答：支持用户以自然语言提问快速生成分析图表，结合上下文关联与归因分析动态解读数据，并智能推荐深入问题，大幅降低数据分析门槛。
  * 数据预警：通过预设指标阈值实时监控数据异常，依托多渠道精准推送至动态责任人，并支持预警闭环追踪，提升企业风险响应效率。
  * 数据门户：作为企业统一数据查询入口，聚合报表、指标及动态通知，支持个性化组件配置与多终端适配，提升数据查找与触达效率。
  * 应用封装：将多业务看板集成封装为标准化应用，提供多终端导航模式，支持快速复用与推广，简化跨场景数据分析流程。
