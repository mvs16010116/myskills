### 1.2 应用场景
根据两列数据分层应用于组织代码表中的机构代码有两列，且分别为当前机构号和直接上级机构号。
例如银行机构表，某银行镇江丹徒新区支行的机构代码「JGID」是 7018，它的直接上级机构代码「PARENT_ID」是 711。
说明「镇江环城支行」是「镇江丹徒新区支行」直接上级。
![1.png](https://help.fanruan.com/core/style/lod.png)
通过构建层级关系，可以将各个银行的归类到不同级别，并且理清它们之间的上下级关系，如下图所示：
![5.png](https://help.fanruan.com/core/style/lod.png)
### 1.3 使用范围
  * 适用于有自身 ID 和上级 ID 两列数据的表，若只有一列描述层级关系，可参见 [自循环列-一列分层](<https://help.fanruan.com/finebi7.0/doc-view-1132.html>)
  * 只有 [基础表](<https://help.fanruan.com/finebi7.0/doc-view-43.html>) 有自循环列功能，自助数据集无该功能。
  * 直连属性的表不支持自循环列功能。


## 2\. 示例
### 2.1 导入数据
1）下载示例数据：[银行_机构维度表.xlsx](<doc-download-/finebi/uploads/file/20260325/银行_机构维度表.xlsx> "下载资料")
2）在数据目录中选择一个文件夹，上传刚刚下载的示例 Excel，如下图所示：
![](https://help.fanruan.com/core/style/lod.png)
### 2.2 字段设置
1）使用示例数据「银行-机构维度表」，点击「编辑」，如下图所示：
![](https://help.fanruan.com/core/style/lod.png)
字段说明
JGID| 该银行的ID  
---|---  
PARENT_ID| 该银行直接上级的ID  
2）需要确保构建层级的两个 ID 列全部为文本字段，若不是，需要进行「字段类型转换」，如下图所示：
![](https://help.fanruan.com/core/style/lod.png)
### 2.3 自循环列
1）添加「自循环列」，如下图所示：
![](https://help.fanruan.com/core/style/lod.png)
2）设置自循环列的需要的条件，点击「构建关系」，如下图所示：
**自循环列类型**|  选择「根据两列数据分层」  
---|---  
**分层依据ID列  
**|  选择银行的ID  
**Parent ID列**|  选择父级或上级银行的 ID 列  
**分层结果字段**|  选择银行或机构的名称  
![](https://help.fanruan.com/core/style/lod.png)
3） FineBI 自动构建银行的层级关系，一共有五个层级。分别命名为「总行、一级分行、二级分行、一级支行、二级支行」，如下图所示：
![](https://help.fanruan.com/core/style/lod.png)
在该表进行更新以后就可以在创建自助数据集、新建仪表板中使用自循环列生成的层级字段。
