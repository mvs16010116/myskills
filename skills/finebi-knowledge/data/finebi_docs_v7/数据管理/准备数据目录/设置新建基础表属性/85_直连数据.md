## 1\. 概述
### 1.1 版本
FineBI 版本  
| 功能变动  
---|---  
7.0| -  
### 1.2 应用场景
直连属性的数据集是由 FineBI 直接向数据库请求数据，所以不需要将数据抽取到 FineBI 中，不需要进行更新。
### 1.3 使用直连数据注意事项
  * 不建议在低性能数据库大数据量的情况下使用直连数据，例如 MySQL 超过千万数据。
  * 直连数据集不支持行列转换和自循环列。
  * 不支持来自不同数据库的两张直连数据集之间做融合分析（关联、上下合并、左右合并）。


## 2\. 操作步骤
### 2.1 如何切换直连数据
选择「公共数据」，点击数据列表的下拉按钮，即可切换「直连数据」与「抽取数据」。如下图所示：
![](https://help.fanruan.com/core/style/lod.png)
### 2.2 缓存设置
直连数据集可设置「缓存设置」。
默认情况下， FineBI 每隔 600 秒会清除一次缓存，重新向数据库发一次 SQL 请求最新数据，这就代表 600 秒 FineBI 中才会刷新一次数据。用户可调整刷新一次间隔的时间：详情请参见 [缓存](<https://help.fanruan.com/finebi7.0/doc-view-1674.html>)
![](https://help.fanruan.com/core/style/lod.png)
## 3\. 注意事项
### 3.1 编辑状态下默认查看数据量
编辑状态下查看部分数据，默认查看前1W 条数据，因此会出现使用直连属性的数据集制作的组件，点击「查看所有数据」不生效。
### 3.2 数据库与 BI 数据不同步
有两种情况：
  * 若在数据库对表结构进行更改（进行了列的增减），那么表结构的变化不会立即更新到在数据准备页面。需要对表进行编辑，勾选新添加进来的字段，若有标红的字段则取消勾选。
  * FineBI 有默认缓存设置，每隔 600 秒才会刷新一次数据，可参见本文 2.2 节。
