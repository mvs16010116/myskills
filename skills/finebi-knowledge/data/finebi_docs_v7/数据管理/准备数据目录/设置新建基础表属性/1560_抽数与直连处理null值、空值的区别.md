### 1.2 功能简介
FineBI 的直连与抽取数据集对于 null 值的处理方式不同。  

  * 抽取数据：空和 null 值统一处理为 null。
  * 直连数据：空值与 null 值分开单独处理，和数据库逻辑保持统一。


## 2\. 示例
「文本1」字段中有空值、 null 值、空格值。如下图所示：  

其中对应 id 为 3、13、23、33 的为 null 值，对应 id 为 5、15、25、35 的为空值。
![21.png](https://help.fanruan.com/core/style/lod.png)
### 2.1 直连数据
1）使用直连数据集制作一个明细表，并添加一个文本过滤组件可对「文本1」进行过滤。如下图所示：
![22.png](https://help.fanruan.com/core/style/lod.png)
2）按 F12 进入开发人员模式后，可以看到筛选框下拉后，第一个为 null 值，第二个为 空值，如下图所示：
所以null 值和空值在直连版本中是分开处理的。（其中 2、3 对应的是空格值）
![23.png](https://help.fanruan.com/core/style/lod.png)
3）勾选 null 值，成功筛选出 null 值数据。如下图所示：
![24.png](https://help.fanruan.com/core/style/lod.png)
### 2.2 抽数数据
使用抽取数据集制作同样的组件，使用 F12 查看文本下拉框中的可勾选值，如下图所示：
可以看到没有空值了，只有 null 值和空格值。这是因为空值一起被处理成了 null 值。
![25.png](https://help.fanruan.com/core/style/lod.png)
勾选 null 值，获得的结果如下图所示，可以看出不仅筛选出了 null 值，原数据表中的空值也被筛选出来了。
![26.png](https://help.fanruan.com/core/style/lod.png)
