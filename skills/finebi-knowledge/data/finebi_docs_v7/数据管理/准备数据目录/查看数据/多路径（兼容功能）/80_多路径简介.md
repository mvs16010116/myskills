7.0版本不支持两表配置出多路径，但是保留「多路径设置」功能以便和旧版本兼容。
## 1\. 概述
当数据表较多且表间关联关系设置较多且复杂时，可能会存在从一张表到另一张表之间多路径的情况。
比如如下图所示：从 A 表关联到 C 表，有两条路径。可以通过 A 表与 C 表直接关联；也可以 A 表先关联 B 表，B 表与 C 表关联，从而间接性达成 A 表与 C 表关联。  

![222](https://help.fanruan.com/core/style/lod.png)  

## 2\. 多路径介绍
多路径包含：冗余多路径、错误路径等。  

  * 冗余多路径：多条路径下获取的数值都是一样的，但是有些路径很复杂，有些很简单。比如 A>C 明显比 A>B>C 要更简单。我们在使用的时候为了减轻服务器压力，可以直接选择简单路径进行数据关联。
  * 错误路径：多路径中个别路径获取的数据并不是正常业务逻辑下需要得出的，影响正常数据分析，因此需要设置部分非业务需要的路径不参与分析。


## 3\. 多路径解决方式
多路径对于业务分析来说是需要尽量避免和优化的，下面将会为大家介绍多路径设置的两种方式。  

### 3.1 规范建立数据关联
很多冗余的多路径都是因为用户添加表和建立关联时不规范导致的，需要我们在建立关联时就要规范操作。
具体详情请参见 [设置关联](<https://help.fanruan.com/finebi7.0/doc-view-2452.html>)。
### 3.2 多路径设置界面
在多路径设置界面，FineBI 会将起始表与结束表之间的路径展示出来，提供给用户对进行选择。
具体详情请参见[多路径设置界面](<https://help.fanruan.com/finebi7.0/doc-view-82.html>)。
