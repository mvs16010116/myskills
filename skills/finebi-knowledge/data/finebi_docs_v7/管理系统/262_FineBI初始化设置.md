## 应用场景
FineBI安装成功后，管理员需要登录FineBI，设置超管账号密码等必要信息，完成初始化设置。
## 初始化管理员
### 选择浏览器
推荐使用以下版本的浏览器访问 FineBI ，否则可能导致界面展示异常。
支持的浏览器类型和版本  
---  
推荐使用 Chrome 浏览器最新版本  
支持使用 Chrome、FireFox、Safari、opera 浏览器  
对于360 浏览器、搜狗浏览器、QQ 浏览器、UC 浏览器、猎豹浏览器、百度浏览器等双核心浏览器，只支持其极速模式，不支持兼容模式不支持 IE 浏览器  
  
### 进入FineBI
通过运维平台成功部署的新项目，自动接入运维平台的项目管理列表中，可进行相关运维操作。
其中的访问地址，即为该运维项目的访问地址。点击即可在浏览器新窗口访问该地址，进入工程初始化配置界面。
**地址形如：**<http://ip:port/工程名/decision>
其中 ip 和 端口号是 FineBI 的帆软内网关组件所在的服务器 IP 和端口，工程名默认为webroot
![](https://help.fanruan.com/core/style/lod.png)
### 设置管理员
首次访问FineBI，会进入超管账号密码设置界面。
该管理员为FineBI 系统中的最大权限用户，即超级管理员，负责统筹整个系统，包含用户、数据、权限、系统信息等。
注：建议密码强度和复杂度满足常见安全需求， 以防超管账号被他人盗用。
![](https://help.fanruan.com/core/style/lod.png)
点击「下一步」，再次确认超管账号密码，完成初始化设置。  

注：请牢记您设置的用户名和密码。这里设置的超管密码，原则上不允许修改，无法重置，请千万不要忘记密码！
![](https://help.fanruan.com/core/style/lod.png)
点击「登录」，使用设置好的超管账密登录FineBI系统，即可进行 FineBI相关设置
例如添加用户、添加目录、设置权限等必要操作，详情请参见：[管理员操作指南](<https://help.fanruan.com/finebi7.0/doc-view-777.html>)
![](https://help.fanruan.com/core/style/lod.png)
