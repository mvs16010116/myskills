### 1.2 功能简介
每一家企业都不会只有一个系统，希望每个系统都能够有统一的 UI 规范。
因此在使用FineBI系统时，也希望能够统一风格，比如登录界面、平台系统风格等。
FineBI系统提供了此功能，最大程度的支持用户个性化设置。
管理员登录FineBI系统，选择「管理系统>外观配置」，即可对FineBI的登录页、平台主题、平台样式、目录样式、BI全局样式、报表样式自定义设置。如下图所示：
