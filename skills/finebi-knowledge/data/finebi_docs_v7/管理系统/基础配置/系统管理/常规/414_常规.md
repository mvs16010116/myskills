## 2\. 常规参数
注：部分常规参数仅作用于 FineReport 模板，请根据自身需要进行设置。 
功能| 参数对应工程| 简介  
---|---|---  
Servlet 路径名| FineReport| 修改它将影响到访问 FineReport 模板时 URL 的书写方式，不推荐修改默认为 decision  
周开始于| FineBI| 对于运维平台部署的FineBI，该配置无效。请在运维平台的组件管理中，对引擎相关组件修改配置：[更改项目组件配置](<https://help.fanruan.com/fineops/doc-view-52.html>)
  * 设置周开始于星期一时，系统中周的范围为星期一到星期日
  * 设置周开始于星期日时，系统中周的范围为星期日到星期六

该设置对日期公式有影响，具体如下：
  * 支持的公式有 [WEEK()](<https://help.fanruan.com/finebi7.0/doc-view-1419.html>) 和 [WEEKDATE()](<https://help.fanruan.com/finebi7.0/doc-view-1404.html>)
  * 不影响 [WEEKDAY()](<https://help.fanruan.com/finebi7.0/doc-view-1420.html>) ，返回的是数字周几
  * 不影响 DATEINWEEK() ，默认周起始日期是周一

  
连接网址管理中心| FineBI| 云中心连接开关，FineBI 产品中的各种参考链接由云中心管理，建议开启以便之后相关云端运维功能使用。建议开启  
Gzip 压缩| FineReport| 开启 Gzip 压缩设置后，可以减少存储空间通过网络传输文件时，可以减少传输的时间，可加快 FineBI 的访问速度建议开启  
加密算法| FineBI| 管理员可在默认加密方式和国密间切换，切换加密方式后，传输、存储、用户密码等都统一使用国密算法进行加密详情请参见：[加密算法](<https://help.fanruan.com/finebi7.0/doc-view-1137.html>)  
外接数据库| FineBI| 报表系统配置外接数据库后，遇到集群环境或数据量较大情况时，可保证报表系统的稳定性详情请参见：[配置存储组件简介](<https://help.fanruan.com/finebi7.0/doc-view-1080.html>)  
注1：用户关闭「连接网址管理中心」按钮后，服务器将不再主动请求网址管理中心，且不会在日志中输出网址管理中心连接失败的相关日志。
注2：关闭「连接网址管理中心」按钮后，一些功能将无法使用，无法使用的功能如下表所示：
模块| 功能| 具体说明  
---|---|---  
云中心| 获取网址中心的网址| 网址管理中心本身  
插件引擎| 获取更新信息| 插件商城版本信息  
下载插件| 在线安装插件、在线更新插件  
平台-插件商城信息| 获取插件商城信息  
本地打印| 获取网址中心的网址| 在线下载本地打印  
BBS 认证| 帆软通行证登录| 设计器登录  
平台插件商城  
短信登录  
云端运维登录  
帆软市场| 开启 [短信平台](<https://help.fanruan.com/finebi7.0/doc-view-904.html>)| -  
发送短信| -  
  
决策平台| 获取当前客户端 IP 和城市| [上次登录信息提示](<https://help.fanruan.com/finebi7.0/doc-view-741.html>) 功能 注：上次登录信息提示功能无法显示最新信息
