## 1\. 概述
### 1.1 版本
BI 服务器版本  
| 功能变更  
---|---  
6.0| -  
### 1.2 功能简介
FineBI工程支持添加 3 种服务器数据集：SQL 数据集、树数据集、文件数据集。
1）服务器数据集可作为同步数据集，方便管理员 [同步用户](<https://help.fanruan.com/finebi7.0/doc-view-413.html>) 。
2）建立远程连接后，用户可以在 FineBI 中使用服务器数据集添加 FR 中的数据表。
![未命名文件.png](https://help.fanruan.com/core/style/lod.png)
## 2\. 添加权限
超级管理员默认可从FineBI工程添加服务器数据集。普通用户如需添加，需要超管授予权限。
超级管理员登录FineBI系统，点击「管理系统>权限管理>全局设置」，打开「分级授权」和「数据连接控制」，点击「保存」。如下图所示：
![](https://help.fanruan.com/core/style/lod.png)
超级管理员登录FineBI系统，点击「管理系统>权限管理>普通权限配置」，选择权限载体「部门/角色/用户」，选择具体项，配置「管理系统>数据连接>查看权限」。如下图所示：
![](https://help.fanruan.com/core/style/lod.png)
注：如需创建 SQL 数据集，需要额外获得数据连接的使用权限。
超级管理员登录数据决策系统，点击「管理系统>权限管理>普通权限配置」，选择权限载体「部门/角色/用户」，选择具体项，打开「数据连接>数据连接管理>使用权限」。如下图所示：
![](https://help.fanruan.com/core/style/lod.png)
## 3\. 服务器数据集添加方式
### 3.1 在 BI 中直接添加
拥有权限的用户登录FineBI工程，点击「管理系统>数据连接>服务器数据集」，点击「创建数据集」。
支持在FineBI系统添加 SQL 数据集、树数据集、文件数据集。如下图所示：
![](https://help.fanruan.com/core/style/lod.png)
各种数据集的具体设置方式如下表所示：
数据集类型| 简介| 文档教程  
---|---|---  
SQL 数据集| 数据源是数据连接的数据库中的表数据| [SQL 数据集](<https://help.fanruan.com/finebi7.0/doc-view-890.html>)  
  
树数据集| 数据源是有层级关系的 SQL 数据集| [树数据集](<https://help.fanruan.com/finebi7.0/doc-view-1011.html>)  
  
文件数据集| 文本数据集| 数据源是一系列的 TXT 文本文件| [文本数据集](<https://help.fanruan.com/finebi7.0/doc-view-1197.html>)  
  
Excel 数据集| 数据源是一系列的 XLS 文件| [Excel 数据集](<https://help.fanruan.com/finebi7.0/doc-view-1198.html>)  
  
XML 数据集| 数据源是一系列的 XML 文件| [XML 数据集](<https://help.fanruan.com/finebi7.0/doc-view-1199.html>)  
  
### 3.2 通过 FineReport 远程设计添加
FineReport 设计器中还可以添加更多服务器数据集类型：程序数据集、内置数据集、存储过程、关联数据集、JSON 数据集、JSON 程序数据集
用户如需在 BI 工程中添加上述类型的服务器数据集，可以通过 [FineReport 设计器远程连接 FineBI 工程](<https://help.fanruan.com/finebi7.0/doc-view-931.html>) ，在 FineReport 设计器中创建服务器数据集 ，BI 工程中即可出现该服务器数据集。
数据集  
| 数据集简介  
---|---  
[程序数据集](<https://help.fanruan.com/finereport/doc-view-637.html>) | 通过 AbstractTableData 抽象类来读取用户自定义的数据源  
[内置数据集](<https://help.fanruan.com/finereport/doc-view-109.html?source=4>)| 使用 FineReport 自身做的类似数据库表的原表  
[存储过程数据集](<https://help.fanruan.com/finereport/doc-view-117.html?source=4>)| 将数据库的存储过程查询为数据集  
[关联数据集](<https://help.fanruan.com/finereport/doc-view-125.html?source=4>)  
| 参见<关联数据集>的第 1 节  
[树数据集](<https://help.fanruan.com/finereport/doc-view-126.html?source=4>) | 添加有层级关系的数据集  
[MongoDB 数据连接](<https://help.fanruan.com/finebi7.0/doc-view-417.html?source=4>)  
| BI 暂不可以直接连接 MongoDB 数据库，使用 FineReport 连接 MongoDB 实现数据集，然后 BI 调用  
## 4\. 效果预览
该页面列出所有数据集，包含 FineReport 设计器远程连接 BI 工程时创建的服务器数据集数据集。
  * 平台支持添加的服务器数据集类型：SQL 数据集、树数据集、文件数据集

## 6\. 补充说明
### 6.1 直连服务器数据集注意事项
1）服务器数据集的数据受缓存策略限制，详细可参见：[BI缓存](<https://help.fanruan.com/finebi7.0/doc-view-1674.html>)
![](https://help.fanruan.com/core/style/lod.png)
2）服务器数据集不支持和「数据库表」和「SQL数据集」联合查询（包括：上下合并、左右合并、关联），若进行了联合查询，系统会报错：不支持服务器数据集合DB表，SQL表联合查询
3）服务器数据集支持和「Excel数据集」联合查询。
### 6.2 禁用 SQL 函数
一些高危的 SQL 函数安全风险较高，因此补充默认禁用的 SQL 关键字和函数。
若语句中使用了禁用内容建议修改语句。
1）6.0 至 6.0.15 版本默认禁用的 SQL 函数如下：
数据库  
| 禁用的SQL函数  
---|---  
MySQL| load_fileoutfilegeneral_loggeneral_log_fileascii  
informationmidschema_name  
  
2）6.0.16 及之后版本默认禁用的 SQL 函数如下：
数据库  
| 禁用的SQL函数  
---|---  
H2| file_writefile_readcsvwritecsvread  
HSQL| load_filescript  
SQLSERVER| xp_cmdshellxp_regwrite  
sp_oacreatesp_configurexp_write_filexp_read_fileopenrowset  
MySQL| load_fileoutfilegeneral_loggeneral_log_file  
### 6.3 禁用 SQL 关键字
1）6.0 至 6.0.15 版本默认禁用的 SQL 关键字如下：
attach、create、drop、alter、merge、insert、delete、comment、call、renname、lock、exec、database。
2）6.0.16 及之后版本默认禁用的 SQL 关键字如下：
benchmark、xp_dirtree、attach、create、drop、alter、merge、insert、delete
