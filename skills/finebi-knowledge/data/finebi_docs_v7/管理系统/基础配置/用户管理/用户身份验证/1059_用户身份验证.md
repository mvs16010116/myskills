### 1.2 功能简介
用户登录FineBI系统时，系统需要对输入的用户名和密码进行验证，以确保系统安全。  

FineBI系统提供三种用户身份认证方式，管理员可根据需求选择认证方式。
## 2\. 认证方式
管理员登录FineBI系统，点击「管理系统>用户管理>全局设置」，可看到三种认证方式，如下图所示：
注：FineBI系统支持多源用户。管理员可对「导入、添加的用户」和「同步的用户」分别设置认证方式。
![](https://help.fanruan.com/core/style/lod.png)
三种认证方式的简介如下表所示：
认证方式  
| 简介  
---|---  
平台内置认证| 平台内置认证是指使用平台内部的 [用户信息](<https://help.fanruan.com/finebi7.0/doc-view-170.html>) 进行身份验证，如果用户名密码一致，则通过认证，不一致则不通过默认使用平台内置认证  
LDAP 认证| 用户登录时，平台拿用户名密码到设置的 LDAP 系统进行认证，认证成功则登录成功，若认证失败，则登录失败详情请参见： [LDAP认证](<https://help.fanruan.com/finebi7.0/doc-view-1058.html>)  
HTTP 认证| 用户登录时，平台拿用户名密码到设定的验证页面进行验证，认证成功则登录成功，若认证失败，则登录失败详情请参见： [HTTP 认证](<https://help.fanruan.com/finebi7.0/doc-view-1075.html>)
