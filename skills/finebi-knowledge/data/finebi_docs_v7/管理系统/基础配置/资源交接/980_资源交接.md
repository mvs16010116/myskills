## 1\. 概述
适用人群：超级管理员
注：次级管理员无法在「数据决策系统>管理系统」下进行资源交接相关管理操作。
### 1.1 版本
FineBI 版本| 功能变动  
---|---  
6.0| -  
6.0.2  
| 1）资源交接的接收方，支持选择超管2）已删除用户的用户名显示优化对于因同步用户导致删除的用户，在资源交接时，展示为用户名（用户id）对于手动从FineBI系统中删除的用户，在资源交接时，展示为未知用户（用户id）  
### 1.2 应用场景
当企业中有用户离职或者转岗后，该用户制作的仪表板和数据集需要交接给其他用户继续进行使用和编辑。  

### 1.3 功能简介
管理员可以把 A 用户制作的的全部或部分数据集、仪表板批量交接为 B 用户。
B 用户可以像原用户一样，自由的使用、编辑这些资源。
## 2\. 资源交接说明
### 2.1 交接内容
支持资源交接的内容为「我的分析」和「公共数据」下的资源。
**1）我的分析**
我的分析，可交接的资源包括：文件夹、分析主题、数据、组件、仪表板等。
接收方在「我的分析」下会自动新建一个文件夹，名称为「交出方用户名+移交的分析」，作为接收分组。
交接后，在接收分组下，按原有相对路径(相对于原根目录)放置交接的资源 ，并将创建者更改为接收方。
**2）公共数据**
公共数据下，可交接的资源包括：DB表、SQL表、Excel、发布的数据集。
对于DB表、SQL表、Excel，交接前后资源位置不变，仅将创建者从交出方改为接收方，使得接收方可以像交出方一样对这些表进行使用、管理。
对于发布的数据集，交接的逻辑与在我的分析下选择对应的数据集，效果相同。
### 2.2 用户类型
支持资源交接的内容为「我的分析」和「公共数据」下的资源。
而仅 BI设计用户才可进行「我的分析」和「公共数据」下的相关操作。
因此资源接收方必须是 [BI设计用户](<https://help.fanruan.com/finebi7.0/doc-view-367.html>)，否则无法进行交接。
注：6.0.2及之后版本，资源交接的接收方，支持选择超管
### 2.3 数据权限
做资源交接的两个用户，对交接资源的权限建议完全一致。
否则由于 [权限](<https://help.fanruan.com/finebi7.0/doc-view-488.html>) 不一致，交接后可能数据不可用。
## 2\. 普通用户资源交接
普通用户资源交接是指该用户没有从用户管理中删除时，管理员将该用户制作的部分或者全部仪表板和数据集交接给其他用户使用。
本例为用户 Anna 由于转岗，需要将其制作的相关资源交接给用户 eoco 使用。
### 2.1 选择交出方
超管登录FineBI系统，选择「管理系统>资源交接」，选择「普通用户」，选择交出方为 Anna 用户，如下图所示：
交出方可选用户范围：[[BI设计用户](<https://help.fanruan.com/finebi7.0/doc-view-367.html>)](<https://help.fanruan.com/finebi7.0/doc-view-370.html>)（包括超级管理员）
![](https://help.fanruan.com/core/style/lod.png)
### 2.2 选择交接资源
#### 2.2.1 我的分析  

点击「我的分析」Tab，选择「我的分析」下该用户创建的需要交接的文件夹、分析主题、数据、组件、仪表板等。
![](https://help.fanruan.com/core/style/lod.png)
#### 2.2.2 公共数据
点击「公共数据」Tab，选择「公共数据」下该用户创建/发布的需要交接的数据表。
![](https://help.fanruan.com/core/style/lod.png)
### 2.3 选择接收方
接收方可选用户范围：[[BI设计用户](<https://help.fanruan.com/finebi7.0/doc-view-367.html>)](<https://help.fanruan.com/finebi7.0/doc-view-370.html>)（包含超级管理员）
选择接收方为「eoco」。
![](https://help.fanruan.com/core/style/lod.png)
### 2.4 进行交接
点击「确定」，弹出对话框「是否确定将“安娜（Anna）”的资源交接给“艾可（eoco）”？」，点击「确定」，如下图所示：
![](https://help.fanruan.com/core/style/lod.png)
注1：若用户部门角色不一致，则会弹出提示「交出方和接收方的部门角色不匹配，未来可能需要重新配置权限。确定执行交接？」，如下图所示：
![](https://help.fanruan.com/core/style/lod.png)
注2：若被交接的资源正在被编辑，则出现提示「正在编辑的资源不支持交接，请退出编辑或重新选择资源。」
![](https://help.fanruan.com/core/style/lod.png)
交接成功后，出现提示「交接成功」，如下图所示：  

注1：若交接失败，则会提示：系统异常，交接失败，具体异常信息已写入系统日志。
注2：若有因异常不能交接的资源，系统会自动跳过交接失败的资源，继续交接剩余资源。
![](https://help.fanruan.com/core/style/lod.png)
### 2.4 效果查看
#### 2.4.1 我的分析  

接收方用户eoco（eoco，1）登录FineBI系统，点击「我的分析」，新增文件夹「Anna移交的分析主题」，文件夹内为本次交接到Anna的所有资源，如下图所示：
eoco可对主题进行编辑、删除、重命名等处理。
![](https://help.fanruan.com/core/style/lod.png)
#### 2.4.2 公共数据
接收方用户eoco（eoco，1）登录FineBI系统，点击「公共数据」。
Anna创建的数据集，创建人已更改为eoco，如下图所示：
![](https://help.fanruan.com/core/style/lod.png)
## 3\. 已删除用户资源交接
已删除用户是指该用户从用户管理中删除，管理员将该用户制作的部分或者全部仪表板和数据集交接给其他用户使用。
注：如不进行交接，其他用户编辑该数据集时，提示：保存失败，user unknown，key：未知用户，cause：get null user object
![image.png](https://help.fanruan.com/core/style/lod.png)
本例为 Alice 用户交接创建的仪表板给 Anna 用户。
### 3.1 操作步骤
超管登录FineBI系统，选择「管理系统>资源交接」，选择「已删除用户」，选择交出方，选择需要转出的仪表板，选择接收方为 Anna 用户 ，如下图所示：
交出方可选用户范围| 用户管理中已经删除该用户，但FineBI系统中仍然有相关资源的用户。通过查询暂存的删除用户表，可展示删除用户的用户名。若查询不到，则显示未知用户+用户ID。  
---|---  
**接收方可选用户范围**| [[BI设计用户](<https://help.fanruan.com/finebi7.0/doc-view-367.html>)](<https://help.fanruan.com/finebi7.0/doc-view-370.html>)6.0.2及之后版本，资源交接的接收方，支持选择超管

## 4\. 注意事项
### 4.1 数据连接权限
对于SQL数据集和数据库表，接收资源用户需要有该数据集的使用权限和对应 [数据连接的使用权限](<https://help.fanruan.com/finebi7.0/doc-view-488.html>) 。
### 4.2 主题分享
交接不会改变资源分享或者协作的状态。
若交接前资源被分享/协作给其他用户，交接后其他用户仍然拥有该资源的相关权限。
### 4.3 挂出仪表板
对于已经挂出或者正在申请挂出的仪表板，在交接后仍维持原来的状态，但相关信息更改为接收仪表板用户的信息。
### 4.4 公共链接
若在交接前，接收资源用户没有开启公共链接的权限，则需要为其开启 [公共链接权限](<https://help.fanruan.com/finebi7.0/doc-view-622.html>) ，否则仪表板公共链接会显示关闭状态。
