## 1\. 概述
### 1.1 版本
FineBI服务器版本| 功能变更  
---|---

### 1.2 应用场景
用户在生产环境上，数据把控的比较严格，大部分用户是不允许导出数据的。
管理员需要可以根据权限载体分配导出权限，对数据安全性进行把控。因此 FineBI 提供了模板导出权限控制来实现该功能。
### 1.3 功能简介
管理员登录 FineBI 数据决策系统，选择「管理系统>权限管理」，在「目录权限」中可为目录/仪表板配置导出权限。如下图所示：  

  * 支持授权导出的内容有：目录节点、FineBI仪表板
  * 不支持授权导出的内容有：FineReport模板、上报标签、超级链接。如需导出FineReport模板，请为模板配置 [浏览器端导出](<https://help.fanruan.com/finereport/doc-view-1109.html>) 。


注1：对于不支持导出权限的内容，权限锁灰化，提示：非BI模板暂不支持导出权限控制。
权限锁灰化，不影响管理员对编辑/授权权限的分配。
注2：有目录导出权限的用户则必然拥有该目录的查看权限。 
![](https://help.fanruan.com/core/style/lod.png)
## 2\. 示例
本章示例：「销售部」员工需要将目录「销售主题」下的仪表板以 PDF 或 Excel 格式导出。
### 2.1 设置用户分类
若「平台使用用户」中「PC端使用用户」及其子分类均为「不限人数」，则无需执行本节操作。
若「平台使用用户」中「PC端使用用户」及其子分类限制了人数，则必须执行本节操作，否则无法查看仪表板。
管理员登录FineBI系统，点击「管理系统>用户管理>平台使用用户」，将销售部员工添加至「BI使用用户（查看用户或设计用户）」中，如下图所示：
![](https://help.fanruan.com/core/style/lod.png)
注：若用户不属于BI使用用户（查看用户或设计用户），即使管理员给该用户分配了对应目录的查看权限，该用户登录FineBI系统后，虽然能在左侧看到对应目录，但是点击查看时，会提示：「非常抱歉，您无法查看该页面。没有权限，请检查平台使用用户设置」。
![](https://help.fanruan.com/core/style/lod.png)
### 2.2 分配目录导出权限
管理员登录FineBI系统，点击「管理系统>权限管理>普通权限配置」，选择权限载体「部门/角色/用户」。
本示例选择部门「销售部」。选择「目录权限」Tab，为「销售部」分配目录「销售主题」的导出权限，如下图所示：
注：一个用户有目录导出权限，则必定有目录查看权限。
![](https://help.fanruan.com/core/style/lod.png)
### 2.3 分配数据使用权限
目录「销售主题」中的仪表板，使用了公共数据文件夹「02_销售_Lisa」的数据。因此需要给销售部员工分配该文件夹的组件数据权限。
管理员登录FineBI系统，点击「管理系统>权限管理>普通权限配置」，选择权限载体「部门/角色/用户」。
本示例部门「销售部」。选择「数据权限」Tab，为「销售部」分配文件夹「02_销售_Lisa」的查看权限，如下图所示：
![](https://help.fanruan.com/core/style/lod.png)
注：如不分配数据权限，查看后会显示报错：「您暂时无权限查看该组件数据，如有疑问请联系管理员」。如下图所示：
![](https://help.fanruan.com/core/style/lod.png)
### 2.4 分配模板认证导出权限
注：此操作的前提是系统开启了 [模板认证](<https://help.fanruan.com/finebi7.0/doc-view-403.html>) 中的 [角色权限认证](<https://help.fanruan.com/finebi7.0/doc-view-405.html>) 功能。如未开启，无需执行本操作。
管理员登录FineBI系统，点击「管理系统>模板认证>普通权限配置」，选择权限载体「部门/角色/用户」。
本示例选择部门「销售部」，为「销售部」分配「销售主题」相关仪表板的「导出」权限，如下图所示：
![](https://help.fanruan.com/core/style/lod.png)
### 2.5 效果预览
销售部员工Lisa（Lisa，1）登录FineBI系统，即可查看目录「销售主题」及目录下的仪表板。可以看到上方的操作栏有导出按钮，可导出仪表板。如下图所示：
![](https://help.fanruan.com/core/style/lod.png)
