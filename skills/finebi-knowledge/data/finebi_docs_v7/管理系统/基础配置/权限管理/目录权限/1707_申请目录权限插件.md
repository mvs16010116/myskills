## 1\. 概述
### 1.1 版本
FineBI服务器版本| 插件版本  
---|---  
6.0| V1.0  
### 1.2 应用场景
无目录查看权限的情况下，就无法知晓模板的存在，导致重复性工作。例如：
人力资源部门制作了一张「员工培训明细」仪表板，挂载在FineBI系统目录中，但仅给人力资源部门开放了目录查看权限。  

财务部需要统计员工培训带来的财务成本，但是由于没有「员工培训明细」仪表板的查看权限，不知道人力部门已经制作好了相关仪表板，自己又花时间做了仪表板，事倍功半。
### 1.3 功能介绍
通过安装「申请目录权限」插件，用户能够直接在平台查看所有目录的标题和描述，方便对于没有权限的节点进行申请。
## 2\. 插件介绍
### 2.1 插件安装
点击下载插件：[申请目录权限插件](<https://market.fanruan.com/plugin/845609bb-3964-4b17-aa1f-eefdc3be0bfd>)
插件安装方法请参见：[插件管理](<https://help.fanruan.com/finebi7.0/doc-view-459.html>)[](<https://help.fanruan.com/finereport/doc-view-2220.html>)
### 2.2 界面简介
用户访问工程路径/entry/overview页面（例如http://localhost:37799/webroot/decision/entry/overview），可查看到当前FineBI系统中所有目录的名称和描述，可对无权限的目录申请查看权限。如下图所示：
注1：若工程配置了虚拟路径，例如 [Tomcat 下通过 IP 直接访问数据决策系统](<https://help.fanruan.com/finebi7.0/doc-view-903.html>) ，则访问路径为 http://ip/decision/entry/overview ，必须要额外加上decision。
注2：推荐将该页面挂载到数据决策系统目录中，方便用户访问和查看。
![](https://help.fanruan.com/core/style/lod.png)
超级管理员登录FineBI系统，在「我的消息」中新增「目录申请」消息。可接收到用户申请目录查看权限的消息，支持跳转到权限管理页面进行处理。
注：只有超级管理员可以收到申请消息，次级管理员无权限。
![](https://help.fanruan.com/core/style/lod.png)
## 3\. 示例
人力资源部门制作了一张「住房公积金可视化驾驶舱」仪表板，挂载在数据决策系统目录中。  

财务部用户 eoco 需要统计住房公积金带来的财务成本，于是申请「住房公积金可视化驾驶舱」仪表板的查看权限。
### 3.1 用户申请查看权限
用户 eoco（eoco，1）登录FineBI系统。在浏览器窗口访问http://IP:port/webroot/decision/entry/overview页面。
在「行业应用>公共部门」目录列表中发现了「住房公积金可视化驾驶舱」仪表板，点击「申请权限」。
弹出提示框「你将向超管(1)发送目录节点的查看申请，是否确认？目录节点: 行业应用/公共部门/住房公积金可视化驾驶舱」，点击「确定」。如下图所示：
![](https://help.fanruan.com/core/style/lod.png)
### 3.2 超管分配权限
超级管理员登录FineBI系统，弹出新消息「你好，艾可（eoco）申请查看目录节点:管理驾驶舱/住房公积金可视化驾驶舱」，如下图所示：
![](https://help.fanruan.com/core/style/lod.png)
点击「处理」按钮，跳转到「管理系统>权限管理」页面。
**1）分配目录权限**
在「普通权限配置」界面，选择权限载体「部门/角色/用户」，本示例选择用户eoco。
为其分配目录「行业应用>公共部门>住房公积金可视化驾驶舱」的「查看」权限，如下图所示：
![](https://help.fanruan.com/core/style/lod.png)
**2）分配数据权限**
点击目录「住房公积金可视化驾驶舱」后的「组件数据权限」设置按钮，勾选相关组件数据权限，点击「确定」，如下图所示：
![](https://help.fanruan.com/core/style/lod.png)
### 3.3 效果预览
用户 eoco（eoco，1）再次登录FineBI系统。可查看「住房公积金可视化驾驶舱」目录。如下图所示：
![](https://help.fanruan.com/core/style/lod.png)
