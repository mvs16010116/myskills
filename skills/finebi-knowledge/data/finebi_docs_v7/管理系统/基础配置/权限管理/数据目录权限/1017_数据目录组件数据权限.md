## 1\. 概述
### 1.1 版本
FineBI服务器版本  
| 功能变更  
---|---  
7.0| -  
### 1.2 应用场景
1）希望用户能在仪表板中查看表X的数据，但是不希望用户在「数据目录」查看 / 使用表X。
2）希望管理员给用户配置仪表板查看权限后，可以快速配置对应数据的查看权限。
### 1.3 功能简介
FineBI 系统提供组件数据权限配置，专门用于目录中仪表板组件的数据查看权限。
![](https://help.fanruan.com/core/style/lod.png)
## 2\. 组件数据权限简介
### 2.1 使用范围
**何时需要配置组件数据权限？**
1）使用数据目录的表 A 制作了主题内的数据表 B ，组件调用数据表 B 的数据，那么管理员需要为用户分配数据目录表 A 的查看权限。
2）使用主题内上传 Excel 的 Excel 数据，组件数据权限已自动配置开启，无需额外设置。
**举例：**
用户在「我的分析」下创建的仪表板，其中的组件的数据来源，若使用「数据目录」中的表，如下图所示：
![](https://help.fanruan.com/core/style/lod.png)
那么其他用户如需查看该仪表板中该组件的数据，必须要给用户分配「数据目录」中的表的组件数据权限。
![](https://help.fanruan.com/core/style/lod.png)
### 2.2 生效范围
「数据目录」下的表，「管理」权限依赖「使用」权限，「使用」权限依赖「元数据」和「组件数据」权限。
  * 用户有A表的「使用」权限，则必定有A表的「组件数据」和「元数据」权限。
  * 用户有A表的「管理」权限，则必定有A表的「组件数据」、「元数据」权限和「使用」权限。


### 2.3 注意事项
**1）直连数据类型**
由于直连权限缓存跟随数据集缓存，因此如果数据为「直连数据」类型，权限分配不一定实时生效。
如发现权限分配未生效，并非配置出问题，而是命中了缓存。请耐心等待 5~10 分钟，等待缓存失效后再次查看效果即可。
**2）组件数据权限**
用户在只拥有「组件数据」的权限时，能够在目录预览数据，但无法使用这些数据来编辑仪表板。
若将仪表板另存为主题后打开，另存为的分析主题中「数据」Tab 没有明细数据，显示「字段xxx的权限丢失，只能显示空数据」。
![](https://help.fanruan.com/core/style/lod.png)  

「组件」Tab 中无法编辑组件，字段标红，需向管理员申请对应数据表的使用权限。
![](https://help.fanruan.com/core/style/lod.png)  

## 3\. 示例
本章示例：
「数据目录」下有一张表「组织绩效」，仪表板「销售业绩达成情况」中的组件基于此表创建。
给部门「开发部」分配权限，使得开发部员工 Billy 登录 FineBI 系统后可查看目录中的仪表板「销售业绩达成情况」。
### 3.1 设置用户分类
若「平台使用用户」中「PC端使用用户」及其子分类均为「不限人数」，则无需执行本节操作。
若「平台使用用户」中「PC端使用用户」及其子分类限制了人数，则必须执行本节操作，否则无法查看仪表板。
管理员登录 FineBI 系统，点击「管理系统>用户管理>平台使用用户」，将用户 Billy 添加至「设计用户」中。
![](https://help.fanruan.com/core/style/lod.png)
### 3.2 分配数据组件数据权限
注1：使用主题内上传 Excel 的 Excel 数据，组件数据权限已自动配置开启，无需额外设置。
注2：使用数据目录的表 A 制作了主题内的数据表 B ，组件调用数据表 B 的数据，那么管理员需要为用户分配数据目录表A 的查看权限。
1）管理员登录 FineBI 系统，点击「管理系统>权限管理>普通权限配置」。  

2）选择权限载体「部门 / 角色 / 用户」，本示例选择部门「开发部」。
3）选择「数据目录&指标中心>数据目录」Tab，为其配置「部门数据>销售_Lisa>组织绩效」的「组件数据」权限。
![](https://help.fanruan.com/core/style/lod.png)
### 3.3 分配目录查看权限
1）管理员登录 FineBI 系统，点击「管理系统>权限管理>普通权限配置」。  

2）选择权限载体「部门 / 角色 / 用户」，本示例选择部门「开发部」。
3）选择「目录权限」Tab，为其分配「业务应用>销售主题>销售业绩达成情况」的目录查看权限，如下图所示：
![](https://help.fanruan.com/core/style/lod.png)
目录权限的「组件数据权限」，和数据目录的「组件数据」权限关联，可以看到「销售业绩达成情况」仪表板后的组件数据权限已勾选。如下图所示：
![](https://help.fanruan.com/core/style/lod.png)
### 3.4 效果预览
开发部员工 Billy（Billy，1）登录 FineBI 系统，即可查看「销售业绩达成情况」仪表板。如下图所示：
注：由于直连权限缓存跟随数据集缓存，因此如果数据为「直连数据」类型，权限分配不一定实时生效。
如发现权限分配未生效，并非配置出问题，而是命中了缓存。请耐心等待5~10分钟，等待缓存失效后再次查看效果即可。
