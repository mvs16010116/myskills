## 1\. 概述
### 1.1 版本
FineBI服务器版本  
| 功能变更  
---|---  
7.0| -  
  
### 1.2 应用场景
次级管理员需要能在「数据目录」指定文件夹下添加/编辑/删除数据库表、SQL数据集、Excel数据集。
### 1.3 功能简介
超管赋予用户数据目录中文件夹的管理权限，用户可在文件夹下新建表。
超管赋予用户数据目录中表的管理权限，用户可对有权限的表进行编辑 / 删除操作。
### 1.4 前置条件
由于只有「设计用户」可以编辑数据表，因此需要先设置用户分类。  

超管登录 FineBI 系统，点击「管理系统>用户管理」，选择平台使用用户，将人力资源部长 Lily 添加至「设计用户」中，如下图所示：
![](https://help.fanruan.com/core/style/lod.png)
## 2\. 数据库表/SQL数据集
本章示例：给部门「人力资源」分配权限，使人力资源员工可以新建 / 编辑 / 删除数据库表 / SQL 数据集。
次管不仅需要拥有「数据库表 / SQL 数据集」的管理权限，还需要「数据库表/SQL 数据集」调用的数据连接的使用权限。
### 2.1 开启数据连接授权
超级管理员登录 FineBI 系统，点击「管理系统>权限管理>全局设置」，开启「数据连接控制」按钮，点击「保存」。如下图所示：
注：如不开启「数据连接控制」按钮，则默认用户不拥有任何数据连接的使用权限。
![](https://help.fanruan.com/core/style/lod.png)
### 2.2 分配数据连接使用权限
1）管理员登录 FineBI 系统，点击「管理系统>权限管理>普通权限配置」。
2）选择权限载体「部门 / 角色 / 用户」，本示例选择部门「人力资源」。
3）选择「数据连接」Tab，为其配置指定数据连接和服务器数据集的「使用」权限，如下图所示：
![](https://help.fanruan.com/core/style/lod.png)
### 2.3 分配数据权限
1）管理员登录 FineBI 系统，点击「管理系统>权限管理>普通权限配置」。
2）选择权限载体「部门 / 角色 / 用户」，本示例选择部门「人力资源」。
3）选择「数据目录&指标中心>数据目录」Tab，为其配置文件夹「部门数据>HR_Lily」的「管理」权限。
![](https://help.fanruan.com/core/style/lod.png)
### 2.4 效果预览
人力资源部长 Lily （Lily，1）登录 FineBI 系统，点击「数据目录」。  

**1）新建表**
可在「部门数据>HR_Lily」文件夹及子文件夹内新建**数据库表** ，仅支持**有权限的数据连接和服务器数据集** 。
可在「部门数据>HR_Lily」文件夹及子文件夹内新建**SQL数据集** ，仅支持**有权限的数据连接** 。
![](https://help.fanruan.com/core/style/lod.png)
**2）管理表**
可对「部门数据>HR_Lily」文件夹及子文件夹内的、有数据连接权限的 **SQL 数据集** 进行「**修改SQL、编辑** 」操作。
可对「部门数据>HR_Lily」文件夹及子文件夹内、有数据连接权限的**数据库表** 进行「**编辑** 」操作。
![](https://help.fanruan.com/core/style/lod.png)
## 3\. Excel数据集
本章示例：给部门「人力资源」分配权限，使人力资源员工可以新建/编辑/删除Excel数据集。  

### 3.1 分配数据权限
1）管理员登录 FineBI 系统，点击「管理系统>权限管理>普通权限配置」。
2）选择权限载体「部门 / 角色 / 用户」，本示例选择部门「人力资源」。
3）选择「数据目录&指标中心>数据目录」Tab，为其配置文件夹「部门数据>HR_Lily」的「管理」权限。
![](https://help.fanruan.com/core/style/lod.png)
### 3.2 效果预览
次管eoco登录数据决策系统，点击「数据准备」。
1）可在「部门数据>HR_Lily」文件夹及子文件夹内新建 Excel 数据集。
2）可对「部门数据>HR_Lily」文件夹及子文件夹内的 Excel 数据集进行编辑、更新等操作。
![](https://help.fanruan.com/core/style/lod.png)
