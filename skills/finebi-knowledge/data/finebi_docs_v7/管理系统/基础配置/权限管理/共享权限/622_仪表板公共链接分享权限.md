## 1\. 概述
### 1.1 版本
BI 服务器版本| 功能变更  
---|---  
6.0| -  
6.1.2| 公共链接中新增导出权限  
### 1.2 功能简介
公共链接功能让所有用户都能将自己创建的仪表板公开，此行为可能会导致内部数据外泄。
因此 FineBI 新增了对公共链接权限的管理，需要公开链接时可以给对应用户配置权限，方便管理。
注：仅支持超管分配该分享权限给用户，次管无法分配该权限。
## 2\. 示例
本章示例：给「销售主管」分配「仪表板公共链接」共享权限，使得销售主管可以将自己制作的仪表板生成公共链接，分享给任何人。
### 2.1 分配分享权限
超管登录FineBI系统，点击「管理系统>权限管理>普通权限配置」，选择权限载体「部门/角色/用户」。
本示例选择部门「销售部>saleLeader」。选择「共享权限」Tab，为 eoco 配置「仪表板公共链接」的「使用」权限，如下图所示：
![813-1731.png](https://help.fanruan.com/core/style/lod.png)
### 2.2 生成公共链接
销售主管Lisa（Lisa，1）登录 FineBI 系统，可对仪表板 [创建公共链接](<https://help.fanruan.com/finebi7.0/doc-view-164.html>)，如下图所示：
创建好的公共链接可以分享给任何人查看，无论是否有使用权限都可以查看此公共链接。
![](https://help.fanruan.com/core/style/lod.png)
## 3\. 注意事项
### 3.1 取消权限
若之前的已分配权限的用户，管理员想要取消他们的权限，可进入权限管理，直接关闭权限，如下图所示：
![813-1734.png](https://help.fanruan.com/core/style/lod.png)
此时，用户之前创建的公共链接将失效，访问该链接时将显示分享被取消或不存在，如下图所示：
![](https://help.fanruan.com/core/style/lod.png)
当管理员再次开启公共链接使用权限时，对应链接则重新生效。
### 3.2 公共链接导出权限
6.1.2 及之后版本，支持导出公共链接。需开启「公共连接导出控制」权限，确保用户分享的公共链接具备仪表板导出权限。如下图所示：
![820-1549.png](https://help.fanruan.com/core/style/lod.png)
拥有「公共链接导出控制」权限的用户，创建公共链接时勾选「公共链接导出」可以允许该公共链接导出。如下图所示：
![820-1558.png](https://help.fanruan.com/core/style/lod.png)
使用公共链接查看仪表板时，点击左上角「导出」按钮，就可导出仪表板。如下图所示：
![820-1600.png](https://help.fanruan.com/core/style/lod.png)
