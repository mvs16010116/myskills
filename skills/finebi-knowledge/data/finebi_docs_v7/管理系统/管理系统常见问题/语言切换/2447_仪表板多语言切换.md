### 1.4 key匹配规则
#### 1.4.1 通用规则
富文本中需要使用 fi18n[] 函数的场景可参见 1.3 节中标注的场景，此处介绍不使用 fi18n[] 时的匹配规则：以行为单位，每行的 key 需要全词匹配（包括符号和空格）才能够被识别并实现转换。
场景| 规则| 示例  
---|---|---  
文字  
| 单行情况下当行的文本内容需要为一个 key（包括符号和空格）| 1）若已将「购买数量」录入为 key，则「购买数量」能被识别并转换，「购买数量：」不能被识别![708-1517.png](https://help.fanruan.com/core/style/lod.png)![708-1520.png](https://help.fanruan.com/core/style/lod.png)![708-1523.png](https://help.fanruan.com/core/style/lod.png)2）如果希望「购买数量：」能够被识别的话，需要将「购买数量：」作为一个 key 录入![708-1525.png](https://help.fanruan.com/core/style/lod.png)![708-1530.png](https://help.fanruan.com/core/style/lod.png)  
多行情况下，每行识别为单独的 key| 换行的情况下，「购买数量」能被识别![708-1534.png](https://help.fanruan.com/core/style/lod.png)  
文字 + 字段| 若当行富文本内容中存在维度/指标字段，则将以字段作为分割，字段前后的文本可以被单独识别为 key。例如：key1字段key2，则 key1、key2 均可以被识别。同样，key1、key2 需满足全词匹配（包括符号和空格）| 若已将「购买数量：」和「（个）」录入为 key，则「购买数量:+字段+（个）」中，「购买数量：」和「（个）」均可以被识别![708-1543.png](https://help.fanruan.com/core/style/lod.png)  
#### 1.4.2 例外情况
图表提示中，适配了 key1:key2 的场景，如果 key 之间使用「：」进行了分割并紧贴「：」（不能有空格），则 key1、key2 均可以被识别。
注：除「：」外其他符号同 1.4.2 节中的规则一致。

### 2.4 制作仪表板
#### 2.4.1 「组件国际化」按钮
V2.3.13 及之后的版本支持一键实现组件标题、表头国际化，如下图所示：
![1775035155JxIW.png](https://help.fanruan.com/core/style/lod.png)
1）组件标题国际化
点击按钮后，自动将组件标题嵌套国际化公式（fi18n[原始组件名])，以及自动将组件名称作为国际化 key 储存。用户在「管理系统 > 语言配置」中补充对应语言的翻译。
储存规则：
  * 只储存新的国际化 key，如果历史 key 已经存在则直接略过。
  * 如果新增的国际化 key 有重复，则后面的 key 改写前面的 key。


支持范围：
  * 支持静态字符串的自定义标题。
  * 支持默认标题（动态获取组件名）。
  * 不支持字段标题。


2）表头国际化
点击按钮后，自动将表头字符作为国际化 key 储存，用户在「管理系统 > 语言配置中」中补充对应语言的翻译。
#### 2.4.2 手动设置国际化
V2.3.13 之前的版本需要逐个修改组件标题：
1）新建一个仪表板，将制作好的表格和图表组件拖入仪表板，并分别修改组件标题为 fi18n[组件标题] 格式。以表格为例，如下图所示：
![708-1027.png](https://help.fanruan.com/core/style/lod.png)
2）添加「其他>文字组件」作为仪表板标题，内容设置为 2011-2017[合同分析看板]，如下图所示：
![708-1034.png](https://help.fanruan.com/core/style/lod.png)
3）添加「过滤组件>文字下拉」对合同类型进行过滤，添加「过滤组件>年月区间」对合同签约进行过滤，如下图所示：
![708-1036.png](https://help.fanruan.com/core/style/lod.png)
「文字下拉」组件的标题设置为 fi18n[合同类型] ，如下图所示：
![708-1037.png](https://help.fanruan.com/core/style/lod.png)
