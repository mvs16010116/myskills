## 1\. 概述
### 1.1 版本
FineBI 版本| 多语言方案插件版本  
---|---  
6.0.19| V2.2.0  
### 1.2 应用场景
在企业中，不同部门使用不同语言时，为了避免使用多个系统来满足各部门的需求，需要实现一个系统并具备多语言展示的效果。不仅包括切换决策平台的系统界面语言，还需要切换平台的目录名称、平台标题以及移动平台服务器等。如下图所示：
![705-1122.gif](https://help.fanruan.com/core/style/lod.png)
### 1.3 功能简介
FineBI 支持对决策平台的语言进行切换，切换范围包括以下两类：
  * 支持一键切换系统界面语言：[管理系统](<https://help.fanruan.com/finebi7.0/doc-view-168.html>)、[登录页](<https://help.fanruan.com/finebi7.0/doc-view-986.html>)、 [BI工具](<https://help.fanruan.com/finebi7.0/doc-view-1546.html>)、 [公共数据](<https://help.fanruan.com/finebi7.0/doc-view-263.html#05b38ab11c967326>)、 [我的分析](<https://help.fanruan.com/finebi7.0/doc-view-263.html#9316593119caa4f8>)、 [回收站](<https://help.fanruan.com/finebi7.0/doc-view-263.html#a2aeb07c38e21d3e>)。
  * 支持通过「键-值」切换平台语言：系统中可自定义名称的部分，如：平台目录名称、平台标题、移动平台服务器名称等。


注1：只支持「简体中文、繁体中文、英文、日文、韩文」5 种语言的切换。
注2：不支持仪表板内容的多语言切换，如需实现仪表板语言切换请参考 [仪表板多语言切换](<https://help.fanruan.com/finebi7.0/doc-view-2447.html>) 。
本文将以一个简单的示例来演示如何切换决策平台的语言。
### 1.4 使用前提
安装多语言方案插件，点击下载插件：[](<https://market.fanruan.com/plugin/2cd754e6-3765-42f3-a45c-8b25160e8a2e>)[多语言方案](<https://market.fanruan.com/plugin/ccee8b03-bedf-4939-b063-c3872cac31d0>)。
设计器插件安装方法请参见： [插件管理](<https://help.fanruan.com/finebi7.0/doc-view-459.html>)。
## 2\. 示例
**本节示例：**
切换决策平台的语言为英文，切换范围包括管理系统、「测试」目录以及该目录下的子目录和子模板、平台标题、移动平台服务器名称。
**实现思路：**
设置「键-值」，将自定义的目录/模板名称、平台标题、移动平台服务器名称设置为 Key「键」，其对应的英文设置为「值」。
则在切换平台语言时，将一键切换管理系统的语言，并根据 Key 将自定义的名称切换为对应的英文。
### 2.1 准备工作
#### 2.1.1 新增目录和模板
管理员登录数据决策系统，点击「管理系统>目录管理」，添加目录及模板。
![705-0947.png](https://help.fanruan.com/core/style/lod.png)
#### 2.1.2 修改平台标题
点击「管理系统>外观配置>平台样式」，将平台标题修改为「决策平台」，如下图所示：
![705-0951.png](https://help.fanruan.com/core/style/lod.png)
#### 2.1.3 修改移动平台服务器名称
点击「管理系统>移动平台>APP配置」，设置服务器名称为「移动端」，如下图所示：
![705-0957.png](https://help.fanruan.com/core/style/lod.png)
#### 2.1.4 开启浏览器缓存禁用
注：若未开启「浏览器缓存禁用」，则无法实现管理系统的语言切换。
点击「管理系统>安全管理>安全防护」，开启「Security Headers 」功能。点击「高级设置」，即可开启「浏览器缓存禁用」。如下图所示：
![705-1000.png](https://help.fanruan.com/core/style/lod.png)
### 2.2 新增「键-值」
点击「管理系统>语言配置」，点击「添加」按钮，在「Key」和「英语」的右侧文本框中输入值，如下图所示：
注1：Key 值不可为空，不可重复，至少填写一种语言翻译。
注2：FineBI 工程若之前迁移到 Oracle 、SQL Server，安装插件后如果添加 Key 值保存失败，可尝试下更换驱动版本，Oracle 更新到 ojdbc7 ，SQL Server 更新到 sqljdbc42.jar 。
![705-1003.png](https://help.fanruan.com/core/style/lod.png)
![705-1006.png](https://help.fanruan.com/core/style/lod.png)
「Key」和「英语」的右侧文本框中输入的值如下表所示：
注：若 Key 没有对应的国际化值，切换平台语言后显示 Key 原值；若 Key 存在对应的国际化值，切换平台语言后显示为国际化后的值。
类别  
| Key| 英语  
---|---|---  
目录名称| 测试| Test  
二级目录| Second-level directory  
模板名称| 行程管理| Journey Management  
会议安排| Meeting Arrangement  
平台标题| 决策平台| Decision-making Platform  
移动平台服务器名称| 移动端| Mobile Terminal  
### 2.3 切换语言
点击「简体中文」按钮，在下拉框中选择「English」，即可切换系统语言为英文，如下图所示：
![705-1009.png](https://help.fanruan.com/core/style/lod.png)
### 2.4 效果预览
1）管理系统的语言已切换为英文，且平台标题以英文显示。
2）点击「Directory」，可看到 2.1.1 节添加的目录及模板名称以英文显示，如下图所示：
![705-1010.png](https://help.fanruan.com/core/style/lod.png)
3）使用 [数据分析App](<https://help.fanruan.com/finebi7.0/doc-view-342.html>) 登录决策平台，查看效果如下图所示：
  * 服务器名称以英文「Mobile Terminal」显示
  * 2.1.1 节添加的目录及模板名称以英文显示


![705-1015.gif](https://help.fanruan.com/core/style/lod.png)
## 3\. 功能说明
### 3.1 语言配置
#### 3.1.1 管理「键-值」
管理员身份登录决策平台，点击「管理系统>语言配置」即可进入国际化设置界面。
可在该页面内查看、添加、删除、修改、搜索、批量导入、批量导出、备份、还原备份「键-值」等操作。
注1：不支持搜索「备注」字段。
注2：「清空列表」按钮仅在选中全部 Key 时出现，可勾选「Key」字段实现一键全选。
![705-1017.png](https://help.fanruan.com/core/style/lod.png)
#### 3.1.2 导入内置key
该功能支持批量获取所有系统内置的key，用户可选择直接翻译或导出 EXCEL 翻译后导入系统。
![705-1154.png](https://help.fanruan.com/core/style/lod.png)
#### 3.1.3 批量导入「键-值」  

1）新建一个 Excel 文件作为数据源，Excel 字段名必须满足格式，否则导入失败，Excel 示例表如下图所示：
![705-1021.png](https://help.fanruan.com/core/style/lod.png)
2）在决策平台内点选「导入」，选择数据源，导入成功，如下图所示。
注：导入 Excel 时，2.0.7 之前的版本仅支持 xls 格式，2.0.7 及之后的版本支持 xls、xlsx 格式。
![705-1045.png](https://help.fanruan.com/core/style/lod.png)
![705-1047.png](https://help.fanruan.com/core/style/lod.png)
#### 3.1.4 批量导出「键-值」
在「管理系统>语言配置」页面，点击「导出>导出Excel」，即可批量导出 Excel 文件，如下图所示：
![705-1050.png](https://help.fanruan.com/core/style/lod.png)
#### 3.1.5 备份还原
点击「备份」，出现「备份成功」提示，即可成功备份当前「键-值」。
点击「还原备份」，出现「恢复备份成功」提示，即可成功还原备份的「键-值」，如下图所示：
![705-1052.png](https://help.fanruan.com/core/style/lod.png)
### 3.2 系统偏好语言
管理员登录决策平台，点击「管理系统>语言配置>更多配置」，即可进入系统语言偏好设置，如下图所示：
  * 平台语言偏好：设置后，任意用户登入系统以当前设置语言展示，设置将在重启服务器后生效。
  * 平台支持语种设置：系统支持切换的语言类型。  



注：支持简体中文、繁体中文、英文、日文、韩文。
![705-1058.png](https://help.fanruan.com/core/style/lod.png)
### 3.3 登录页国际化设定
在决策平台登录页面下方，可以选择登录页的语言，预设选项跟随浏览器语言，如下图所示：
注1：如需使用登录页语言切换功能，平台语言偏好需设置为「简体中文」，详情请参考本文 3.2 节。
注2：对于 FineBI 系统，如需使用登录页语言切换功能，在「管理系统>外观配置>登录页>登录风格」中，必须选择「小窗口」风格 。
![708-1637.png](https://help.fanruan.com/core/style/lod.png)
