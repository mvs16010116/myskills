## 1\. 概述
### 1.1 问题现象：
当设计用户添加数据集并进行求中位数/去重计数时，在数据编辑界面下方数据预览界面出现提示「中位数或去重计数计算超出内存阈值，请减少数据量或联系管理员处理」，如下图所示：
![](https://help.fanruan.com/core/style/lod.png)
### 1.2 原因分析：
数据量太大，导致报错。
管理员可以让分析用户通过自身对数据的过滤/分组汇总/减少字段等方式减少数据量，避免该报错。
## 2\. 解决方案
可以通过减少数据量的方法来解决。  

若该数据集用户在后续数据分析时，用不到这么多数据，可提前进行数据处理。在该报错步骤前，通过过滤、删除不必要字段等方式来减少数据量大小，具体操作数据分析用户可查看如下链接：  

  * [过滤](<https://help.fanruan.com/finebi7.0/doc-view-507.html>)
  * [编辑数据概述](<https://help.fanruan.com/finebi7.0/doc-view-506.html>)


数据分析用户在添加上述步骤尝试减少数据量后，可以再次进入该步骤求「中位数/去重计数」来查看是否还有超出内存限制的报错。
