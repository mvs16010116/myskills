## 1\. 概述
### 1.1 版本
FineBI服务器版本  
| 功能变更  
---|---  
6.0| -  
  
### 1.2 功能简介
在 FineBI 进行数据更新后，若出现报错，需要定位原因，可去日志中查看详细信息。
本文将对日志中数据更新和实时数据执行相关的日志关键词做出说明，帮助管理员定位系统问题。
### 1.3 日志路径
日志位置：%FineBI%/logs
日志文件：fanruan.log（或fanruan.log.日期）
## 2\. 抽取数据更新日志说明
执行顺序：更新开始>更新基础表>更新分析表>更新关联>更新表失败>更新结束
注：此处日志说明内容为 info 级别打印。在调整日志级别查看/取出详细日志后，要及时调整日志级别为日常的 ERROR，否则影响使用性能。
**1）更新类型日志关键词**  

**更新类型**| **关键字**  
---|---  
单表更新| Table Load: {}  
文件夹更新| Package Load Table: {}  
全局更新| Global Load Trigger!: {}  
**2）表更新日志关键词**
功能| 子功能  
| 关键字  
  
---|---|---  
更新开始标记| 基础表| Full Load:{}  
基础表增量更新| Increase Load:{}  
自助数据集| analysis Load:{}fast Load:{}  
关联缓存| relation load startrelation load successrelation load fail  
更新表开始执行| table load start  
表执行成功| table load success  
表执行失败| table load fail  
**3）关联更新日志关键词**
更新关联个数：[Group Load] RelationTask Size: {}  

**4）分组任务**更新日志关键词****
**功能**  
| **关键字**  
---|---  
任务开始执行| [Group Load] Start {}  
任务执行失败| [Group Load] Fail {}  
任务执行成功| [Group Load] Success {}
