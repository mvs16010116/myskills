## 1\. 主题保存失败
### 1.1 现象描述
版本：6.1.3/6.1.5
主题保存失败，点「确定」之后反复提示下图弹窗，无法进行任何操作。
若未保存关闭主题，查看「版本管理>特殊存档」，点读取，也无法恢复。
「操作失败」：抱歉，我们无法提交您上一步的更改，请稍后重试。若反复出现，请联系管理员处理。
![](https://help.fanruan.com/core/style/lod.png)
### 1.2 原因分析
主题未保存的操作步骤超过 1000 条。
### 1.3 解决方案
建议一段时间内，及时保存项目；当未保存内容过多，减少编辑数据的操作步骤。
