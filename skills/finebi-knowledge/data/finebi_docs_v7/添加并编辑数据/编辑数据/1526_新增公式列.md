## 1\. 概述
### 1.1 版本
FineBI 版本| 功能变动  
---|---  
7.0| -  
  
### 1.2 应用场景
在不影响原有字段的情况下，使用公式函数对原有字段进行计算获得新的字段。
### 1.3 功能简介
支持使用四则计算和「常用函数、数学和三角函数、日期函数、文本函数、逻辑函数、其他函数」计算。  

![2025-09-22_16-20-19.png](https://help.fanruan.com/core/style/lod.png)
## 2\. 示例一：计算均值
示例数据：[合同事实表.xlsx](<doc-download-/finebi6.X/uploads/file/20230818/合同事实表.xlsx> "下载资料")
已有「合同金额、购买数量」字段，如何求得每个合同的均值呢。  

1）创建分析主题，添加示例数据「合同事实表」，进入数据编辑界面；
2）添加「新增公式列」，两种方式，如下图所示：  

![2025-09-22_16-21-59.png](https://help.fanruan.com/core/style/lod.png)
3）选择「公式/函数」。使用合同金额/购买数量，获得一个新的「均价」字段，字段类型选择「数值」，如下图所示：
注1：默认字段类型为自动，系统根据生成的结果进行字段类型的字段自动判断。
注2：添加的字段需要从左侧选择。
![2025-09-22_16-24-32.png](https://help.fanruan.com/core/style/lod.png)
4）在公式输入框：
  * 用户可以通过输入首字母或首个字搜索字段或函数；
  * 可以从左侧点击添加。如下图所示：  



![2025-09-23_09-54-20.png](https://help.fanruan.com/core/style/lod.png)
5）点击确定，即可在数据预览框看到新增的数据列「均价」，如下图所示：
![2025-09-23_09-57-35.png](https://help.fanruan.com/core/style/lod.png)
## 3\. 示例二：使用 if 函数
除了简单的四则运算，用户也可以通过函数来新增列。
示例背景：例如，合同金额大于 1,000,000 为「大额合同」，否则为「小额合同」。
实现思路：需要用 if 做判断条件，新增一列，输入公式。
操作步骤:
1）创建分析主题，添加示例数据「合同事实表」，进入数据编辑界面。
2）添加新增列。如下图所示：
![1712558088sdWK.png](https://help.fanruan.com/core/style/lod.png)
3）新增列合同大小标注。输入公式：IF(合同金额>1000000,"大合同","小合同")，如下图所示：
![1757657830I9PA.png](https://help.fanruan.com/core/style/lod.png)
4）点击确定后，即可看到对「合同金额大小标注」，如下图所示：
![1757901265YhSc \(1\).png](https://help.fanruan.com/core/style/lod.png)
## 4.修改公式列
如果需要修改「均价」公式列公式，可以进行以下操作：
第一步：点击右侧数据编辑步骤链的「均价」步骤，返回「均价」公式列页面。
第二步：点击新增列公式，进入新增列编辑页面，进行修改。
如下图所示：
![1757901265YhSc.png](https://help.fanruan.com/core/style/lod.png)
