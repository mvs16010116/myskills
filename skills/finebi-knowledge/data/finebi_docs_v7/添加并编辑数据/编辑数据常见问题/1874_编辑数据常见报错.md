## 1\. 自助数据集编辑权限被收回
### 1.1 现象描述
在编辑自助数据集的过程中，出现提示：数据集编辑权限已被收回，不能保存或另存。  

![30.png](https://help.fanruan.com/core/style/lod.png)
### 1.2 原因分析
本自助数据集中使用的基础表的使用权限被收回了，导致用户没有权限编辑该自助数据集。  

### 1.3 解决方案
管理员给该用户分配相应基础表的使用权限。详情清参见：[数据表使用权限](<https://help.fanruan.com/finebi7.0/doc-view-1017.html>)
