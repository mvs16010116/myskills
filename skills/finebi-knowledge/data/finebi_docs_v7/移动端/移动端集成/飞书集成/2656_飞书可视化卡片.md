## 1\. 概述
### 1.1 版本
FineBI 版本| BI飞书插件| 功能变动  
---|---|---  
7.0.4| V7.0.0| -  
### 1.2 应用场景
销售团队需要实时监控每日、每周的销售业绩，包括销售额、新客户数量、客户转化率等关键指标。通过将BI看板中的销售数据填充到飞书的可视化卡片中，销售团队成员可以在飞书首页或相关群组中直接查看实时更新的销售业绩图表。管理者可以快速了解团队整体表现，销售人员可以实时关注自己的业绩进度，及时调整销售策略，确保达成销售目标。
  * 拥有更丰富的可视化效果：以往我们只能推送截图、文件、文本等形式，而互动卡片则可以使用飞书丰富的组件自助搭建。展示效果更好、交互效果更好
  * 触达场景更丰富，以往我们只能通过机器人推送到群/个人消息中，互动卡片可以放入到更丰富的场景


### 1.3 前置条件
  * 安装并完成飞书集成：[**飞书集成**](<https://help.fanruan.com/finebi/doc-view-2067.html>)
  * 安装插件：[**飞书集成插件（bi7）**](<https://market.fanruan.com/plugin/caebf0f2-4be1-4469-bbcf-104221b2a04a>)


## 2\. 飞书集成
安装插件并完成集成，步骤详情请参见：**[](<https://help.fanruan.com/finebi/doc-view-350.html>)[**飞书集成**](<https://help.fanruan.com/finebi/doc-view-2067.html>)**
**可视化卡片需要新增权限、添加机器人。见下文。**
### 2.1 创建应用
1）飞书主管理员 [登录开发者后台](<https://open.feishu.cn/app>)，在「应用开放>钉钉应用」下点击「创建应用」。
![](https://help.fanruan.com/core/style/lod.png)
### 2.2 开通权限
在权限管理下，必须开通以下权限才可实现可视化卡片：
注：如果发布应用后再次勾选其他权限，请再次发布应用，配置才可生效。
  * 获取用户 user ID
  * 获取应用信息
  * 获取通讯录基本信息
  * 获取部门基础信息
  * 获取通讯录部门组织架构信息
  * 获取用户基本信息
  * 获取用户 user ID
  * 获取群组信息
  * 获取与发送单聊、群组消息
  * 获取企业信息
  * 查看、编辑和管理知识库  

  * 查看知识库
  * 搜索员工
  * 查看员工工作邮箱
  * 查看员工手机号  



下面二者权限选其一：  

  * 查看员工个人基本信息
  * 查看员工的姓名


### 2.3 添加机器人
1）进入飞书开发平台找到配置的应用，并添加「机器人」并发布。如下图所示：  

![](https://help.fanruan.com/core/style/lod.png)
2）在群聊中添加应用的机器人。如下图所示：
![](https://help.fanruan.com/core/style/lod.png)
### 2.4 发布应用 
在「版本管理与发布」中，完成企业内部应用的线上发布。
注：非企业管理员创建应用并申请上线，需要企业管理员在管理后台中进行应用审核，详情参见文档：[审核自建应用](<https://open.feishu.cn/document/best-practices/intro-to-custom-app-review>)
![](https://help.fanruan.com/core/style/lod.png)
## 3\. 工程集成到飞书应用
**已经完成飞书集成的可忽略此步骤。**
在「凭证与基础信息」下，就可以获取到 App ID 和 App Secret ；
![](https://help.fanruan.com/core/style/lod.png)
  

管理员在飞书「管理后台」获取「企业编号」。
![](https://help.fanruan.com/core/style/lod.png)
在 FineBI 「[飞书管理](<https://help.fanruan.com/finebi/doc-view-2067.html>)」中成功集成上该应用。（租户ID对应企业编号）
![](https://help.fanruan.com/core/style/lod.png)
在「管理系统>飞书管理>应用快捷配置>飞书群」中，「添加已有群」信息。如下图所示：
  

![](https://help.fanruan.com/core/style/lod.png)
  

## 4\. 飞书卡片配置
1）卡片搭建详情请参见飞书帮助文档：<https://open.feishu.cn/cardkit>
2）完成卡片配置后获取模板 ID 。如下图所示：
![](https://help.fanruan.com/core/style/lod.png)
3）获取可视化卡片的组件变量名称。如下图所示：
![](https://help.fanruan.com/core/style/lod.png)
4）可视化添加机器人。如下图所示：
![](https://help.fanruan.com/core/style/lod.png)
## 5\. 创建飞书可视化卡片调度任务
在 FineBI 的「管理系统>[定时调度](<https://help.fanruan.com/finebi/doc-view-175.html>)>飞书数据回填」中 ，进行回填操作配置。
1）创建定时调度任务，并添加 FineBI 中「合同信息」组件所在仪表板作为调度内容，并配置相关信息。
注：调度信息可根据业务需要自行调整，配图仅作参考。
![2026-04-15_17-00-49.png](https://help.fanruan.com/core/style/lod.png)
2）文件管理选择「飞书可视化卡片」，选择推送应用和推送场域。
注：在选择 FineBI 组件进行匹配时，表格类型目前仅支持分组表组件，暂不支持明细表和交叉表。
将卡片id和图表变量填入对应内容，并和「合同信息」组件匹配。
卡片内容为折线图， x 为横轴分类， y 为纵轴指标， 分类 为图例。如下图所示：
![](https://help.fanruan.com/core/style/lod.png)
