## 1\. 概述
### 1.1 版本
FineBI 版本| fine_conf_entity可视化配置插件| App 版本| HTML5 移动端展现插件  
---|---|---|---  
6.0| V1.9.8| V11.0.68| V11.0.68  
### 1.2 应用场景
移动端支持两种横屏查看模板效果。可使用「fine_conf_entity可视化配置插件」设置切换横屏展示效果。
## 2\. 操作步骤
### 2.1 下载并安装插件
插件安装请参考文档：[FINE_CONF_ENTITY可视化配置](<https://help.fanruan.com/finebi7.0/doc-view-1235.html>)
安装后需要重启服务器才能生效。
### 2.2 设置参数值
1）安装插件后，点击「管理系统>系统工具>选择参数配置」，选择系统参数名「MobileConfig.landscapeLayoutType」，设置系统参数值。完成后点击「保存」。
参数名  
| 描述| 参数值  
---|---|---  
MobileConfig.landscapeLayoutType| 控制移动端重布局横屏状态下的布局类型| 参数值可设置： 0 、1 。默认值为 0 0 ：横屏展示时，一页展示一个组件，通过按钮，左右切换组件1 ：横屏展示时，流式布局。横向充满组件，纵向向下滑动查看仪表板。与竖屏查看方式一致  
![](https://help.fanruan.com/core/style/lod.png)
2）完成后，重启 BI 服务器生效。
### 2.3 效果预览
#### 2.3.1 参数值为0  

若参数值未设置，或设置为「 0 」。横屏展示时，一页展示一个组件，通过按钮，左右切换组件。
![1641372033382689.gif](https://help.fanruan.com/core/style/lod.png)
  

#### 2.3.2 参数值为1
若参数值设置为「 1 」。横屏展示时，横向充满组件，向下滑动查看模板。与竖屏查看方式一致。
![1641372107625524.gif](https://help.fanruan.com/core/style/lod.png)
