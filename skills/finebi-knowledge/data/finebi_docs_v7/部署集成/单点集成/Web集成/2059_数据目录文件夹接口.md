### 功能简介
本文讲解FineBI中「数据目录」下文件夹相关接口。
## 添加文件夹
****
**接口简介**
  
|   
  
---|---  
**接口作用**|  添加文件夹  
**接口URL**|  /v5/api/pack/{groupId}/add  
**请求类型**|  GET  
**注意事项**|  1）使用该接口添加文件夹时，无法指定文件夹的命名，只能添加默认文件夹2）groupId为父文件夹ID  
********
**响应实例**
  
|   
  
---|---  
**请求示例  
**|  http://192.168.101.92:8883/webroot/decision/v5/api/pack/13dd317974a144f886dbaaec51df46c6/add注：使用接口时需要登录，需要传递token参数。
  * 正式工程推荐配置单点登录，否则嵌入式集成后，需要反复登录
  * 测试阶段可通过「Authorization>Bearer Token」输入 token 值

  
**响应成功**|  callback({ "success": true, "code": "200", "message": "success", "data": { "id": "c09f77ee6a964b2787e8967f43152f45", "name": "文件夹", "initTime": 1767749976286, "visible": false, "editable": true, "usable": true, "createBy": "admin", "parentId": "13dd317974a144f886dbaaec51df46c6", "coopAnalysis": false, "creatorAuth": false, "folders": [], "subjects": [], "tables": {}, "indexes": {}, "dimensions": {}, "businessModels": {} }, "errorCode": null, "detailErrorMsg": null, "errorMsg": null})  
**截图示意**| ![2026-01-07_09-42-01.png](https://help.fanruan.com/core/style/lod.png)  
**响应参数说明**
参数  
| 参数值说明  
---|---  
id| 创建的文件夹ID  
name| 创建的文件夹名称  
initTime| 创建文件夹的时间  
editable| 是否可编辑true：是  
false：否  
createBy| 文件夹创建者用户名  
parentID| 文件夹所在父文件夹ID  
coopAnalysis| 是否协作给当前用户true：是  
false：否  
creatorAuth  
| 是否拥有和创建者相等的权限true：是  
false：否  
## 重命名文件夹
**接口简介**
  
|   
  
---|---  
**接口作用**|  重命名文件夹  
**接口URL**|  /v5/api/pack/{packId}/rename  
**请求类型**|  GET  
**注意事项**|  packId为文件夹ID  
********
**请求参数-**Query** 参数**
参数名  
| 参数值| 是否必填  
---|---|---  
newName| 业务包新名称| 是  
****
**响应实例**  

  
|   
  
---|---  
**请求示例  
**|  http://192.168.101.92:8883/webroot/decision/v5/api/pack/13dd317974a144f886dbaaec51df46c6/rename?newName=银行金融业注：使用接口时需要登录，需要传递token参数。
  * 正式工程推荐配置单点登录，否则嵌入式集成后，需要反复登录
  * 测试阶段可通过「Authorization>Bearer Token」输入 token 值

  
**响应成功**|  callback({ "success": true, "code": "200", "message": "success", "data": [], "errorCode": null, "detailErrorMsg": null, "errorMsg": null})  
**截图示意**| ![](https://help.fanruan.com/core/style/lod.png)  
## 删除文件夹
**接口简介**
  
|   
  
---|---  
**接口作用**|  删除文件夹  
**接口URL**|  /v5/api/pack/delete  
**请求类型**|  POST  
**请求参数-body参数**
body| 是否必填| 描述说明  
---|---|---  
{"packIds":["文件夹ID"]}| 是| packIds为待删除的文件夹ID

|
