## 仪表板导出Excel
**接口简介**
  
|   
  
---|---  
**接口作用**|  仪表板导出Excel  
**接口URL**|  /v5/api/dashboard/report/export/excel  
**请求类型**|  GET  
**请求参数-**Query** 参数**
参数名  
| 参数值| 是否必填  
---|---|---  
reportId| 仪表板ID| 是  
widgetId| 仪表板中组件ID注意，此ID需要通过F12获取reportWidgetId| 否  
**响应实例**
  
|   
  
---|---  
**请求示例  
**|  http://192.168.101.92:8883/webroot/decision/v5/api/dashboard/report/export/excel?reportId=6aae904df9284bef823921fac05fb247&widgetId=b46db5b52d723110注：使用接口时需要登录，需要传递token参数。
  * 正式工程推荐配置单点登录，否则嵌入式集成后，需要反复登录
  * 测试阶段可通过「Authorization>Bearer Token」输入 token 值

  
**响应成功**|  在浏览器端访问，可直接下载对应Excel  
**截图示意**|  请求：![2026-01-07_14-36-07.png](https://help.fanruan.com/core/style/lod.png)响应：![2026-01-08_14-19-53.png](https://help.fanruan.com/core/style/lod.png)
