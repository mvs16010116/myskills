## 新建仪表板
**接口简介**
  
|   
  
---|---  
**接口作用**|  新建仪表板  
**接口URL**|  /v5/api/platform/dashboard/reports  
**请求类型**|  GET  
******请求参数-**Query** 参数**
参数名  
| 参数值| 是否必填| 描述说明  
---|---|---|---  
data| {"subjectId":"主题ID","reportName":"仪表板名称"}注：参数值格式为JSON，使用时需要进行编码 encodeURIComponent()  
| 是| 1）subjectId：仪表板所在主题ID选中主题后，URL中subject后面的ID即为主题ID2）reportName：仪表板名称  
**响应实例**
  
|   
  
---|---  
**请求示例  
**| **编码前参数值：**{"subjectId":"44cec6b1637c4cb79333410507a50bd5","reportName":"示例仪表板"}**编码后参数值：** %7B%22subjectId%22:%2244cec6b1637c4cb79333410507a50bd5%22,%22reportName%22:%22%E7%A4%BA%E4%BE%8B%E4%BB%AA%E8%A1%A8%E6%9D%BF%22%7D**链接：** http://192.168.101.92:8883/webroot/decision/v5/api/platform/dashboard/reports?data=%7B%22subjectId%22:%2244cec6b1637c4cb79333410507a50bd5%22,%22reportName%22:%22%E7%A4%BA%E4%BE%8B%E4%BB%AA%E8%A1%A8%E6%9D%BF%22%7D注：使用接口时需要登录，需要传递token参数。
  * 正式工程推荐配置单点登录，否则嵌入式集成后，需要反复登录
  * 测试阶段可通过「Authorization>Bearer Token」输入 token 值

  
**响应成功**|  callback({ "success": true, "code": "200", "message": "success", "data": { "name": "示例仪表板", "initTime": 0, "lastUpdateTime": 0, "id": "d46d49e0c80f474d9f744e23b5b5c44b", "shared": false, "publishStatus": 0, "editable": true, "publicLink": { "type": 0, "shared": false, "passProtected": false, "deadline": 0, "exportable": false }, "coopAnalysis": false, "creatorAuth": false }, "errorCode": null, "detailErrorMsg": null, "errorMsg": null})  
**截图示意**  
| ![2026-01-07_11-48-04.png](https://help.fanruan.com/core/style/lod.png)  
**响应参数说明**
参数  
| 参数值说明  
---|---  
name| 仪表板名称  
initTime| 创建时间  
lastUpdateTime| 最近修改时间  
id| 仪表板ID  
shared| 是否分享true：是  
false：否  
publicStatus| 发布状态0：未发布  
1：已发布  
editable| 是否可编辑true：是  
false：否  
publicLink| 公共链接  
coopAnalysis| 是否协作给当前用户true：是  
false：否  
creatorAuth  
| 是否拥有和创建者相等的权限true：是  
false：否  
## 删除仪表板
**接口简介**
  
|   
  
---|---  
**接口作用**|  删除仪表板  
**接口URL**|  /v5/api/platform/dashboard/report  
**请求类型**|  GET  
******请求参数-**Query** 参数**
参数名  
| 参数值| 是否必填  
---|---|---  
reportId| 待删除的仪表板ID| 是  
**响应实例**
  
|   
  
---|---  
**请求示例  
**|  http://192.168.101.92:8883/webroot/decision/v5/api/platform/dashboard/report?reportId=d46d49e0c80f474d9f744e23b5b5c44b注：使用接口时需要登录，需要传递token参数。

  * 测试阶段可通过「Authorization>Bearer Token」输入 token 值

  
**响应成功**|  callback({ "success": true, "code": "200", "message": "success", "data": [], "errorCode": null, "detailErrorMsg": null, "errorMsg": null})

## 重命名仪表板
**接口简介**
  
|   
  
---|---  
**接口作用**|  重命名仪表板  
**接口URL**|  /v5/api/platform/dashboard/rename  
**请求类型**|  GET  
******请求参数-**Query** 参数**
参数名  
| 参数值| 是否必填| 描述说明  
---|---|---|---  
info| { "reportId":"仪表板id", "nameUpdateBean": { "name": "仪表板新名称", "mouduleType": "1/2" }}注：参数值格式为JSON，使用时需要进行编码 encodeURIComponent()| 是| 1）reportID：仪表板ID2）name：仪表板新名称3）mouduleType：模块类别（1：公共数据，2：我的分析）
