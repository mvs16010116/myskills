## 添加数据集-DB表
**接口简介**
  
|   
  
---|---  
**接口作用**|  添加DB表  
**接口URL**|  /v5/api/table/add  
**请求类型**|  POST  
******请求参数-**Body** 参数**
参数| 是否必填| 参数值  
---|---|---  
{ "type":1, "connectionName":"BI Demo", "tableName":"客户跟踪表", "name":"BIDemo_客户跟踪表", "parentId": "6fb11e7b1e6e4ff3bcb907a5747527b0", "initTime":0, "engineType":"spider" "comment":""}| 是| 1）type：表类型为1，代表DB表2）connectionName：数据连接名称3）tableName：数据库中的表名称4）name：添加的数据集名称（建议使用“数据连接_数据库中的表名”这样的形式，作为唯一标识符）5）parentId：数据集所在文件夹ID6）initTime：初始化时间7）engineType：引擎类型（direct：直连数据；spider：抽取数据）8）comment：备注信息，选填  
**响应实例**  

  
|   
  
---|---  
**请求链接  
**|  http://192.168.101.92:8883/webroot/decision/v5/api/table/add注：使用接口时需要登录，需要传递token参数。
  * 正式工程推荐配置单点登录，否则嵌入式集成后，需要反复登录
  * 测试阶段可通过「Authorization>Bearer Token」输入 token 值

  
**请求Body**| { "type":1, "connectionName":"BI Demo", "tableName":"客户跟踪表", "name":"BIDemo_客户跟踪表", "parentId": "13dd317974a144f886dbaaec51df46c6", "initTime":0, "engineType":"spider"}  
**响应成功**|  callback({ "success": true, "code": "200", "message": "success", "data": { "name": "61a3170bff084f25ac40e57354d8c795", "transferName": "BIDemo_客户跟踪表", "success": true }, "errorCode": null, "detailErrorMsg": null, "errorMsg": null})
