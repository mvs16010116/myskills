本文讲解FineBI中仪表板编辑相关接口。
## 分享仪表板给其他用户
**接口简介**
  
|   
  
---|---  
**接口作用**|  通过调用该接口，用户可以将仪表板分享给指定用户  
**接口URL**|  /v5/api/dashboard/share/user/result  
**请求类型**|  GET  
**请求参数-**Query** 参数**
参数名  
| 参数值| 是否必填| 描述说明  
---|---|---|---  
entityId| 仪表板ID| 是| 多个仪表板，可用「,」隔开  
全部仪表板，值为空即可  
userId| 用户ID| 是| 多个用户，可用「,」隔开  
全部用户，值为空即可  
**响应实例**
  
|   
  
---|---  
**请求示例  
**|  http://192.168.101.92:8883/webroot/decision/v5/api/dashboard/share/user/result?entityId=d76fdf3cfb1446aaa450d4668eb18196,b9947708a22e4c58a175019f07e443af&userId=621beb84-59b7-412c-b2f3-78a7b7aeab1a,9ffcfece-80d7-49b2-ac3e-d1f1224bb808注：使用接口时需要登录，需要传递token参数。
  * 正式工程推荐配置单点登录，否则嵌入式集成后，需要反复登录
  * 测试阶段可通过「Authorization>Bearer Token」输入 token 值

  
**响应成功**|  callback({ "data": "success"})  
**截图示意**| ![2026-01-07_15-12-21.png](https://help.fanruan.com/core/style/lod.png)

## 仪表板分享给哪些用户
**接口简介**
  
|   
  
---|---  
**接口作用**|  获取该仪表板分享给了哪些用户  
**接口URL**|  /v5/api/dashboard/share/user  
**请求类型**|  GET  
**请求参数-**Query** 参数**
参数名  
| 参数值| 是否必填  
---|---|---  
entityId| 仪表板ID| 是  
page| 页码| 是  
count| 每页数量| 是  
keyword| 关键字| 否  
**响应实例**
  
|   
  
---|---  
**请求示例  
**|  http://192.168.101.92:8883/webroot/decision/v5/api/dashboard/share/user?entityId=08c5c0be7d6e4dc2ba763e0102e45876&page=1&count=2注：使用接口时需要登录，需要传递token参数。
  * 正式工程推荐配置单点登录，否则嵌入式集成后，需要反复登录
  * 测试阶段可通过「Authorization>Bearer Token」输入 token 值
