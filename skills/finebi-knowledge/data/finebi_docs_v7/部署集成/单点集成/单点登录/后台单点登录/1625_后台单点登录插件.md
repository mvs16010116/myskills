### 1.2 功能简介
当企业已有 OA 系统、统一门户或其他内部平台，希望用户在这些系统中点击链接即可直接进入 FineReport 报表，无需再次登录。
后台单点登录（SSO，Single Sign-On）的核心思路是：由第三方系统（如 OA、门户等）构造一个携带身份信息的特殊 URL，用户点击后直接访问 FineBI，FineBI 从 URL 参数中提取并验证身份信息，验证通过后自动完成登录，无需用户手动输入账号密码。
安装「后台单点登录插件」后，即可实现后台单点登录，无需编写复杂代码，操作简单。插件提供以下两种后台单点登录方案：
  
| 方案一：用户名不加密| 方案二：用户名加密（推荐）  
---|---|---  
说明  
| 直接将用户名拼接至 URL 参数中| 对用户名进行 RSA 加密后拼接至 URL 参数中，安全性更高；支持 ssoToken 超时设置，开启后，sso Token 将在达到「系统管理>登录>登录超时时间」后过期  
访问示例  
| http://ip:端口号/工程名/decision?fine_username=用户名| http://ip:port/工程名/decision?ssoToken=xxx（对用户名加密并转码后得到的结果）  
特点| 简单易用，但用户名明文暴露在 URL 中，安全性较低，适合内网或安全要求不高的场景| 用户名经过 RSA 加密，URL 中不暴露明文，安全性高，推荐在生产环境使用

## 2\. 插件介绍
### 2.1 插件下载
后台单点登录插件下载请点击：[后台单点登录插件](<https://market.fanruan.com/plugin/cadcae90-0b19-4c2f-851a-1fbee21b7221>)
插件安装方法请参见：[插件安装](<https://help.fanruan.com/finebi7.0/doc-view-459.html>)
注：1.2.1之前版本的「SAML 单点登录」插件与「后台单点登录」插件因底层使用相同 Filter 而存在天然冲突，不支持同时启动，否则重启工程后可能导致登录功能异常。
1.2.1及之后版本的「SAML 单点登录」已实现与「后台单点登录」插件兼容，可同时启用。
### 2.2 页面介绍
插件安装后，超管进入平台，点击「管理系统>系统管理」，出现集成后台单点登录页面。如下图所示：  

注：只有超管可见配置页面。
![](https://help.fanruan.com/core/style/lod.png)
## 3\. 方案一：用户名不加密

## 4\. 方案二：用户名加密
注：该方案不再支持访问http://ip:端口号/工程名/decision?fine_username=用户名实现后台单点登录，支持的访问路径请参见本文 4.5 节。
「后台单点登录插件」支持使用 RSA Key 对用户名加密来提高安全性。
### 4.1 生成 RSA Key
插件安装后，Public Key 自动生成。如下图所示：
![](https://help.fanruan.com/core/style/lod.png)
需注意以下几点：
  * 只支持生成默认的 key ，不支持自定义。
  * 生成 Public Key 后，点击「生成 RSA Key」，可重新生成且覆盖之前的 Key 。
  * 生成的 key 只支持 aes 传输加密，安装 base64 插件无效，也不支持国密。  



### 4.2 用户名加密
将生成的 RSA KEY 和用户名放到用户自己的加密代码中，对用户名进行加密。
1）此处用 [加密网站](<http://tool.chacuo.net/cryptrsapubkey>) 进行加密，实际用户建议使用自己加密代码进行加密。
2）如果开启了 4.6 节的「ssoToken超时设置」功能，加密时要用「用户名+当前毫秒时间戳」，具体可参见：[后台单点登录RSA示例代码](<https://help.fanruan.com/finebi7.0/doc-view-1703.html>)。
3）加密步骤如下图所示：
![1635151776855207.png](https://help.fanruan.com/core/style/lod.png)
### 4.3 用户名解密
将加密后的用户名，输入到「解密测试」中，若能成功解密出用户名，代表加解密的流程是正确的。如下图所示：  

![](https://help.fanruan.com/core/style/lod.png)
### 4.4 用户名转码
加密后的用户名需要转码才能嵌入 URL 中，用户可使用encodeURIComponent对加密用户名进行转码。
本文示例使用 [转码网站](<https://tool.oschina.net/encode?type=4>) 进行转码，如下图所示：
![21.png](https://help.fanruan.com/core/style/lod.png)
### 4.5 效果查看
浏览器访问链接：http://ip:port/工程名/decision?ssoToken=xxx（编码后的结果），实现用户名加密的后台单点登录。如下图所示：
![](https://help.fanruan.com/core/style/lod.png)
### 4.6 ssoToken 超时设置
ssoToken 超时设置功能默认不开启，开启后，ssoToken 将在达到「系统管理>登录> [登录超时时间](<https://help.fanruan.com/finebi7.0/doc-view-742.html#fe17addcd41ed9b3>) 」后过期。
如果使用过期的 ssoToken 单点登录 FineBI 系统，将报错：登录超时，请重新登录。如下图所示：
注：如果开启了「ssoToken超时设置」功能，4.2节加密时要用「用户名+当前毫秒时间戳」，具体可参见：[后台单点登录RSA示例代码](<https://help.fanruan.com/finebi7.0/doc-view-1703.html>)。
![1641366727537903.png](https://help.fanruan.com/core/style/lod.png)
## 5\. 注意事项
本文第四节中 ssoToken 的生成需要用户手动进行加密，在实际应用中，可使用代码自动生成 ssoToken，详情请参见：[后台单点登录RSA示例代码](<https://help.fanruan.com/finebi7.0/doc-view-1703.html>)
