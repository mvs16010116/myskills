## 1\. 概述
### 1.1 版本
FineBI服务器版本  
  
---  
7.0  
  
### 1.2 功能简介
本地机器信息认证操作简单，十分方便。
用户通过导出 rif 文件，获取 mac 地址和机器码，来生成一个唯一标识的 license 文件。
### 1.3 注意事项
1）本地机器信息认证，需要 FineBI 工程所在服务器的物理信息固定。如不固定，不适合使用该注册方法。
例如要 FineBI 工程部署在虚拟机环境下，虚拟机环境下物理信息可能变化，造成注册失败，请选取其他注册方式。
2）一个正式 license 文件在一台机器上只能注册一次，若需要在同一台机器上注册多个工程，则需要购买多个 license 。
3）一个正式 license 文件只适用于一台服务器，如需更换服务器，需要进行注册迁移。  

4）同一服务器下跨大版本升级（6.0 升级7.0）后，需要进行注册迁移。
5）请确保工程使用 JDK 1.8 且小版本需在 JDK8u200 以上。
6）Mac 地址不允许设置为空，不允许不限。因为正式 license 文件强制校验 Mac 地址，为空则一定会注册失败。
## 2\. 注册步骤
### 2.1 确认工程名
管理员登录运维平台，在「[开发者模式](<https://help.fanruan.com/fineops/doc-view-202.html>)」下，通过「变更访问路径」，即可查看FineBI的工程名，默认为webroot。
用户可在注册前根据自身需要修改工程名，注册后将无法修改。 
注：此工程名的修改可能会影响模板的超链等设置，请谨慎修改。
修改后，访问工程的地址就变成了http://IP:端口/工程名/decision
![](https://help.fanruan.com/core/style/lod.png)
### 2.2 导出工程ID信息（7.0.3~7.0.8版本必做）
**7.0.3~7.0.8版本 FineBI 工程需完成此操作，其他版本请跳过。**
1）管理员登录 FineBI 系统，点击「管理系统>注册管理」。
2）在「工程信息>应用工程ID」后，点击「导出ID」按钮。
3）导出的文件名为「appID.rif」，该文件中存储了工程的ID信息。
![](https://help.fanruan.com/core/style/lod.png)
### 2.3 导出工程注册信息
1）管理员登录 FineBI 系统，点击「管理系统>注册管理」。
2）在「注册信息>版本注册」后，点击「立即注册」/「重新注册」按钮。
3）认证方式选择「本地机器信息认证」，点击「导出注册信息」/「导出集群注册信息」。
4）导出的文件名为「RegistrationInformation.rif」，该文件中存储了工程的版本和机器信息。7.0.9 及之后版本，该文件还包含工程的唯一 ID 信息。
![](https://help.fanruan.com/core/style/lod.png)
### 2.4 获取授权文件

注1：若有任何特殊情况，请在邮件中注明。
注2：临时注册建议直接通过「[帆软软件-临时授权自助导航](<https://t6ixa9nyl6.jiandaoyun.com/dash/66eb98cb25d61f04a2fb0bf8>)」入口申请。

**2）确认 license 文件名**
收到商务返回的 license 文件后，请先根据文件名确认是否符合你的注册需求。
license 文件命名规则：FanRuan_产品名版本号_认证类型_授权类型_生成日期.lic
示例：FanRuan_FR11.5&BI6.1_LocalMachine_Offical_20250106.lic
信息项  
| 说明  
---|---  
产品名| 
  * FR：FineReport
  * BI：FineBI
  * FDL：FineDataLink
  * Dora：Data Agent  


如 license 文件注册了多个产品，则使用&拼接  
版本号| 大版本号
  * FineBI：7.0、6.1
  * FineReport：11.0、11.5
  * FineDataLink：4.2、4.0
  * Dora：无版本号

  
认证类型| 
  * LocalMachine：本地机器信息认证
  * LocalContainer ：本地容器认证

  
授权类型| 
  * OfficalL：正式授权
  * Temp：临时授权

  
生成日期| 授权文件的生成日期。例如20260616  
### 2.5 上传 lic 文件
1）以管理员身份登录 FineBI 系统，依次点击「管理系统>注册管理>立即注册」。
2）认证方式选择「本地机器信息认证」，点击「上传lic文件」，选择商务发送的 license 文件上传。
![](https://help.fanruan.com/core/style/lod.png)
3）上传成功后，页面显示「注册成功」，即完成授权注册。
  * license 文件存储在文件服务器的 resources 文件夹中。


![](https://help.fanruan.com/core/style/lod.png)
## 3\. 取消注册
1）进入 FineBI 文件服务器中，在/WEB-INF/resources目录下，删除「FanRuan.lic」文件
注：请注意文件服务器类型是否支持后端删除等传输细节（例如minio等S3类型，必须通过浏览器登录前端访问）
![](https://help.fanruan.com/core/style/lod.png)
2）使用运维平台的「[组件管理](<https://help.fanruan.com/fineops/doc-view-44.html>)」功能，重启 FineBI 应用节点，取消注册成功。
![](https://help.fanruan.com/core/style/lod.png)
## 4\. 注册失败
### 4.1 现象描述
若注册失败，页面将出现提示弹窗，如下图所示：
  

![](https://help.fanruan.com/core/style/lod.png)
### 4.2 失败原因
点击详细信息即可查看注册失败的原因，根据具体失败原因进行排查。
失败原因  
| 具体提示  
  
---|---  
证书已过期| 过期时间：2019-02-22  
版本不匹配| 认证应用版本：9.0本地应用版本：10.0  
MAC 地址不匹配| 认证 MAC 地址：xxx本地 MAC 地址：xxx  
机器码不匹配| 认证机器码：xxx本地机器码：xxx  
应用名不匹配| 认证应用名：xxx本地应用名：xxx  
已达可授权数量上限| 证书已被同服务器上其他工程使用  
工程内容不匹配| 认证工程内容：xxx本地工程内容：xx  
注：除上述外失败原因外，其他统一报错：证书内容不正确。
有多个失败原因时，平台中会全部显示出来。
