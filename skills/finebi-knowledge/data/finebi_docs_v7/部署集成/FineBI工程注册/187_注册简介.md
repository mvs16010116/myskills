## 1\. 概述
### 1.1 版本
FineBI服务器版本  
| 功能变更  
---|---  
7.0| -  
### 1.2 功能变更
帆软免费提供 [FineBI 软件](<https://www.finebi.com/product/download>) ，用户可使用该软件进行功能测试和试用。  

  * 直接下载的 FineBI 软件包含了所有功能，但是限制了并发数，使用部分功能时会存在试用信息标志。
  * 用户可联系帆软商务，根据自己的需求购买功能点并注册。注册了的功能点可以使用，未购买的功能点无法使用。


### 1.3 注册方式推荐
FineBI 7.0 仅推荐以下两种注册方式，请根据网络环境选择合适的注册方式。  

**注：其他注册方式，不适合运维平台部署的 FineBI7.0 项目。如有需要请联系帆软技术支持。**  

  * 本地机器信息认证：不适合运维平台部署的项目，FineBI服务器的物理信息必须固定
  * 加密锁认证：不适合运维平台部署的项目，仅面向传统部署的项目
  * 容器私有云认证：是下文运维平台注册方法的变体，需要用户手动部署docker环境下的授权服务组件，难度极高
  * 本地容器认证：是下文运维平台注册方法的变体，更换授权工程需要联系商务，不方便

网络环境| 注册方式| 简介  
---|---|---  
外网，或可与帆软云注册服务器连通的内网| [在线注册](<https://help.fanruan.com/finebi7.0/doc-view-917.html>)| 帆软搭建了一个公有云认证服务器，客户通过填写认证信息发起授权请求，发送至帆软认证服务器，统一验证授权。**优点：** 1）FineBI 工程所在服务器的物理信息可变化2）无需自行准备授权服务器3）允许使用单个账号为多个 FineBI 节点/项目进行注册（申请时需注明最大可认证节点数量）4）更换授权工程时，用户无需联系商务，可自行操作迁移**缺点：** 1）BI 服务器必须能连通帆软云端授权服务器  
内网| [运维平台注册新项目](<https://help.fanruan.com/fineops/doc-view-108.html>)  
| 通过运维平台在FineBI项目中部署一个授权组件，通过手机扫码完成纯内网注册**优点：** 1）FineBI 工程所在服务器的物理信息可变化2）FineBI 工程所在服务器无需开通外网访问，支持纯内网3）允许使用单个账号为多个 FineBI 节点/项目进行注册（申请时需注明最大可认证节点数量，且授权组件与项目内网互通）4）更换授权工程时，用户无需联系商务，可自行操作迁移（此处仅指迁移工程，但不迁移授权组件）**缺点：** 1）需要提供一定服务器资源，用于在FineBI项目中部署授权组件（无需手动部署，可通过运维平台界面化部署）2）授权组件不可关闭，关闭后需要重启进行注册（无需联系商务，只需要自行扫码认证即可）  
## 2\. 查看是否注册
管理员登录FineBI系统，点击「管理系统>注册管理」，如果 FineBI 没有注册，在查看注册信息时，会显示「未注册」**。** 如下图所示：
![](https://help.fanruan.com/core/style/lod.png)
## 3\. 未注册的影响
### 3.1 版权信息
如果 FineBI 未注册或者注册许可已经过期，用户通过 IP 或域名访问 FineBI，就会在模板底部显示版权信息：上BI选帆软，专注BI十七年，Powered by 帆软 试用模式。
如下图所示：
![](https://help.fanruan.com/core/style/lod.png)
### 3.2 并发数
并发数指的是允许同时访问报表服务器的接入数量，详情请参见：[注册并发原理](<https://help.fanruan.com/finereport/doc-view-276.html>)
未注册的并发数固定为 2 。如下图所示：
![](https://help.fanruan.com/core/style/lod.png)
如正在访问服务器的并发数已达到最高并发数，后登录的用户将无法访问。
注：公共链接访问模板，占用并发数，关闭页面后释放占用。
### 3.3 Web 应用服务器
未注册版本 Web 应用服务器每七天会暂停运行，仪表板无法正常访问，此时需要重启 Web 应用服务器如 Tomcat 。
如果您的项目正在进行中，上述未注册出现的暂停运行问题可能会对项目产生比较大的影响，甚至于出现不必要的损失。  

因此，我们建议您购买 FineBI 软件，注册后再使用。
### 3.4 注册提醒
如果 FineBI 未注册或者注册许可已经过期，用户通过 IP 或域名访问模板或数据分析，每天弹出一次注册提醒，如下图所示：
注：用户通过 localhost 或 127.0.0.1 访问模板或数据分析，未注册时不会显示注册提醒。
超管：  

![](https://help.fanruan.com/core/style/lod.png)
普通用户：
![](https://help.fanruan.com/core/style/lod.png)
### 3.5 功能无法使用
工程未注册时，「回收站」和「协作」功能无法使用。
详情请参见：[回收站](<https://help.fanruan.com/finebi/doc-view-1953.html>)、[协作](<https://help.fanruan.com/finebi/doc-view-1895.html>)
