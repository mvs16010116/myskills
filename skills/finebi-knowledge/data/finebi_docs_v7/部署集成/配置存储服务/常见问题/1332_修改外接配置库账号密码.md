## 1\. 概述
系统配置了外接数据库后，工程每次启动时都需要连接外接数据库。
如果直接修改外接数据库的账号密码，工程则无法成功连接外接库，导致启动失败。
本文将简单介绍正确修改外接数据库账号密码的方法，以及错误修改后的解决方案。  

## 2\. 修改方法
本文提供两种正确修改外接数据库账号密码的方法。
### 2.1 方法一：无需迁移
注：本方案默认仅对单机工程生效。
集群环境下需要把其他节点关闭，只启动一个节点进行密码修改。
修改成功后，把 db.properties 文件复制到没修改的节点，然后关闭集群所有节点再启动。
注2：在进行密码修改之前，为避免失败，请务必对原工程进行备份后再进行后续操作。
请参考 [工程备份还原方案](<https://help.fanruan.com/finebi7.0/doc-view-2224.html>) 4.1节，对工程进行备份。
1）启动工程，管理员登录数据决策系统，点击「管理系统>系统管理>常规>外接数据库>已配置」，如下图所示：
![](https://help.fanruan.com/core/style/lod.png)
2）确保打开了「外接数据库配置」页面。
![](https://help.fanruan.com/core/style/lod.png)
3）此时可以去修改数据库的用户名密码。
![](https://help.fanruan.com/core/style/lod.png)
4）在「外接数据库配置」页面，填入新用户名和密码，切勿勾选「迁移数据至要启用的数据库」，点击「启用新数据库」，启用成功即可。
![](https://help.fanruan.com/core/style/lod.png)
### 2.1 方法二：临时迁移
注：在进行密码修改之前，为避免失败，请务必对原工程进行备份后再进行后续操作。
请参考 [工程备份还原方案](<https://help.fanruan.com/finebi7.0/doc-view-2224.html>) 4.1节，对工程进行备份。
1）准备一个临时数据库，数据库内容为空，与需要修改账号密码的外接数据库无关联即可。  

2）按照文档，将外接数据库迁移至新的数据库。迁移时必须勾选「迁移数据至要启用的数据库」。
数据库类型| 迁移方法  
  
---|---  
MySQL5RDS MySQL| [配置MySQL5外接数据库](<https://help.fanruan.com/finebi7.0/doc-view-1248.html#9>)  
  
MySQL8  
| [配置MySQL8外接数据库](<https://help.fanruan.com/finebi7.0/doc-view-1249.html#9>)  
  
SQL Server| [配置SQL Server外接数据库](<https://help.fanruan.com/finebi7.0/doc-view-1251.html#9>)  
  
Oracle| [配置Oracle外接数据库](<https://help.fanruan.com/finebi7.0/doc-view-1250.html>)  
  
DB2| [配置DB2外接数据库](<https://help.fanruan.com/finebi7.0/doc-view-1252.html#9>)  
  
PostgreSQL| [配置PostgreSQL外接数据库](<https://help.fanruan.com/finebi7.0/doc-view-1260.html#7>)  
  
3）此时可以去修改原外接数据库的用户名密码。
![](https://help.fanruan.com/core/style/lod.png)
4）修改完成后再次按照步骤 2，将外接数据库迁移回原数据库。迁移时必须勾选「迁移数据至要启用的数据库」。
## 3\. 解决方法
若未按照第二章进行操作，外接数据库的账号密码已被修改。
工程启动时失败，自动跳转到服务器部署向导页面，提示「数据库连接异常，外接数据库连接失败」，如下图所示：
本章将简单介绍出现该情况时的解决方法。
![](https://help.fanruan.com/core/style/lod.png)
### 3.1 方法一：回退账号密码
1）联系数据库管理员，将外接数据库的账号密码回退。
2）工程正常启动后，按照第二章的方法修改外界数据库的账号密码。
### 3.2 方法二：服务器部署向导
在服务器部署向导页面，重新配置外接数据库信息。
![](https://help.fanruan.com/core/style/lod.png)
