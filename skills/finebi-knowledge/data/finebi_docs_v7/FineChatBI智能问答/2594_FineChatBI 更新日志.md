### 新增指标属性设置
为避免指标累加结果无业务参考性的错误，在指标属性中将指标被划分为三类：可累加指标、半累加指标、不可累加指标。  

  * 可累加指标：可在所有维度求和，比如销售额；
  * 半累加指标：可在部分维度求和，但通常不按时间维度求和，比如库存数量；
  * 不可累加指标：任意维度下的累加均无业务参考性，比如利润率。


详情请参见：[指标属性](<https://help.fanruan.com/finebi/doc-view-2575.html#9be310d7ba1ed046>)。
![](https://help.fanruan.com/core/style/lod.png)

详情请参见：[FineChatBI 使用权限配置](<https://help.fanruan.com/finebi/doc-view-2590.html>)。

### 新增业务规则
详情请参见：[配置业务规则](<https://help.fanruan.com/finebi/doc-view-2713.html#0054c8bc07c2edf7>)
新增业务规则配置，可用来定义企业业务逻辑、数据筛选、主题匹配等规则，确保问数据得到的分析结果符合业务规范。
例如希望提问销售额时，系统可以自动过滤出今年的数据。那么可以就设定业务规则“如果问题中没有指定明确日期，那么默认查询今年的数据”。
![](https://help.fanruan.com/core/style/lod.png)  

### 新增数据结论
详情请参见：[数据结论](<https://help.fanruan.com/finebi/doc-view-2714.html>)
开启数据结论功能后，系统可基于查询出来的图表数据，在生成图表的同时也生成易懂的业务结论与分析结果，同时满足精准查数和深度分析计算。
![](https://help.fanruan.com/core/style/lod.png)
若 FineChatBI 查询的图表需进一步运算才能获得结论，则会启动 code agent 代码能力进行二次计算，提升 FineChatBI 处理复杂问题的能力，并输出最终结论。
比如提问：6月份的销售额比3月份高的城市是多少：
1）系统先查询 “2024 年 3 月各城市销售额”“2024 年 6 月各城市销售额” 的基础数据并生成对应图表；
2）系统编写代码进行二次计算，对每个城市的 “6 月销售额 - 3 月销售额” 做差值计算，筛选出差值 > 0 的城市；
![](https://help.fanruan.com/core/style/lod.png)

### 支持使用表达式查询
支持+、-、*、/和()操作符，可对指标名进行运算，运算时遵循正常优先级规则。
支持场景  
| 问法示例  
---|---  
复杂表达式查询| 支持+、-、*、/和()操作符，可对指标名进行运算，运算时遵循正常优先级规则，例如：
  * 销售额/成本额
  * 成本额+利润额
  * 销售额-成本额
  * （成本额+销售额）/数量

注1：指标名数量不超过 5 个，可重复注2：不支持聚合字段和非聚合字段一起参与表达式计算注3：不支持在问句中自定义指标，比如说 上海市销售额+北京市销售额

  * 若系统仅匹配到标签内一个分析主题的数据，会直接基于该主题给出答案。
  * 若问题涉及标签内多个分析主题的数据，系统会展示相关分析主题供用户选择。当用户选择「确定，是这个数据」 后，后续再提出此问题，系统将自动切换并匹配该主题，无需重复选择。


**标签内自动切换主题**
若用户提问的问题关联的分析主题与当前使用的分析主题不同，系统会依据提问问题，智能识别并自动切换至对应的分析主题。

### 指标运算单位适配
两个指标计算（如相减）时，系统会自动匹配最合理的单位：
  * 指标计算得到具体数值后，自动匹配最合适的单位：比如 10000 会显示为 1万，200 则显示为 200。


数据格式统一：
  * 千分位：只要参与计算的指标有千分位（如 1,000），结果自动带千分位（如 5,000）；
  * 小数位：取参与计算指标的 最大小数位数 展示（例：指标 1 存 3 位小数、指标 2 存 1 位，结果显 3 位）；
  * 百分比：计算结果中忽略百分比格式，专注数值本身。
