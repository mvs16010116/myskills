## 1\. 概述
![icon](https://help.fanruan.com/core/style/lod.png)该功能处于内测阶段，暂不提供技术支持服务。  

企业微信可创建「资产检索机器人」，方便企业成员在企业微信中快速检索 FineBI 仪表板。
![](https://help.fanruan.com/core/style/lod.png)
## 2\. 创建资产检索机器人
### 2.1 FineBI 创建 IM 机器人
1）进入「管理系统>智能问答配置」，点击「IM 机器人配置」页面，在企业微信下点击「新增机器人」，如下图所示：  

![](https://help.fanruan.com/core/style/lod.png)
2）填写机器人配置信息，点击确定。如下图所示：
![](https://help.fanruan.com/core/style/lod.png)
配置项  
| 填写说明  
---|---  
机器人名称| 自定义命名(例：FineBI 资产检索助手)  
机器人类型| 选择「资产检索机器人」  
BotID| 暂不填写，待企业微信机器人创建完成后补充  
Token| 用于验证信息来源的令牌，是企业微信与 FineBI 服务的对接密钥。建议使用复杂字符串（例：maXwN）并记录，后期需使用。  
EncodingAESKey  
| 是企业微信与 FineBI 服务间消息加密的密钥，用于保障传输内容安全。需使用 43 位字母数字组合（例：Jr3jzw9gU7mKBkdtefvfn2dY9UpdCN5TpRQHjS2AcXg）并记录，后续需使用。  
用户匹配方式| 
  * 用户名匹配：

适用于企业微信账号与 FineBI 平台账号完全一致的情况。
  * 正则表达式匹配

当企业微信账号与 FineBI 平台账号命名规则不同，但存在可提取的规律时使用。您可以通过配置正则表达式，从企业微信账号中提取出对应 FineBI 账号的部分。示例：若企业微信用户名为 ABC_xyz，而 FineBI 用户名为 ABC，则可配置正则表达式为 ^[^_]+，意为“匹配第一个下划线前的所有字符”。如下图所示：![](https://help.fanruan.com/core/style/lod.png)  
3）创建完成后效果如下，之后企业微信配置时需使用下图红色区域的内容。
![](https://help.fanruan.com/core/style/lod.png)
### 2.2 企业微信后台创建机器人
**需拥有企业微信管理员权限才可完成本节操作。**  

1）点击头像，进入企业微信的「管理企业」页面，如下图所示：  

![](https://help.fanruan.com/core/style/lod.png)
2）在「安全与管理>管理工具」页面，找到智能机器人，如下图所示：  

![](https://help.fanruan.com/core/style/lod.png)
3）在创建账号最下方，切换至「API模式创建」，如下图所示：
![](https://help.fanruan.com/core/style/lod.png)
4）输入机器人的配置信息，如下图所示：
![](https://help.fanruan.com/core/style/lod.png)
配置项  
| 填写说明  
---|---  
名称  
| 自定义机器人名称  
简介| 自定义机器人简介  
可见范围| 根据企业需求自定义设置  
URL| URL 配置：按「域名 + 端口号 + 接口路径 + ID」格式拼接
  * 域名：配置的域名其备案主体需与当前企业主体相同或有关联关系，通常可直接使用 FineBI 系统的访问地址作为该域名。
  * 端口号：填写 FineBI 的 BI 服务端口号（例：8080）。
  * 接口路径：固定填写「webroot/decision/v1/ai/chat/dashboard/api/wx/asset/retrieval」。
  * ID：使用 2.1 节操作完成后生成的 ID。

完整示例：https://www.chatbixxx.com:8080/webroot/decision/v1/ai/chat/dashboard/api/wx/asset/retrieval/630c648f199f6sc1/。  
Token| 填写 2.1 节的 Token  
EncodingAESKey| 填写 2.1 节的 EncodingAESKey  
5）创建完成即可查看配置详情，复制 BotID，如下图所示：
![](https://help.fanruan.com/core/style/lod.png)
6）回到 FineBI「IM机器人配置」页面，编辑机器人，补全 BotID 配置项。如下图所示：
![](https://help.fanruan.com/core/style/lod.png)
### 2.3 在企业微信使用机器人
在通讯录中找到创建的机器人，可以直接对它发消息，也可以添加到群聊后@它进行提问。
![](https://help.fanruan.com/core/style/lod.png)
