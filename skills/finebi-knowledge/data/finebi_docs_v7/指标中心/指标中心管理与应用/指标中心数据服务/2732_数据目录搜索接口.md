## 2\. 接口信息
**接口简介**
  
|   
  
---|---  
**接口作用**|  获取用户想要的资源  
**接口URL**|  /api/dc/{version}/indicator/search  
**请求类型**|  POST  
**请求参数**
Path 参数
参数名  
| 类型| 参数值| 是否必填  
---|---|---|---  
version| string| 接口版本号示例：v1| 是  
Body 参数
参数名  
| 子参数名| 类型| 参数值| 是否必填  
---|---|---|---|---  
keyword| -| string| 搜索关键词| 是  
packageId| -| string| 文件夹id支持在文件夹下搜索，缺省时表示全局搜索| 否  
queryId| -| string| 搜索id| 否  
pageIndex| -| integer| 分页页码| 是  
pageSize| -| integer| 分页数据量| 是  
force| -| boolean| true 则不纠错| 是  
privilege| -| enum<string>| 权限
  * view：元数据权限
  * use：使用权限

| 是  
filter| -| object(过滤 req) | 过滤条件| 否  
filter| itemTypes| array [anyOf]| 类型枚举值:
  * 3：表
  * 65：指标
  * 66：维度
  * 67：业务模型
  * 49：文件夹

| 否  
tableTypes| array[integer]| 表类型枚举值:
  * 2：sql表
  * 3：excel表
  * 4：自助数据集
  * 5：服务器数据集
  * 9：etl数据集

| 否  
tags| array[string]| 标签 id| 否  
fields| array[string]| 字段名| 否  
creators| array[string]| 创建者 id| 否  
initTime| object| 创建时间
  * startTime（integer，必填）
  * endTime（integer，必填）

| 否  
extensionProperties| -| array [object]| 扩展字段| 否  
  
extensionProperties| id| string| 扩展字段id| 是  
filterValue| array[string]| 扩展字段值| 是

**响应参数说明**
参数| 参数值  
---|---  
keyword| 搜索关键词  
highlight| 高亮词  
items| 搜索结果集  
count| 总数  
pageCount| 分页数据量  
pageIndex| 分页页码  
type| [搜索类型](<https://help.fanruan.com/finebi/doc-view-2467.html>)区分普通搜索、高级搜索、AI搜索枚举值:
  1. 普通搜索
  2. 增强搜索
  3. AI搜索

  
correct（增强搜索）| 是否纠错  
correctWord| 纠错之后的搜索关键词  
更多详情返回响应的参数详情请参见：[API服务-搜索](<https://s.apifox.cn/15f4d658-e6ef-41f2-b6aa-fbfca0c74048/386165578e0>)
