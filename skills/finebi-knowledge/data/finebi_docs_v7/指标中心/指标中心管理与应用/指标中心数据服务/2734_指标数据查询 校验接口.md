## 2\. 数据查询
**接口简介**
  
|   
  
---|---  
**接口作用**|  对维度/指标进行数据结果查询或进行数据校验。指标/维度支持配置维度、指标、过滤、排序、分页信息后进行数据查询。其中，日期维度支持设置分组方式，明细指标支持选择汇总方式  
**接口URL**|  /api/dc/{version}/indicator/query/data  
**请求类型**|  POST  
**请求参数**
Path 参数
参数名  
| 类型| 参数值| 是否必填  
---|---|---|---  
version| string| 接口版本号示例：v1| 是  
Body 参数
参数名  
| 类型| 参数值| 是否必填  
---|---|---|---  
dimensions| array[string]| 使用的维度| 是  
metrics| array[string]| 使用的指标| 是  
source| object | 用到的所有指标维度map| 是  
fieldId| string| 指标/维度id| 是  
resourceType| integer | 类型| 是  
summary| object| (分组汇总)汇总聚合指标不支持再汇总**简单类型：**
  * type（integer ）

3：求和4：最大值5：最小值6：平均数7：中位数8：标准差9：方差10：去重计数11：计数  
**百分位：**
  * type（ enum<integer>）固定值:27
  * paras（array[string]）枚举值:


  * 0.05
  * 0.1
  * 0.25
  * 0.5
  * 0.75
  * 0.9
  * 0.95

| 是  
group| object| (分组汇总)分组目前支持日期分组  

  * type（ enum<integer>）枚举值:


  * 12：周数，一年中第几周
  * 9：周几
  * 8：月份
  * 6：年份
  * 5：年月日
  * 10：每月第几天
  * 13：时
  * 14：分
  * 15：秒
  * 7：季度
  * 48：月日
  * 17：年月
  * 16：年季度年+第几季度
  * 18：年周数年+第几周周数
  * 19：年月日时
  * 20：年月日时分
  * 21：年月日时分秒

| 是  
type| integer| 数据类型枚举值:
  * 16：文本
  * 32：数值
  * 48：日期

| 是  
name| string| 名称| 是  
format| object| 数值格式化支持缺省；BI7.0.8之后支持  

  * formatDecimal<integer> 保留几位小数，默认2位
  * numSeparators<boolean> 是否需要数字用逗号分隔，默认false

| 否  
filters| array[object]| 过滤条件| 是  
orders| array[string]| 排序的字段| 是  
limit| object | 分页信息| 是  
pageSize| string| 分页数据量| 是  
pageIndex| string| 分页页码| 是  
rowCount| string| 总数据量  
| 是  
engineType| string| 引擎类型| 是
