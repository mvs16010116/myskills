## 2\. 查看指标属性
**接口简介**
  
|   
  
---|---  
**接口作用**|  查看指标属性  
**接口URL**|  /api/dc/{version}/indicator/metric/{metricId}/info  
**请求类型**|  GET  
**权限**|  元数据权限  
**请求参数**
Path 参数
参数名  
| 类型| 参数值| 是否必填  
---|---|---|---  
version| string| 接口版本号示例：v1| 是  
metricId| string| 指标id示例：c99a001e-edbd-4ead-acbe-ef762d4b7990| 是  
**响应实例**
  
|   
  
---|---  
**请求示例  
**|  http://secure.finedevelop.com:63702/webroot/decision/api/dc/v1/indicator/metric/c99a001e-edbd-4ead-acbe-ef762d4b7990/info  
**响应成功**|  查看对应指标的指标属性信息![](https://help.fanruan.com/core/style/lod.png)  
**截图示意**| ![](https://help.fanruan.com/core/style/lod.png)  
**响应参数说明**
参数| 参数值  
---|---  
id| 指标/维度id  
pId| 父文件夹id  
approver| 审批者
  * userld：用户id
  * displayName：用户显示名
  * userName：用户

  
creator| 创建者用户显示名  
createTime| 创建时间  
editTime| 编辑时间  
type| 数据类型
  * 16：文本
  * 32：数值
  * 48：时间

  
tags| 标签
  * id：标签id
  * name：标签名
  * description：标签描述

  
extensionProperties| 扩展字段type：扩展字段类型枚举值:
  * 16：字符串
  * 32：数值
  * 48：文本
  * 64：单选
  * 65：多选
  * 80：用户单选
  * 81：用户多选

required：是否启用value：扩展字段值  
validStatus| 标红状态枚举值:
  * VALID：正常  

  * INVALID：标红

  
caliber| 计算口径
  * id：指标/维度id
  * name：指标/维度名
  * formula：公式
  * fields：公式所用字段
  * type：公式类型；固定值：1

  
更多详情返回响应的参数详情请参见：[API服务-指标属性](<https://s.apifox.cn/15f4d658-e6ef-41f2-b6aa-fbfca0c74048/386176755e0>)
## 3\. 查看指标血缘
**接口简介**
  
|   
  
---|---  
**接口作用**|  查看指标血缘  
**接口URL**|  /api/dc/{version}/indicator/metric/{metricId}/consanguinity  
**请求类型**|  GET  
**权限**|  元数据权限  
**请求参数**
Path 参数
参数名  
| 类型| 参数值| 是否必填  
---|---|---|---  
version| string| 接口版本号示例：v1| 是  
metricId| string| 指标id示例：c99a001e-edbd-4ead-acbe-ef762d4b7990| 是  
**响应实例**
  
|   
  
---|---  
**请求示例  
**|  http://secure.finedevelop.com:63702/webroot/decision/api/dc/v1/indicator/metric/c99a001e-edbd-4ead-acbe-ef762d4b7990/consanguinity  
**响应成功**|  返回指标的血缘信息![](https://help.fanruan.com/core/style/lod.png)  
**截图示意**| ![](https://help.fanruan.com/core/style/lod.png)  
**响应参数说明**
  

参数| 参数值  
---|---  
nodeInfo| 所有节点属性
  * id：节点id  

  * showName：id名称
  * engineType：引擎类型
  * status：状态
  * publishstatus：发布状态
  * consanguinityLevel：血缘层级
  * consanguinityOverlimit：血缘层级是否超限
  * idparentld：父文件夹
  * manageable：管理权限
  * usable：使用权限
  * viewable：元数据权限 
  * knots：下游节点数
  * moduleType：数据目录/我的分析
  * resourceType：资源类型
  * tableType：表类型

  
parentEdges|  父节点展示指标的血缘视图中父节点的上下游节点id  
childEdges| 子节点展示指标的血缘视图中子节点的上下游节点id
