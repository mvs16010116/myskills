## 2\. 我的分析
### 2.1 新增分析主题类型
本次更新对「分析主题」进行了类型拆分。原有分析主题统一调整为「自助分析主题」，并新增「标准分析主题」，以适配不同的数据分析场景。
  * 「自助分析主题」延续原有分析主题能力，适合业务人员进行灵活的数据探索，支持数据清洗、过滤、多表合并、上传 Excel 以及复杂函数计算等操作。
  * 「标准分析主题」面向高性能直连分析场景，适合直接使用数仓中已治理好的高质量数据表。该类型仅支持直连数据，不支持上传 Excel，不提供编辑数据能力，也不支持 DEF 类函数、WINDOW 窗口函数和引用函数，以减少不必要的数据加工链路，提升查询与分析性能。


此次调整后，用户在新建分析主题时可根据业务需求选择合适的主题类型，实现灵活探索与高性能分析的分场景管理。
参考文档：[FineBI 分析主题简介](<https://help.fanruan.com/finebi/doc-view-2769.html>)
![2026-05-20_14-36-21.png](https://help.fanruan.com/core/style/lod.png)
### 2.2 新增 LOD 函数
标准分析主题中新增 LOD 函数能力，用于弥补该主题类型下不支持 DEF 类函数、WINDOW 窗口函数和引用函数的能力差异。
LOD 函数仅支持在「标准分析主题」中使用，适用于直连数据场景下的灵活聚合计算。用户可通过 [FIXED](<https://help.fanruan.com/finebi/doc-view-2770.html>)、[INCLUDE](<https://help.fanruan.com/finebi/doc-view-2772.html>)、[EXCLUDE](<https://help.fanruan.com/finebi/doc-view-2771.html>) 等函数，按指定分析粒度完成数据汇总与计算，在保持标准分析主题高性能直连能力的同时，满足常见的跨维度分析和明细聚合需求。
## 3\. 指标中心
### 3.1 物化命中场景优化
更新前：仅支持较简单聚合场景的物化加速。
更新后：扩展了物化可命中场景，支持更多可视化复杂指标/维度、指标条件和日期分组的分析查询命中物化结果，提升直连分析性能。
详情请参见：[物化加速](<https://help.fanruan.com/finebi/doc-view-2746.html>)
