## 3\. 指标中心
### 3.1 新增指标中心
FineBI7.0 指标中心以降低数据使用门槛为核心目标，提供统一数据模型、指标加工、指标管理与指标应用的全链路解决方案，实现数据「可管理、可置信、可消费」的闭环，为 FineChatBI 提供强大的语义层支撑。
  * 查看用户：全局口径统一，提供指标资产的快速检索链路。
  * 分析用户：打破数据应用壁垒，业务人员高效利用数据。
  * IT 用户：构建基于指标血缘的可复用数据消费底座。


![1710923494MGCf.png](https://help.fanruan.com/core/style/lod.png)
新增「指标管理」、「维度管理」、「指标集管理」，关联视图界面移入指标中心，并重命名为「模型管理」。指标中心详情请查看：[指标中心简介](<https://help.fanruan.com/finebi7.0/doc-view-2646.html>)
![1710923494MGCf.png](https://help.fanruan.com/core/style/lod.png)
指标发布：从「指标中心」制作好的指标，支持发布，或者做成「指标集」发布到「数据目录」中，给用户在进行分析时使用。
![1754291939892615.gif](https://help.fanruan.com/core/style/lod.png)
新增「[加速管理](<https://help.fanruan.com/finebi7.0/doc-view-2633.html>)」，对于抽取模式下指标中心添加的关联支持配置加速，通过预计算的方式优化关联查询性能体验。  

![1710923494MGCf.png](https://help.fanruan.com/core/style/lod.png)

## 6\. 数据目录
「公共数据」升级为「数据目录」通过数据目录统一管理资产并支持精准检索，结合申请审批、数据详情及BI无缝对接，实现指标从可见、可申、可信、可用的业务自助化闭环，确保数据合规流通与高效分析。
  * **智能搜索** ：覆盖资产名称、标签、字段等属性的多维度模糊匹配，叠加「类型+标签+权限」组合过滤，按匹配度＞使用热度＞更新时效三级动态排序，关键结果优先展示。
  * **血缘追溯** ：血缘展现实现双向穿透（前溯原始数据集，后追看板/报表/派生指标），血缘过滤支持多维度精准定位（按上下游/权限/状态等），确保数据流转全链路透明可控。
  * **视图定制** ：自由勾选展示列（描述/标签/类型等），不同角色聚焦关键信息。

## 7\. 我的分析
### ——数据——
### 7.1 新增动态引用函数
新增动态引用函数：[ADD_DIM(引用维度+指定维度)](<https://help.fanruan.com/finebi7.0/doc-view-2623.html>) 、[SUB_DIM(引用维度-指定维度)](<https://help.fanruan.com/finebi7.0/doc-view-2624.html>)、[FIELD_IN(判断数组是否属于)](<https://help.fanruan.com/finebi7.0/doc-view-2638.html>)
#### 场景1：动态指标实现不同场景重复使用
例如月累计销售额场景中，不同角色和分析需求关注的维度不同，需要依据不同的分析需求调整维度，查看月累计销售额。
角色/场景| 分析需求| 维度  
---|---|---  
cfo  
| 分析地区月累计销售额| 省份、城市  
进货预测| 分析商品月累计销售额| 大类、产品名称  
WINDOW 的分组维度没法动态的随着用户在分析区的调整保持始终正确的逻辑，维度在省份、城市和大类、产品名称间切换时，需更改计算字段。
运用 SUB_DIM 函数后，无需调整计算字段，只需更换维度，即可查看相应的月累计销售额。
![1710923494MGCf.png](https://help.fanruan.com/core/style/lod.png)
**实现思路：**
[WINDOW_SUM](<https://help.fanruan.com/finebi7.0/doc-view-2477.html>) 配合 [SUB_DIM](<https://help.fanruan.com/finebi7.0/doc-view-2624.html>) 实现组内行间计算，用「一份数据模型」适应不同维度的月累计销售额展示需求
**月累计销售额动态字段** = WINDOW_SUM(SUM_AGG(销售额),[SUB_DIM(签约时间)],[签约时间],["first",0]) 
**详情请参见文档：**[**配合 WINDOW 实现组内行间计算**](<https://help.fanruan.com/finebi7.0/doc-view-2624.html#66f08e3390383ae6>)
#### 场景2：不同层级的指标计算规则不同
用户角色| 分析需求| 关注指标  
---|---|---  
CFO/财务总监/部门经理| 查看公司各区域、部门的人力成本情况| 公司成本   
= 员工薪资及福利 + 办公场地租赁 + 设备折旧等  
人力资源分析师| 查看每员工的个人成本，分析个人效益比| 个人成本  
= 员工个人的薪资及福利  
  
如何在企业用「一份数据模型」适应不同分析层级的成本展示需求，无需切换数据源或计算字段。查看从公司到个人层级的成本情况？
![1710923494MGCf.png](https://help.fanruan.com/core/style/lod.png)
**实现思路：**
配合 [FIELD_IN()](<https://help.fanruan.com/finebi7.0/doc-view-2638.html>) 函数动态的判断计算视图是否引入了某维度。如果有「员工姓名」维度，则函数计算中使用「个人成本」，不然则使用「公司成本」。
**成本额= IF(FIELD_IN(ADD_DIM(), [员工姓名]), 个人成本, 公司成本)**
**详情请参见文档：**[**动态层级维度成本分析**](<https://help.fanruan.com/finebi7.0/doc-view-2643.html>)
#### 场景3：自定义合计行计算逻辑
和场景 2 的实现方式与公式相同，因为合计方式为「自动」所以计算时未使用「门店名称」，因此配合 [FIELD_IN()](<https://help.fanruan.com/finebi7.0/doc-view-2638.html>) 动态判断计算视图是否有门店名称，实现依据维度计算与合计行的计算方式不同。
![1710923494MGCf.png](https://help.fanruan.com/core/style/lod.png)
**详情请参见文档：**[**自定义合计行计算规则**](<https://help.fanruan.com/finebi7.0/doc-view-2649.html>)
### 7.2 EARLIER函数优化
EARLIER 函数字段列支持数组，可配合 [SUB_DIM](<https://help.fanruan.com/finebi7.0/doc-view-2624.html>) 使用。
例如：  

[DEF](<https://help.fanruan.com/finebi7.0/doc-view-1987.html?source=4>)+[EARLIER](<https://help.fanruan.com/finebi7.0/doc-view-1991.html?source=4>) 配合 [SUB_DIM](<https://help.fanruan.com/finebi7.0/doc-view-2624.html>) 实现组内行间计算，用「一份数据模型」适应不同维度的月累计销售额展示需求。
**月累计销售额动态字段** =DEF_ADD(SUM_AGG(销售额),[],[EARLIER(SUB_DIM(月))=SUB_DIM(月),月份<=EARLIER(月份)])
**详情请参见文档：**[**配合DEF+EARLIER实现组内行间计算**](<https://help.fanruan.com/finebi7.0/doc-view-2624.html#6cc944b97b5e7b41>)
### 7.3 指标中心支持跨表明细计算
FineBI7.0 版本「跨表明细计算」提升跨表明细计算能力，行级别的跨表运算不会被报错阻止“非聚合计算不支持跨表”，满足更多计算场景。详情请参见文档：[跨表明细计算场景](<https://help.fanruan.com/finebi/doc-view-2607.html>)  

以下列举一些跨表明细计算场景：
  * 产品维度表（单价）*销售表（销售数量）求销售额
  * 对指标进行跨表的明细或条件的过滤
  * 计算衍生指标，比如求销售额，过滤条件为「年=2022」或「商品类型=“A”」
