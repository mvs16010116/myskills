## 2\. 指标中心对接 BI 自助分析能力增强
### 2.1 支持跨指标集分析
FineBI7.0.5 及之后的版本，支持跨指标集分析。对于有关联的指标集内字段，可按照实际关联，进行跨指标集分析。用户无需再制作包含大量字段的指标集，可依据明确的业务主题进行精细化分类，方便用户查找并管理指标。
注：时间衍生指标、defsub类需要匹配字段的场景，只能找到当前指标集下的字段匹配，无法匹配到其他指标集的字段。
![](https://help.fanruan.com/core/style/lod.png)
详情请参见文档：[主题内指标分析流程](<https://help.fanruan.com/finebi/doc-view-2704.html>)
### 2.2 数据中心指标支持指标条件
7.0.5 版本及之后的 FineBI 「指标中心」发布的指标支持在组件中设置「指标条件」完成对指标的过滤。实现业务对「指标集」的灵活探索。
![](https://help.fanruan.com/core/style/lod.png)
部分场景下的指标依旧不支持指标条件：
  * 组件添加的计算字段
  * 常量指标
  * 使用 WINDOW/RANK_AGG/DEF 相关分析函数计算的指标
  * 指标配置了聚合过滤条件/衍生方式


详情请参见：[「指标中心」发布的指标支持添加指标条件](<https://help.fanruan.com/finebi/doc-view-2424.html#3e76c1174955c257>)
### 2.3 转成表相关性提示优化
转成表的字段增加相关性提示。区分指标、维度，无关联的指标/维度将出现提示，支撑用户使用数据编辑完成二次数据加工分析。
若分组字段之间在「模型管理」有关联，任意分组字段可以分析任何汇总字段。若拖入的分组字段与部分汇总字段不相关，则出现下方提示：
![](https://help.fanruan.com/core/style/lod.png)
详情请参见：[转成表](<https://help.fanruan.com/finebi/doc-view-2652.html>)
### 2.4 指标集支持复制到
7.0.5 在跨主题取数调用时，支持将主题内使用的「指标集」复制到其他主题内，方便「指标集」相关数据和看板的复用场景。详情请参见：[跨主题取数调用](<https://help.fanruan.com/finebi/doc-view-2100.html>)  

### 2.5 指标保存优化
「模型管理」中的数据表关联字段删除，将保持关联关系并标红字段。

### 3.2 支持使用复杂表达式查询
支持+、-、*、/和()操作符，可对指标名进行运算，运算时遵循正常优先级规则。
支持场景  
| 问法示例  
---|---  
复杂表达式查询| 支持+、-、*、/和()操作符，可对指标名进行运算，运算时遵循正常优先级规则，例如：
  * 销售额/成本额
  * 成本额+利润额
  * 销售额-成本额
  * （成本额+销售额）/数量

注1：指标名数量不超过 5 个，可重复注2：不支持聚合字段和非聚合字段一起参与表达式计算注3：不支持在问句中自定义指标，比如说 上海市销售额+北京市销售额  
### 3.3 找报表权限补齐
找报表相关权限补齐，详情请参见：[FineChatBI 使用权限配置](<https://help.fanruan.com/finebi/doc-view-2590.html>)。
### 3.4 找报表-数据抄录（beta版）
数据抄录支持用户在目录仪表板中，选中目标组件后，快速抄录组件内的数据信息。可将抄录结果以文字形式直接复制，便于嵌入各类文档；也可下载为 PDF 文件，和另存为分析文档。
详情请参见：[数据抄录](<https://help.fanruan.com/finebi6.X/doc-view-2687.html>)
![](https://help.fanruan.com/core/style/lod.png)
### 3.5 找报表-分析报告（beta版）
系统可以对仪表板进行智能化摘要总结与自动报告输出，无需人工手动整理，可自动生成结构化分析报告，快速提炼核心数据结论，提升数据复盘与业务汇报效率。
详情请参见：[分析报告](<https://help.fanruan.com/finebi6.X/doc-view-2686.html>)
![](https://help.fanruan.com/core/style/lod.png)

仪表板问答功能支持用户通过自然语言查询，快速检索并定位相关仪表板资产，自动呈现相关可视化内容和文字结论。
详情请参见：[仪表板问答](<https://help.fanruan.com/finebi/doc-view-2671.html>)

### 3.8 TOPN 提问场景拓展
此次版本开始适配以下两种提问场景：  

场景  
| 提问  
  
---|---  
维度过滤+TOPN| 
  * 江苏省山东省陕西省山西省中销售额前3的省份？
  * 城市包含州的城市哪个城市的销售额最高  

  * 客户不为空的客户，哪些客户销售额前三

  
定基同环比+TOPN  
| 
  * 本月销售额环比最高的门店编码
  * 本月门店编码不为空的销售额环比最低的门店编码

  
### 3.9 图表展示效果优化
对分析主题提问时，图表效果有以下变更：  

  * 在返回的图表下方新增「数据更新时间」，方便用户判断数据时效性（本次更新表格暂无此效果）。  

  * 对提问返回的图表样式效果进行调优，例如折线图调整了线宽、连线样式等。


![](https://help.fanruan.com/core/style/lod.png)
### 3.10 重命名字段使用逻辑调整
对字段重命名后（例如将「商品名称」重命名为「物品名称」），V3.31.0 及后续版本会直接弃用原字段名，输入原名不再匹配，字段 hover 也不显示原名，让分析主题里的字段名更纯粹统一，更高效清晰做数据分析。
![](https://help.fanruan.com/core/style/lod.png)
