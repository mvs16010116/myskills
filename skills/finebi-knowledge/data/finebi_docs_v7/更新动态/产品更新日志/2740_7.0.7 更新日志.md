## 3\. 数据目录
### 3.1 数据目录开放指标接口
企业的大量指标集中到指标平台并得到统一管理后，指标平台要与企业生产环境内的各类应用系统，包括BI工具、经营分析平台、业务应用系统、IM产品等进行对接。因此，FineBI 7.0.7 提供 API 接口方便对发布到「**数据目录** 」的指标/维度等数据资源进行查看调用。
如何配置认证方式以及获取 Secret Key 请参见文档：[数据目录接口](<https://help.fanruan.com/finebi/doc-view-2720.html>)

### 5.2 思维链输出速度提升
更快获取数据答案，思维链输出速度提升。
![](https://help.fanruan.com/core/style/lod.png)
### 5.3 移动端新增停止停止按钮
移动端的归因分析和数据解读新增了停止生成按钮，方便用户中断提问。
![](https://help.fanruan.com/core/style/lod.png)
### 5.4 新增偏好记忆
支持在 PC 及移动端实现前端偏好记忆，不需要每次进来后重新设置：  

  * 模式选择：记住用户选的「极速/智能」模式；
  * 界面操作：保存「数据概览/历史会话」的收起状态；
  * 分析模式选择：记住「指标维度/分析主题」的选择状态。


### 5.5 新增指标属性设置
为避免指标累加结果无业务参考性的错误，在指标属性中将指标被划分为三类：可累加指标、半累加指标、不可累加指标。  

  * 可累加指标：可在所有维度求和，比如销售额；
  * 半累加指标：可在部分维度求和，但通常不按时间维度求和，比如库存数量；
  * 不可累加指标：任意维度下的累加均无业务参考性，比如利润率。


详情请参见：[指标属性](<https://help.fanruan.com/finebi/doc-view-2575.html#9be310d7ba1ed046>)
![](https://help.fanruan.com/core/style/lod.png)
### 5.6 权限优化
智能问答功能权限独立
在旧版本中，只能对「智能问答」进行整体授权。在新版本中进行了优化，支持对「问数据」「找报表」进行独立的权限配置。
详情请参见：[FineChatBI 使用权限配置](<https://help.fanruan.com/finebi/doc-view-2590.html>)。
![](https://help.fanruan.com/core/style/lod.png)
指标维度权限适配
此前版本中，次级管理员无法对指标维度的「预加载配置、知识配置、推荐问题」进行配置，本版本开始适配。
### 5.7 移动端新增历史问答
移动端支持查看历史问答记录。
详情请参见：[移动端使用手册](<https://help.fanruan.com/finebi/doc-view-2582.html>)。
![](https://help.fanruan.com/core/style/lod.png)
### 5.8 新增思维链条
针对旧版本中回答过程不透明问题，本次上线的思维链条会清晰展示的完整分析步骤，帮用户获取可信分析成果。
详情请参见：[问数据](<https://help.fanruan.com/finebi/doc-view-2580.html>)
![](https://help.fanruan.com/core/style/lod.png)  

### 5.9 报错代码及提示语优化
新增常见错误代码汇总，涵盖 「不支持的功能、使用错误、异常信息、系统提示」 四大类场景，方便用户快速定位错误原因、获取解决方案。
详情请参见：[FineChatBI 错误代码汇总](<https://help.fanruan.com/finebi/doc-view-2725.html>)
