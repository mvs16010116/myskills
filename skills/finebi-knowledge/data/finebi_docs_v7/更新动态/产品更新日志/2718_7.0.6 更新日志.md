## 3\. 指标中心
### 3.1 新增半累加指标
半累加指标是解决「**部分维度不需要聚合，仅取特定值（最大 / 最小），其他维度正常汇总** 」的可视化配置功能。
不用写复杂函数，通过指标可视化配置就能实现快照类数据的统计，替代原来需要手动编写 def 函数的高难度操作。
详情请参见文档：[半累加指标](<https://help.fanruan.com/finebi/doc-view-2716.html>)
![](https://help.fanruan.com/core/style/lod.png)
示例| 场景| 可视化配置  
---|---|---  
账户余额统计| 按账户取「最后一次流水时间」的余额，再按「网点/支行」汇总| 
  * 不可累加维度 = 时间
  * 窗口分组 = 账户
  * 取值 = 最大值

  
库存数量统计| 按库房、品类取「最后一次记录时间」的库存，再按地区汇总| 
  * 不可累加维度 = 时间
  * 窗口分组 = 库房 + 品类
  * 取值 = 最大值

  
考试成绩统计| 考生同一科目多次考试，取「最高/最低分」作为最终成绩| 
  * 不可累加维度 = 考试次数
  * 窗口分组 = 考生 + 科目
  * 取值 = 最大值 / 最小值

### 3.5 图表相关性检测规则
![](https://help.fanruan.com/core/style/lod.png)
**字段相关性定义**
维度之间都有连线，所有维度能分析任意指标。
**字段在 FineBI 中如何判断维度和指标**
看在待分析区是维度还是指标，默认的原始字段「文本/时间=维度 ；数值=指标；（数值维度=维度）」 后续字段转指标 /转维度也会改变其属性。
**待分析区相关性提示显示条件**
校验分析区「所有横纵轴+图形属性」中的字段与「待分析区」字段是否具有相关性。
**查询合法性校验规则** ： 
7.0.6 版本及以上优化处理思路：**按目前图表的查询方式，拆分成多个分组表查询合法性。任一一个查询单元不合法，整体图表查询报错**
  * 单元拆分规则：


  * 按照横纵轴上的每一个指标拆分成一个单元，包括：横纵轴上所有的维度+ 该横纵轴的指标+ 该指标上配置的图形属性上的全部字段
  * 如果横纵轴指标单元中的维度都相同，那么合并成一个校验单元
  * 如果横纵轴没有指标时，整体图形属性视为一个单元


### 3.6 指标中心功能点优化
  * 「指标中心」功能点不再控制「创建关联」功能。未购买「指标中心」功能点，也可在「数据目录」中使用「关联视图」功能，用于创建关联关系  

  * 「指标中心」功能点不再控制「数据搜索」功能。未购买「指标中心」功能点，也可在「数据目录」中进行基础搜索，但无法进行增强搜索  

  * 新增「标签与扩展字段」功能点，控制「标签管理」和「扩展字段」相关功能  

  * 新增「权限申请审批」功能点，控制「元数据」和「权限审批」相关功能


详情请参见：[注册管理-指标中心](<https://help.fanruan.com/finebi/doc-view-177.html#ce2c4fe8104e06ee>)  

## 4\. AI问答
### 4.1 业务用语优化
详情请参见：[配置业务用语](<https://help.fanruan.com/finebi/doc-view-2713.html#d711d8a5344dbc70>)
系统无法识别业务人员提问中的企业内部独有业务用语时，可使用「业务用语」建立独有用语与系统标准表述的对应匹配。
例如：给系统标准表述「员工内部唯一识别码」添加业务用语「内编」。提问“李四的内编”系统即可精准匹配并正确回应。
  * 业务用语交互页面重构。业务用语配置此前需在「同义词配置」模块操作，V3.34.0 版本将其整合至「知识配置 > 业务用语」模块。


![](https://help.fanruan.com/core/style/lod.png)
  * 新增「业务域 / 全局」按钮，在 V 3.34.0 及之后的版本，管理员可实现配置的业务用语全局生效。


![](https://help.fanruan.com/core/style/lod.png)
### 4.2 新增业务规则
详情请参见：[配置业务规则](<https://help.fanruan.com/finebi/doc-view-2713.html#0054c8bc07c2edf7>)
新增业务规则配置，可用来定义企业业务逻辑、数据筛选、主题匹配等规则，确保问数据得到的分析结果符合业务规范。
例如希望提问销售额时，系统可以自动过滤出今年的数据。那么可以就设定业务规则“如果问题中没有指定明确日期，那么默认查询今年的数据”。
![](https://help.fanruan.com/core/style/lod.png)  

### 4.3 新增数据结论
详情请参见：[数据结论](<https://help.fanruan.com/finebi/doc-view-2714.html>)
开启数据结论功能后，系统可基于查询出来的图表数据，在生成图表的同时也生成易懂的业务结论与分析结果，同时满足精准查数和深度分析计算。
![](https://help.fanruan.com/core/style/lod.png)
若 FineChatBI 查询的图表需进一步运算才能获得结论，则会启动 code agent 代码能力进行二次计算，提升 FineChatBI 处理复杂问题的能力，并输出最终结论。
比如提问：6月份的销售额比3月份高的城市是多少：
1）系统先查询 “2024 年 3 月各城市销售额”“2024 年 6 月各城市销售额” 的基础数据并生成对应图表；
2）系统编写代码进行二次计算，对每个城市的 “6 月销售额 - 3 月销售额” 做差值计算，筛选出差值 > 0 的城市；
![](https://help.fanruan.com/core/style/lod.png)
### 4.4 新增用户偏好后台配置
详情请参见：[用户偏好](<https://help.fanruan.com/finebi/doc-view-2701.html>)
该功能支持管理员查看并管理用户的确认记录，帮助解决个人用户操作失误引发的歧义问题，保障智能问答等场景下数据查询的准确性。
![](https://help.fanruan.com/core/style/lod.png)
### 4.5 新增追问功能
详情请参见：[追问](<https://help.fanruan.com/finebi/doc-view-2711.html>)
追问功能支持用户在数据分析过程中，通过追问历史问题，自动切换数据并保持提问的连贯性，无需重复说明背景信息，提升提问效率。
![](https://help.fanruan.com/core/style/lod.png)
