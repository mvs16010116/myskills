## 功能更新推送及反馈
产品更新后，用户进入「我的分析」会自动推送一次产品更新内容，或点击右上角信息，可查看「版本功能信息/功能使用反馈」。
1）用户可查看新版本功能，使用新功能实现业务场景。
2）用户可反馈新功能使用评价，获取限量现金奖励。
3）如无需进行功能更新推送，管理员禁用「FineBI版本更新推送」插件即可。

## 7.0.11
### 我的分析
新增：新增标准分析主题的过滤层级。  

  

更多详情可参考文档：[7.0.11 更新日志](<https://help.fanruan.com/finebi/doc-view-2781.html>)
## 7.0.10
### 我的分析
新增：分析主题类型拆分，原有分析主题统一调整为「自助分析主题」，并新增「标准分析主题」，用于适配灵活探索和高性能直连分析等不同场景
新增：标准分析主题支持 LOD 函数，可通过 FIXED、INCLUDE、EXCLUDE 等函数按指定分析粒度完成数据汇总与计算
### 指标中心
优化：物化命中场景扩展，支持更多可视化复杂指标/维度、指标条件和日期分组的分析查询命中物化结果，提升直连分析性能
  

更多详情可参考文档：[7.0.10 更新日志](<https://help.fanruan.com/finebi/doc-view-2773.html>)
## 7.0.9
### 我的分析
新增：支持获取单个组件的预览链接，用户可分享特定组件查看地址，无需分享整个仪表板
优化：数据预警推送内容长度支持参数控制，管理员可通过参数调整预警推送内容的最大字符数
优化：「周开始于」和「排序设置」配置方式，7.0.9 及之后版本仅需在 BI 侧统一设置即可同步生效
新增：逻辑函数新增限制参数，可控制逻辑函数的参数数量上限
### 数据目录
新增：支持管理员设置数据属性使用权限，可限制用户在新建基础表时使用「直连数据」或「抽取数据」属性
### 指标中心
新增：模型管理支持聚焦功能，可快速将模型视图切换到全部节点或选中节点的展示中心
新增：关系检测支持关键词搜索，可在检测结果中快速定位目标关系
优化：数据活跃逻辑，修改并保存原本不活跃的数据集配置后，系统会自动触发该数据集转为活跃状态
### 移动端
新增：适配鸿蒙系统，支持在鸿蒙系统上正常使用 KPI 指标卡跳转
  

更多详情可参考文档：[7.0.9 更新日志](<https://help.fanruan.com/finebi/doc-view-2766.html>)
## 7.0.8
### 我的分析
新增：指标中心的指标集与指标字段，支持在组件中设置自定义同环比
优化：组件导出 Excel 日期字段后，将保留原有类型，在 Excel 中仍为日期类型
### 指标中心
新增：指标管理支持批量移动指标、批量取消发布指标
新增：在直连模式下，新增物化加速功能，通过预计算将复杂以及数据量大的表提前物化成结果表，实现秒级响应
### AI 问答
新增：移动端新增追问功能，支持与大模型进行多轮对话
新增：移动端的智能模式新增思维链条和意图明确
新增：支持单查询同时处理多个时间字段
新增：支持包含百分比的提问问法
新增：管理员支持通过 URL 给用户提供特定分析主题的问答界面
优化：支持管理员自定义用户问答模式的可选范围
优化：支持连接 Azure 云上大模型
优化：智能问答输入框的新增换行功能，优化长文本输入体验  

优化：数据抄录功能新增快捷按钮，支持在输入框中直接选择仪表板及组件进行数据抄录
  

更多详情可参考文档：[7.0.8 更新日志](<https://help.fanruan.com/finebi/doc-view-2749.html>)
## 7.0.7
### 我的分析
新增：表格支持添加折线图、柱形图、饼图三种迷你图并可调整样式，直观展示数据趋势与对比，无需占用单独图表区域
### 数据目录
新增：开放指标接口，支持指标等数据资源查看及指标结果集、查询SQL获取，便于对接各类应用系统
新增：支持通过FineDataLink读取指标维度数据并写入指定数据库，供其他系统直接使用
### 指标中心
新增：多路径支持查看关系详情，且可对多路径进行修改编辑操作
新增：指标维度支持复制功能，助力用户快速复用资源、提升开发效率
优化：指标、维度、指标集预览体验优化，支持查看最近编辑时间、发布路径、创建者等关键信息。
优化：公式校验交互优化，字段显示来源，选中范围点击「校验数据」触发校验
### AI 问答
新增：移动端归因分析和数据解读功能，新增停止生成按钮方便中断提问
新增：前端偏好记忆功能，PC及移动端可保留模式、界面操作等状态，无需重复设置
新增：指标属性设置，将指标划分为三类，避免累加结果无业务参考性错误
新增：移动端支持查看历史问答记录功能
新增：思维链条功能，清晰展示完整分析步骤，提升分析成果可信度
优化：智能模式日期提问场景，支持「时分秒」级别提问及多类时间维度查询
优化：思维链输出速度，帮助用户更快获取数据答案
优化：报错代码及提示语，汇总四大类错误代码，便于快速定位原因与解决问题
优化：智能问答权限配置，支持独立授权及次级管理员指标维度配置适配
  

更多详情可参考文档：[7.0.7 更新日志](<https://help.fanruan.com/finebi/doc-view-2740.html>)
## 7.0.6
### 我的分析
新增：升级用户部分主题计算场景将自动检测旧引擎逻辑，支持手动切换新 / 旧逻辑，旧逻辑后续版本可能不再维护
新增：导出 Excel 功能优化，新增多语言插件支持，且可将科学计数法数据显示为数值
### 数据目录
新增：数据目录新增「类型」字段展示数据资源所属类型，支持通过列显示设置修改显示状态或调整字段位置
### 指标中心
新增：新增半累加指标功能，通过可视化配置实现部分维度取特定值（最大 / 最小）、其他维度正常汇总，替代复杂 def 函数操作
优化：指标集数据校验增强，支持日期分组、明细指标汇总方式选择、字段单独 / 批量删除，且可选字段范围扩展至来源表及关联表相关字段
优化：模型视图展示效果优化，关联字段自动标记，点击可展开关联表及关系，支持显示所有表间关联属性，同时优化新手引导流程
优化：数据描述 / 扩展字段可输入字符数限制从 200 调整至 1000
优化：图表相关性检测规则优化，按横纵轴指标拆分单元校验查询合法性，任一单元不合法则整体报错
优化：指标中心功能点调整。不再控制「创建关联」和基础「数据搜索」功能，新增「标签与扩展字段」「权限申请审批」功能点
### AI 问答
新增：新增业务规则配置功能，可定义企业业务逻辑、数据筛选、主题匹配等规则，确保分析结果符合业务规范
新增：新增数据结论功能，生成图表时同步输出易懂的业务结论，复杂问题将启动 code agent 进行二次计算并输出最终结果
新增：新增用户偏好后台配置，管理员可查看并管理用户确认记录，解决操作失误引发的歧义问题
新增：新增追问功能，支持基于历史问题展开追问，自动切换数据且保持提问连贯性，无需重复说明背景
新增：排序问法升级，新增组内排序、多维度排序、全局排名三类提问场景及对应问法
新增：管理员监管功能新增问答模式，可查询所有历史问答记录，包含问答模式、问题明细、结果状态等字段，支持筛选与导出
优化：移动端智能问答界面优化，调整展示样式与推荐问题呈现形式，提升交互体验
优化：业务用语功能优化，整合至「知识配置 > 业务用语」模块，支持管理员配置全局生效的业务用语，建立企业内部用语与系统标准表述的匹配
  

更多详情可参考文档：[7.0.6 更新日志](<https://help.fanruan.com/finebi/doc-view-2718.html>)
## 7.0.5
### 指标中心
新增：指标中心支持跨指标集分析，有关联的指标集内字段可按实际关联分析，便于业务主题精细化分类管理，仅部分特定场景字段无法跨指标集匹配
优化：「指标中心」发布的指标可在组件中设置「指标条件」过滤，实现灵活探索，部分特定类型指标不支持该功能
优化：转成表的字段新增相关性提示，区分指标与维度，对无关联的指标 / 维度给出提示，支撑二次数据加工分析  

优化：跨主题取数调用时，可将主题内的「指标集」复制到其他主题，方便数据和看板复用。
优化：「模型管理」中数据表关联字段删除后，仍保持关联关系并标红该字段。
### AI 问答
新增：找报表新增数据抄录（beta 版），可选中仪表板组件抄录数据，支持复制文字、下载 PDF 或另存为分析文档
新增：找报表新增分析报告（beta 版），可自动对仪表板进行摘要总结，生成结构化分析报告，提升复盘与汇报效率
新增：仪表板问答（beta 版）支持自然语言查询相关仪表板资产并呈现可视化内容和文字结论，需申请试用权限
新增：FineChatBI 支持管理员设置默认语言，且可选择是否允许用户自定义语言
新增：支持拓展维度过滤 + TOPN、定基同环比 + TOPN 两种提问场景，适配更多 TOPN 查询需求
新增：分析主题提问返回的图表新增「数据更新时间」（本次更新表格暂无），并调优折线图等图表样式
优化：AI 问答提问界面整体优化。新增历史会话管理，支持点选或展开数据列表提问、显示可提问字段，「确认记录」更名为「用户偏好」并调整位置
优化：支持使用 +、-、*、/ 和 () 操作符对指标名进行运算（遵循优先级规则），有指标数量、字段类型等使用限制
优化：找报表相关权限补齐
优化：V3.31.0 及后续版本中，字段重命名后弃用原字段名，输入原名不匹配、hover 不显示原名，统一分析主题字段名
  

更多详情可参考文档：[7.0.5 更新日志](<https://help.fanruan.com/finebi/doc-view-2705.html>)
  

## 7.0.4
### 指标中心
新增：指标/维度支持批量修改标签、数据描述、扩展字段等内容到系统
新增：维度支持添加条件赋值列，为不同条件的维度赋予不同标签（如按订单金额划分小额、中等、大额订单）。
优化：指标集权限展示优化
### 数据目录
优化：数据目录搜索界面支持切换搜索范围，数据预览页面搜索框固定在右上角
优化：更新任务管理界面可搜索表名、查看更新耗时明细等，方便进行数据更新问题排查
新增：「BI参数」新增「个人抽取空间限制」。支持为 「我的分析」 中除超管外的用户设置抽取空间上限，避免单个用户过度占用磁盘空间
### AI 问答
新增：归因分析报告可导出为 PDF 或另存至分析文档
新增：移动端适配数据解读和归因分析功能，可在移动端查看相关分析结果及图表
新增：新增自定义排序。用户可通过拖拽调整推荐问题分类、分类下具体问题及标签的顺序，将重要或常用内容前置
新增：预加载配置中可设置维度值是否大小写敏感，开启则严格区分（如 “ABC” 与 “abc” 不同）
