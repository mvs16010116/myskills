## 6\. 共创招募：仪表板问答功能
仪表板问答功能支持自然语言问答交互，通过结合底层数据表、计算字段、仪表板内容等多维信息，帮助用户以更高效率找到目标仪表板及数据，并可根据查询条件进行参数联动直接返回相关结果，从而大幅提升检索体验与使用效率。
  * 支持查找仪表板：包含基于BI制作的仪表板
  * 支持进行参数联动查询，提前选中过滤条件
  * 支持生成数据解读，并根据用户的指令调整解读报告的内容
