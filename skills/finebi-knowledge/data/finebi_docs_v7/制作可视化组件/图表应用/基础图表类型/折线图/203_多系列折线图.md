## 1\. 概述
### 1.1 版本
FineBI 版本| 功能变动  
---|---  
7.0| -  
### 1.2 应用场景
  * 多系列折线图通过在同一坐标系中绘制多条折线来展示同一维度下不同指标随时间或其他自变量的变化情况。
  * 例如，用多系列折线图展示自 1800 年至 2017 年全世界能源消耗情况，图中不同颜色的折线代表不同的能源类型（水泥、煤炭、燃气、天然气、石油），如下图所示：


![](https://help.fanruan.com/core/style/lod.png)
### 1.3 基本要求
多系列折线图的基本要求：
图表效果 |  维度字段|  指标字段  
---|---|---  
多系列折线图|  >=1|  >=2  
### 1.4 图表特点
**1）优点**
  * 比较不同系列：允许用户在同一图表中比较多个数据系列，这使得比较不同系列之间的趋势、模式和关系变得直观和容易
  * 节省空间：通过在同一图表中展示多个系列，可以节省空间并减少创建多个单独图表的需要，从而使得报告或展示更加简洁


**2）缺点**
  * 视觉拥挤：如果在一个图表中包含太多的系列，可能会导致视觉拥挤，使得线条难以区分，特别是如果这些系列的颜色或样式相似时
  * 难以展示非数值关系：多系列折线图最适合展示随时间或有序分类变化的数值数据。对于非数值数据或展示数据间的非线性关系，可能不是最佳选择  



## 2\. 示例一：纵轴拖入多个字段实现
### 2.1 准备数据
1）用户登录 FineBI 系统，点击「我的分析」，选中某个文件夹，点击「新建分析主题」，如下图所示：
![2025-09-19_11-12-50.png](https://help.fanruan.com/core/style/lod.png)
2）点击「本地Excel文件>上传数据」，上传表数据。如下图所示：
示例数据：[CO2-by-source.xlsx](<doc-download-/finebi6.X/uploads/file/20240417/CO2-by-source.xlsx> "下载资料")
![](https://help.fanruan.com/core/style/lod.png)
3）上传后，点击「确定」按钮。如下图所示：
![2025-09-22_15-19-24.png](https://help.fanruan.com/core/style/lod.png)
4）点击表头「Year」字段前的「#」按钮，选择「T 文本」，设置其为文本格式，如下图所示：
![2025-09-22_15-25-33.png](https://help.fanruan.com/core/style/lod.png)
5）点击保存更新主题数据。点击「预览」，可以预览数据。如下图所示：
![2025-09-22_15-28-59.png](https://help.fanruan.com/core/style/lod.png)
### 2.2 创建组件
1）点击左下角「组件」按钮。
2）在图表类型下点选择「多系列折线图」。
3）将左侧待分析区域的「Year」拖入分析区域的横轴，「Cement」、「Coal」、「Flaring」、「Gas」、「Oil」拖入纵轴，如下图所示：
![](https://help.fanruan.com/core/style/lod.png)
### 2.3 美化组件
**1）设置颜色**
将左侧待分析区域的「指标名称」拖入「图形属性> 全部」下的颜色栏，不同指标则显示为不同的颜色，如下图所示：
![](https://help.fanruan.com/core/style/lod.png)
**2）设置纵轴指标字段**
  * 点击纵轴「 Cement 」字段的下拉按钮，选择「数值格式」，在弹出的设置框中数量单位选择「亿」，点击「确定」，如下图所示：


![](https://help.fanruan.com/core/style/lod.png)
  * 点击纵轴「 Cement 」字段的下拉按钮，选择「设置值轴(左值轴)」，在弹出的设置框中显示范围勾选「自定义」，点击蓝色公式设置按钮设置最小值为 0 ，取消勾选「显示轴标题」，点击「确定」，如下图所示：


![](https://help.fanruan.com/core/style/lod.png)
### 2.4 创建仪表板
1）点击分析主题编辑界面下方添加仪表板。
2）进入仪表板编辑界面，将组件拖入至仪表板中，如下图所示：
![](https://help.fanruan.com/core/style/lod.png)
3）下拉选择「编辑标题」，样式选择「自定义」，设置标题为「多系列折线图示例一」，点击「确定」。如下图所示：
![](https://help.fanruan.com/core/style/lod.png)

![](https://help.fanruan.com/core/style/lod.png)
