## 1\. 概述
### 1.1 版本
FineBI 版本| 功能变动  
---|---  
7.0| -  
### 1.2 应用场景
平行条形图，又名分区（分面）条形图，在一个视图中展示了多个条形图，每个条形的厚度是统一的，用于进行横向和纵向的对比，可以转化成分区（分面）柱形图。
例如，用平行条形图展示了某互联网产品在三级分销渠道中的访问次数、浏览量、跳出次数和总停留时间四项指标的对比：
![](https://help.fanruan.com/core/style/lod.png)
### 1.3 实现思路
使用分区柱形图，然后交换横纵轴坐标实现。
### 1.4 基本要求
图表效果 |  维度字段|  指标字段  
---|---|---  
平行条形图| >=1| >=1  
  
### 1.5 图表特点
**1）优点**
多维度比较：平行条形图能够清晰地比较多种维度下不同指标的数据量差距
**2）缺点**
数据过多可能导致混淆：如果一个类别包含过多的子类别，或者数据量非常大，平行条形图可能会变得难以阅读和理解
## 2\. 示例
### 2.1 准备数据
1）用户登录 FineBI 系统，点击「我的分析」，选中某个文件夹，点击「新建分析主题」，如下图所示：
![1710923494MGCf.png](https://help.fanruan.com/core/style/lod.png)
2）点击「本地Excel文件>上传数据」，上传表数据。如下图所示：
示例数据：[互联网渠道统计数据.xlsx](<doc-download-/finebi6.X/uploads/file/20240411/互联网渠道统计数据.xlsx> "下载资料")
![](https://help.fanruan.com/core/style/lod.png)
3）上传后，点击「确定」按钮。如下图所示：
![](https://help.fanruan.com/core/style/lod.png)
4）点击保存更新主题数据。点击「预览」，可以预览数据。如下图所示：
![2025-09-22_16-19-20.png](https://help.fanruan.com/core/style/lod.png)
### 2.2 创建组件
1）点击左下角「组件」按钮。
2）在图表类型下选择「分区柱形图」。
3）将左侧待分析区域的维度字段「三级渠道名」拖入分析区域的横轴，指标字段「访问次数」、「浏览量」、「跳出次数」、「总停留时间」拖入分析区域的纵轴，如下图所示：
![](https://help.fanruan.com/core/style/lod.png)
4）点击交换「横纵轴的字段」按钮，将分区柱形图转换为平行条形图，如下图所示：  

![](https://help.fanruan.com/core/style/lod.png)
### 2.3 美化组件
**1）设置颜色**  

将左侧待分析区域的「指标名称」拖入「图形属性>全部」下的颜色栏，不同指标则显示为不同的颜色，如下图所示：
注：更多颜色设置详情参见：[图表颜色](<https://help.fanruan.com/finebi7.0/doc-view-1657.html>)
![](https://help.fanruan.com/core/style/lod.png)
**2）设置标签**
将左侧待分析区域的「访问次数」、「浏览量」、「跳出次数」、「总停留时间」拖入图形属性中对应字段的标签栏中，图表中将会显示指标的数值，如下图所示：
注：更多标签设置详情参见：[图表标签](<https://help.fanruan.com/finebi7.0/doc-view-1659.html>)
![](https://help.fanruan.com/core/style/lod.png)
### 2.4 创建仪表板
1）点击分析主题编辑界面下方添加仪表板。
2）进入仪表板编辑界面，将组件拖入至仪表板中，如下图所示：
![](https://help.fanruan.com/core/style/lod.png)
3）下拉选择「编辑标题」，样式选择「自定义」，设置标题为「平行条形图」，点击「确定」。如下图所示：
![](https://help.fanruan.com/core/style/lod.png)
