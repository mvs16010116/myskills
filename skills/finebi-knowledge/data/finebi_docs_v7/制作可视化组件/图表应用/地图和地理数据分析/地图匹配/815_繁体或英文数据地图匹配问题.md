## 1\. 概述
### 1.1 问题描述
当客户使用繁体或英文的数据表，制作地图组件时，无法与 BI 自带的地图匹配。
### 1.2 解决思路
有两种解决方法：地图 JSON 文件预处理或者手动匹配。
## 2\. 方法一：JSON 文件预处理
地图 JSON 文件保存在路径%FineBI5.1%\webapps\webroot\WEB-INF\assets\map\geographic下，选择需要用到的地图 JSON 文件，使用文本编辑器打开。
  * 如果使用的是繁体数据表，将文件内容全部复制到 [简转繁工具](<https://tool.lu/zhconvert/>) 里，将文件内容里的简体文字转换为繁体文字后重新粘贴进 JSON 文件。
  * 如果使用的是英文数据表，需要将区域名全部替换成对应的英文名，可以直接在决策平台的管理系统>地图配置>地理信息下进行修改，如下图所示：


![1613784557411403.png](https://help.fanruan.com/core/style/lod.png)
## 3\. 方法二：手动匹配
在创建地理角色的时候，手动配置。  

1）创建对应的地理角色，如下图所示：
![image.png](https://help.fanruan.com/core/style/lod.png)
2）出现地理角色设置框，有一栏是用户数据，在匹配到一栏选择下拉，就可以手动选择地图对应的区域，如下图所示：
![image.png](https://help.fanruan.com/core/style/lod.png)
