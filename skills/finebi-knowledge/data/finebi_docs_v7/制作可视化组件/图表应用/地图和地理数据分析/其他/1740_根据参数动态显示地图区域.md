## 1\. 概述
### 1.1 预期效果
目前区域地图仅针对中国地图进行显示，用户希望可以动态显示某个省份的地图。如下图所示：
![11.png](https://help.fanruan.com/core/style/lod.png)
### 1.2 实现思路
通过文本下拉过滤组件实现。
## 2\. 操作步骤
### 2.1 准备数据
1）管理员进入系统，点击「我的分析」，选中某个文件夹，点击「新建分析主题」。如下图所示：
![](https://help.fanruan.com/core/style/lod.png)
2）点击「本地Excel文件>上传数据」，上传表数据。如下图所示：
示例数据：[地区数据分析.xlsx](<doc-download-/finebi6.X/uploads/file/20240326/地区数据分析.xlsx> "下载资料")
[](<doc-download-/finebi6.X/uploads/file/20220719/地区数据分析.xlsx> "下载资料")  

![堆积面积图-2.jpg](https://help.fanruan.com/core/style/lod.png)
3）上传后，点击「确定」按钮。如下图所示：  

![根据参数动态显示地图区域-3-1.jpg](https://help.fanruan.com/core/style/lod.png)
### 2.2 创建组件
1）点击左下角「组件」按钮。如下图所示：  

![根据参数动态显示地图区域-4.jpg](https://help.fanruan.com/core/style/lod.png)
2）将待分析区域维度下的字段「城市」转化为地理角色。如下图所示：
注：直辖市匹配请参见：[直辖市匹配地理角色(城市)](<https://help.fanruan.com/finebi7.0/doc-view-847.html>)
![](https://help.fanruan.com/core/style/lod.png)
3）在图表类型下选择「区域地图」，将「城市（经度）」字段拖入横轴，「城市（纬度）字段」拖入纵轴。如下图所示：
![](https://help.fanruan.com/core/style/lod.png)
4）点击「组件样式>背景」，不勾选 GIS 。如下图所示：
注：该步骤为了更直观地显示每个省份包含的区域，可不做。
![](https://help.fanruan.com/core/style/lod.png)
注：添加标签请参见：[图表标签](<https://help.fanruan.com/finebi7.0/doc-view-1659.html>)；图表背景设置请参见：[背景](<https://help.fanruan.com/finebi7.0/doc-view-231.html#13>)
### 2.3 添加文本下拉过滤组件
1）添加仪表板，并将组件添加至仪表板。如下图所示：
![](https://help.fanruan.com/core/style/lod.png)
2）点击「过滤组件>文本下拉」，拖入「省份」字段。如下图所示：
![1658285923447849.jpg](https://help.fanruan.com/core/style/lod.png)
