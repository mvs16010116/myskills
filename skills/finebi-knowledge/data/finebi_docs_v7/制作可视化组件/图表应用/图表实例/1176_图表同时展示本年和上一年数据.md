## 1\. 概述
### 1.1 预期效果
有时用户需要在一张图表中同时展示不同年份的指标数据，例如需要在同一张图表中展示 2013 年和 2014 年每月的合同金额数据。如下图所示：
![1686644345224520.png](https://help.fanruan.com/core/style/lod.png)
### 1.2 实现思路
对「合同金额」设置指标条件，过滤条件为合同签约时间为「2013年」。
复制「合同金额」指标，设置指标条件，过滤条件为合同签约时间为「2014年」。
将两个「合同金额」指标拖入指标栏、「合同签约时间」拖入维度栏，在图表类型下选择「对比柱状图」。
## 2\. 操作步骤
### 2.1 准备数据
1）管理员进入系统，点击「我的分析」，选中某个文件夹，点击「新建分析主题」。如下图所示：
![2025-09-23_17-28-37.png](https://help.fanruan.com/core/style/lod.png)
2）上传「合同事实表」到分析主题，步骤详情请参见：[5分钟上手BI](<https://help.fanruan.com/finebi7.0/doc-view-818.html>)  

示例数据：[合同事实表.xlsx](<doc-download-/finebi6.X/uploads/file/20220721/合同事实表.xlsx> "下载资料")
### 2.2 设置指标条件
1）创建组件，对「合同金额」设置指标条件，过滤条件为「合同签约时间」为「2013年」。如下图所示：  

![16.jpg](https://help.fanruan.com/core/style/lod.png)
![2.jpg](https://help.fanruan.com/core/style/lod.png)
2）复制「合同金额」指标。如下图所示：
![17.jpg](https://help.fanruan.com/core/style/lod.png)
3）对指标字段「合同金额1」设置指标条件，过滤条件为合同签约时间为「2014年」。如下图所示：
![4.jpg](https://help.fanruan.com/core/style/lod.png)
### 2.3 制作图表
1）将「合同签约时间」字段拖入维度中，「合同金额」「合同金额1」拖入指标中。如下图所示：
![5.jpg](https://help.fanruan.com/core/style/lod.png)
2）设置「合同签约时间」显示格式为「月份」。如下图所示：  

![6.jpg](https://help.fanruan.com/core/style/lod.png)
3）选择图表类型为「对比柱状图」，鼠标悬浮在字段上，点击即可修改字段名称。如下图所示：
![18.jpg](https://help.fanruan.com/core/style/lod.png)
4）将「跨表字段」下的「指标名称」拖入颜色栏，配色方案选择「清新多彩」。如下图所示：
![15.jpg](https://help.fanruan.com/core/style/lod.png)
### 2.4 添加仪表板
[新建仪表板](<https://help.fanruan.com/finebi7.0/doc-view-155.html#3>)，并将组件添加至仪表板。如下图所示：
![9.jpg](https://help.fanruan.com/core/style/lod.png)

详情参见本文 1.1 节。
