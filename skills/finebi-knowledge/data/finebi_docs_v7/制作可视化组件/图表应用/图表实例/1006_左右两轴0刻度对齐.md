## 1\. 概述
### 1.1 问题描述
在有左右轴时，有时会出现 0 刻度不在一条水平线上的情况。如下图所示：  

![1637043649617704.png](https://help.fanruan.com/core/style/lod.png)
如何将两条轴的 0 刻度调到同一水平线呢？
### 1.2 实现思路
在 FineBI 中，只需要左右两条轴的最大值和最小值的比保持一致，便可让 0 刻度在同一水平线上。  

## 2\. 操作步骤
### 2.1 准备数据
1）管理员进入系统，点击「我的分析」，选中某个文件夹，点击「新建分析主题」。如下图所示：
![2025-09-23_17-28-37.png](https://help.fanruan.com/core/style/lod.png)
2）点击「本地Excel文件>上传数据」，上传表数据。如下图所示：  

示例数据：[银行机构指标数据.xlsx](<doc-download-/finebi6.X/uploads/file/20220721/银行机构指标数据.xlsx> "下载资料")
![堆积面积图-2.jpg](https://help.fanruan.com/core/style/lod.png)
3）上传后，点击「确定」按钮。如下图所示：
![左右两轴 0 刻度对齐-1.jpg](https://help.fanruan.com/core/style/lod.png)
### 2.2 创建组件
1）点击左下角「组件」按钮，将「PA产品名称」字段拖入横轴，「税后净利润_完全利润」、「外部利息净收入」字段拖入纵轴，制作柱形图-折线图。可参见文档：[柱形图-折线图](<https://help.fanruan.com/finebi7.0/doc-view-1242.html>)
![1658381743159457.jpg](https://help.fanruan.com/core/style/lod.png)
2）设置右值轴请参见文档：[图表设置双y轴](<https://help.fanruan.com/finebi7.0/doc-view-1664.html>)
可发现 0 刻度不在同一水平线上。如下图所示：  

![左右两轴 0 刻度对齐-3.jpg](https://help.fanruan.com/core/style/lod.png)
### 2.3 调整 0 刻度在同一水平线上
本文示例中，右值轴最大值和最小值的比为-7（70000/-10000=-7），左值轴可以调整最大值为 1400000，最小值为 -200000 。如下图所示：  

![1658382121951163.jpg](https://help.fanruan.com/core/style/lod.png)
### 2.4 添加仪表板
添加仪表板，并将组件添加至仪表板。如下图所示：
![1658382587628887.jpg](https://help.fanruan.com/core/style/lod.png)
