## 1\. 概述
### 1.1 版本
FineBI 版本| 功能变动  
---|---

### 1.2 应用场景
有时用户使用的日期字段数据不是连续的。如下图所示：
![46.png](https://help.fanruan.com/core/style/lod.png)
为了折线图的连续性希望能补全数据。如下图所示：
![47.png](https://help.fanruan.com/core/style/lod.png)
### 1.3 功能简介
在「图表组件」的详细设置界面，可对分析区域维度栏内的日期字段进行操作，按照当前时间分组显示缺失的时间。  

注：只补充日期类型字段的缺失时间，且只补充中间缺失的时间，首尾不会进行补充。
## 2\. 操作步骤
对「合同签约时间」下拉勾选「显示缺失时间」。如下图所示：
![48.png](https://help.fanruan.com/core/style/lod.png)
完成操作后 FineBI 会自动补充缺失的时间，详情可参见本文 1.2 节。
## 3\. 其他说明
### 3.1 分区柱形图&折线图
分区柱形图和分区折线图在使用「显示缺失时间」功能时，会出现一个空维度。  

例如省份只筛选出「北京、上海」，打开「显示缺失时间」后，图表重会出现第三行空维度。如下图所示：
![](https://help.fanruan.com/core/style/lod.png)
### 3.2 超出数据量
**提示内容**
来源表因超出数据量限制导致数据异常，请重新编辑该表至不超限或联系管理员处理。
**触发条件**
1）编辑仪表板时：
当用户点击「显示缺失时间」时，计算该时间维度补全后维度字段数据量，当补全的虚拟缺失数据超出 30w 条，出现报错提示，提示用户时间补全的范围超出限制
2）预览仪表板时：
编辑时未超出限制但数据集变化导致预览时超出数据量范围限制，提示用户时间补全的范围超出限制
