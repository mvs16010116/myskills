## 1\. 概述
### 1.1 版本
FineBI 版本| 功能变动  
---|---  
7.0| -  
### 1.2 应用场景
需要统计一些产品的售卖情况，为了方便区分具体产品，想要将产品的图片（图片是以 URL 的格式存储的）在 FineBI 表格中直接显示出来，如下图所示：
![](https://help.fanruan.com/core/style/lod.png)
### 1.3 功能简介
FineBI 提供设置「表格」内容以图片类型显示的功能，可将文本类型的字段（该字段内容为图片存储的 URL ）设置为以图片形式显示。
注：仅支持对文本类型字段设置显示类型为图片。
### 1.4 使用范围
分组表、交叉表、明细表。
## 2\. 示例
### 2.1 准备数据
1）用户登录 FineBI 系统，点击「我的分析」，选中某个文件夹，点击「新建分析主题」。如下图所示：
![1710923494MGCf.png](https://help.fanruan.com/core/style/lod.png)
2）点击「本地Excel文件>上传数据」，上传表数据。如下图所示：
示例数据：[产品销量.xlsx](<doc-download-/finebi6.X/uploads/file/20240408/产品销量.xlsx> "下载资料")
![](https://help.fanruan.com/core/style/lod.png)
3）上传后，点击「确定」按钮。如下图所示：
![](https://help.fanruan.com/core/style/lod.png)
4）完成后进入数据编辑界面，点击保存更新主题数据。点击「预览」，可以预览数据。如下图所示：
![2025-09-22_15-28-59.png](https://help.fanruan.com/core/style/lod.png)
### 2.2 创建组件
1）点击左下角「组件」按钮。
2）在图表类型下选择「分组表」。
3）将待分析区域的「名称」拖入维度栏；「销量」拖入指标栏，可以看到「名称」字段的实际内容是图片存放的 URL ，如下图所示：
![](https://help.fanruan.com/core/style/lod.png)
2.3 设置表格以图片类型显示
点击维度栏「名称」字段的下拉按钮，选择「显示类型>显示为图片」，如下图所示：
![](https://help.fanruan.com/core/style/lod.png)
### 2.4 创建仪表板
1）点击分析主题编辑界面下方添加仪表板。
2）进入仪表板编辑界面，将组件拖入至仪表板中。
![](https://help.fanruan.com/core/style/lod.png)
3）下拉选择「编辑标题」，样式选择「自定义」，设置标题为「设置表格以图片形式显示」，点击「确定」。如下图所示：
![](https://help.fanruan.com/core/style/lod.png)

## 3\. 注意事项
  * 文本字段「显示为图片」后「[表格文本字段自定义分组](<https://help.fanruan.com/finebi7.0/doc-view-128.html#04957a923791cfaa>)、[表格属性>维度>颜色](<https://help.fanruan.com/finebi7.0/doc-view-124.html#>)、[组件样式>表格字体](<https://help.fanruan.com/finebi7.0/doc-view-1694.html>)」设置不生效，在切换成「显示为文本」后生效。
  * 文本字段「显示为图片」后联动、跳转、钻取、排序、过滤等功能仍然按照文本内容生效，但联动和跳转仅支持点击非图片区域触发，若无可触发区域则无法触发。
  * 显示为图片的表格组件 [导出 Excel](<https://help.fanruan.com/finebi7.0/doc-view-161.html>) ，对应的显示为图片的字段会显示为原字段而不是图片。
