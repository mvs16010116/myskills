## 1\. 概述
### 1.1 版本

### 1.2 应用场景
  * 表格组件的列初始宽度即表格每个单元格初始加载时的宽度。
  * 如果对初始宽度不满意，便可以设置列宽等分，或进行手动调整。


### 1.3 功能简介
  * 列宽等分功能，指各列宽度相等且不受翻页等操作的影响。
  * 相等的列宽大小是根据表格展示的字段宽度及列数等相关数值计算出来的，在页面大小变化时，会进行自适应调整。
  * 除列宽等分功能，还可手动调整列宽。  



注1：在仪表板预览界面下的操作不会改变表格的原始情况，刷新浏览器就会恢复初始状态。
注2：序号宽度是固定的，不参与表格列宽等分。
### 1.4 使用范围
分组表、交叉表、明细表。

### 2.3 调整列宽
可在三个地方调整列宽：组件编辑界面、仪表板编辑界面、仪表板预览界面。
#### 2.3.1 列宽等分  

1）设置列宽等分
  * 组件编辑界面。表格组件列宽等分入口如下图所示：


![](https://help.fanruan.com/core/style/lod.png)
  * 仪表板编辑界面。点击组件任意位置，表格组件列宽等分入口如下图所示：


![](https://help.fanruan.com/core/style/lod.png)
  * 仪表板预览界面。点击组件任意位置，表格组件列宽等分入口如下图所示：


![](https://help.fanruan.com/core/style/lod.png)
2）取消列宽等分
  * 制作完一个表格组件，设置列宽等分后，发现列宽等分的效果并不理想，希望取消列宽等分。
  * 再次点击「列宽等分」的按钮，则恢复初始列宽。如下图所示：


注：手动调整列宽后，也会自动取消列宽等分。
![](https://help.fanruan.com/core/style/lod.png)  

#### 2.3.2 手动调整列宽
以下以在组件编辑页面手动调整列宽为例。  

1）调整字段宽度  

将鼠标移动到需要调整宽度列的表头左边线或右边线，鼠标形状变为样式时，按住鼠标左右拖动即可改变列宽，如下图所示：
![](https://help.fanruan.com/core/style/lod.png)
2）冻结字段和冻结列
  * 「组件样式>格式」中，可设置冻结表格维度，将表格分为维度显示区域和指标显示区域。
  * 两个区域中间的位置为冻结字段和冻结列，如下图所示：


![](https://help.fanruan.com/core/style/lod.png)
3）调整冻结字段和调整冻结列的差异
冻结字段和冻结列可左右拖动进行调整，具体如下：
注 ：若设置了列宽等分，调整冻结字段和冻结列后，则会取消列宽等分，恢复初始宽度。
  * 调整冻结字段


冻结字段向右拖动，冻结列的位置不变，冻结字段的宽度增加，出现滚动条；向左拖动，冻结列的位置向左移动，冻结字段的宽度减小。
![](https://help.fanruan.com/core/style/lod.png)
  * 调整冻结列  



冻结列向右拖动，冻结列的位置向右移动，冻结字段的宽度增加；向左拖动，冻结列的位置向左移动，冻结字段的宽度不变，出现滚动条。  

![](https://help.fanruan.com/core/style/lod.png)
