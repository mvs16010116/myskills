## 1\. 概述
### 1.1 应用场景
用户想以日期字段为维度，展示数据的同比和环比情况。
例如，下图中以日期字段「合同签约时间」为维度，计算出了每个月份合同金额的环比和年同比。
![6.png](https://help.fanruan.com/core/style/lod.png)
  * 环比表示连续 2 个统计周期（比如连续两天或连续两个月）内量的变化比。计算公式：(本期-环期)/环期*100%
  * 同比一般情况下是某年第 n 月与上一年第 n 月量的变化比，也可以比较某月第 n 天与上月第 n 天量的变化比。计算公式：(本期-同期)/同期*100%


### 1.2 实现思路
计算同比和环比有两种方式：
  * 使用表格快速计算实现。快速计算功能详细请参见：[同比/环比（快速计算）](<https://help.fanruan.com/finebi7.0/doc-view-131.html>)
  * 使用快速计算函数实现。快速计算函数详细请参见：[快速计算函数](<https://help.fanruan.com/finebi7.0/doc-cate-393.html>)


我们更推荐您使用第一种快速计算方式。
## 2\. 使用快速计算计算同环比
示例数据：[地区数据分析.xlsx](<doc-download-/finebi6.X/uploads/file/20230811/地区数据分析.xlsx> "下载资料")
下载示例数据「地区数据分析」，新建分析主题，上传示例数据，进行以下计算：
### 2.1 计算环比
1）进入组件编辑界面，创建分组表，维度栏拖入「合同签约时间」日期字段。
由于我们只想看到月份的同比环比情况，于是设置「合同签约时间」分组类型为「年月」，如下图所示：
![](https://help.fanruan.com/core/style/lod.png)
2）指标拖入两个「合同金额」字段，对其中一个「合同金额」选择「下拉>快速计算>同比/环比>环比增长率」。如下图所示：  

![](https://help.fanruan.com/core/style/lod.png)
3）将该字段命名为「合同金额环比」。合同金额的环比就成功计算出来了，如下图所示：
![](https://help.fanruan.com/core/style/lod.png)
### 2.2 计算同比
1）复制「合同金额」，对该字段选择「下拉>快速计算>同比/环比>同比增长率>年」，命名为「合同金额同比」，如下图所示：
![](https://help.fanruan.com/core/style/lod.png)
2）成功计算出合同金额的年同比情况。如下图所示：
![](https://help.fanruan.com/core/style/lod.png)
## 3\. 使用函数计算同环比
### 3.1 计算环比
环比的公式为：环比=(本期-环期)/环期，需要先计算「环期」值。
1）添加「环期」计算字段。需要使用到环期函数 [PREVIOUS_PERIOD](<https://help.fanruan.com/finebi7.0/doc-view-1213.html>) ，如下图所示：
![](https://help.fanruan.com/core/style/lod.png)
2）添加「环比」计算指标。
使用刚刚计算出来的「环期」字段计算环比，环比=(本期-环期)/环期，命名为「环比」，如下图所示：
![](https://help.fanruan.com/core/style/lod.png)
3）将「环比」字段拖入分组表中，并设置数值格式为百分比。月份环比便成功计算出来了，如下图所示：
![](https://help.fanruan.com/core/style/lod.png)
### 3.2 计算同比
同比公式为：同比=(本期-同期)/同期，所以计算同比需要先计算同期。
1）添加「同期」计算字段。
使用同期函数 [same_period](<https://help.fanruan.com/finebi7.0/doc-view-1212.html?source=4>) 计算同期，公式如下图所示：
![](https://help.fanruan.com/core/style/lod.png)
2）添加「同比」计算字段。
使用刚刚创建的「同期」计算出同比同比=(本期-同期)/同期，如下图所示：
![](https://help.fanruan.com/core/style/lod.png)
3）将「同比」拖入分组表，并将数值格式设置为百分比，结果如下图所示：
![](https://help.fanruan.com/core/style/lod.png)
