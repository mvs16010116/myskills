## 1\. 概述
### 1.1 版本
FineBI版本  
| 功能变动  
---|---  
7.0| -  
7.0.5| 「指标中心」发布的指标支持添加「指标条件」  
  
### 1.2 应用场景
指标条件可以对单独对指标值进行过滤。
例如，我们可以复制一个「毛利」字段，在指标条件中设置过滤条件为「店风格=时尚馆」，就可以获得新指标「时尚馆毛利」。
![](https://help.fanruan.com/core/style/lod.png)
### 1.3 功能简介
明细表不支持设置指标条件。
## 2\. 示例
指标条件过滤一个很常见的场景就是求占比。
### 2.1 创建组件
创建分析主题，上传 FineBI 自带的数据表「门店销售统计」，添加组件。如下图所示：
![](https://help.fanruan.com/core/style/lod.png)
### 2.2 指标条件过滤
我们想得到一个只有时尚馆毛利的字段。对毛利字段过滤，将「时尚馆」过滤出来。
1）复制一个「毛利」字段，命名为「时尚馆毛利」，然后对该字段进行指标条件过滤，如下图所示：
![](https://help.fanruan.com/core/style/lod.png)
2）添加过滤条件为“店风格属于时尚馆”，如下图所示：
![](https://help.fanruan.com/core/style/lod.png)
### 2.3 计算占比
添加计算字段，使用sum_agg(时尚馆毛利)/sum_agg(毛利)，就可以得到时尚馆毛利占总毛利的比例，如下图所示：
![](https://help.fanruan.com/core/style/lod.png)
### 2.4 制作分组表
如此我们便得到每个大区下，时尚馆的毛利额各是多少，以及每个大区时尚馆毛利占总毛利的占比。
最后设置 [数值格式](<https://help.fanruan.com/finebi5.1/doc-view-132.html?source=4>)，将「时尚馆毛利占比」的数值格式改为百分比。如下图所示：

## 3\. 指标条件过滤显示规则
### 3.1 单指标条件过滤
当表格只有一个指标，对该指标进行条件过滤时，表格会将不属于过滤条件的值取消整行。
例如：下表只有一个指标字段「数值 3 」，对「数值 3 」进行明细过滤，过滤条件为数值 3>0 ，那么「数值 3 」字段中小于 0 的值整行被去除了，如下图所示：
![](https://help.fanruan.com/core/style/lod.png)
### 3.2 多指标条件过滤
当组件有多个指标且设置了指标条件过滤时，由于表格需要显示整行的数据，不会取消显示整行，而是把不符合过滤条件的非空数据显示为空，原先就为空的数据仍然为空。数据显示空值后，不参加汇总计算。
例如：下表有两个指标字段「数值 3 」和「记录数」，对「数值 3 」进行明细过滤，过滤条件为数值 3>0 ，不符合的数值显示为空，如下图所示：
![](https://help.fanruan.com/core/style/lod.png)
### 3.3 多个指标对同一个字段条件过滤
在多处对同一个字段设置过滤，不满足条件的字段数据显示为空，不满足条件的记录数显示为0，且为空的数据不参与汇总计算。
例如：对「数值 3 」进行明细过滤，过滤条件为数值 3>0 ，对「记录数」进行明细过滤，过滤条件为数值 3<5 ，效果如下图所示：
![](https://help.fanruan.com/core/style/lod.png)
## 4\. 过滤条件说明
对指标设置条件过滤后，用户可以「添加条件」或「添加公式」作为过滤条件。
![49.png](https://help.fanruan.com/core/style/lod.png)
选择「添加条件」后，不同的字段类型可选择的过滤条件不同，如下图所示：
字段类型  
| 可选择的过滤条件  
---|---  
文本字段| 属于、不属于、包含、不包含、开头是、结尾是、开头不是、结尾不是、为空、非空  
  
日期字段| 属于、不属于、某个日期之前、某个日期之后、等于、不等于、为空、非空  
数值字段| 介于、不介于、等于、不等于、大于、小于、大于等于、小于等于、为空、非空  
## 5\. 指标中心支持指标条件
### 5.1 支持设置指标条件的指标范围
7.0.5 版本及之后的 FineBI 「指标中心」发布的原始指标（包含复制指标、维度转指标）支持设置指标条件。
部分场景下的指标依旧不支持指标条件：
  * 组件添加的计算字段
  * 常量指标
  * 使用 WINDOW/RANK_AGG/DEF 相关分析函数计算的指标
  * 指标配置了聚合过滤条件/衍生方式/半累加


![](https://help.fanruan.com/core/style/lod.png)
### 5.2 指标条件添加的字段范围
指标条件仅支持添加字段、公式进行明细过滤。可选字段需遵循以下规则（不符合规则的不展示）：
  * 可选范围：主题内全部指标集的原始维度、原始指标（不包括复制字段；原始维度/指标互转后，原始字段仍可选）
  * 维度/指标为明细维度（数值维度用数值过滤方式）、明细指标
  * 跨表规则：过滤字段需为指标的相对 1 端，且方向指向指标
  * 不包含动态函数（def_add、add_dim、field_in 等）、def 函数计算的字段
  * 字段类型：非常量（与 5.1 节指标条件范围一致）


### 5.3 注意事项
  * 配置了指标条件的指标仅支持聚合场景中使用
  * 在明细表/明细过滤等明细场景，指标条件隐藏，按照未带指标条件计算
