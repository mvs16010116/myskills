## 1\. 概述
### 1.1 应用场景
在 FineBI 中使用地图相关图表时，对于原先就保存在业务包中的经度纬度的数值字段可以使用 [指标转化为地理角色](<https://help.fanruan.com/finebi7.0/doc-view-112.html>) 。数据库中保存的往往是省份、城市、地区等等文本字段，怎么将其转化为地理角色在地图中使用呢？
### 1.2 功能简介
FineBI 提供了维度转化为地理角色功能，对于保存在数据表中的文本字段，可将其转化为地理角色，从而在地理图表中使用。
## 2\. 操作步骤
使用示例数据「客户维度表」：[客户维度表.xlsx](<doc-download-/finebi6.X/uploads/file/20240905/客户维度表.xlsx> "下载资料")
用「客户维度表」制作组件，待分析维度字段「国家」、「省份」和「城市」可以转化成地理角色。
![2025-09-24_10-02-10.png](https://help.fanruan.com/core/style/lod.png)
### 2.1 将维度转化为地理角色
待分析区域选择「下拉>地理角色」，出现国家/地区、省/市/自治区、城市、区/县、自定义图片五个选项。根据对应的维度字段选择对应的地理分类。
例如，在「省份」字段的下拉框中选择「地理角色>省/市/自治区」，如下图所示：
![8.jpg](https://help.fanruan.com/core/style/lod.png)
### 2.2 进行地理角色匹配
1）进入地理角色匹配界面，FineBI 会根据该城市字段的内容自动匹配到系统内置的地理信息，如下图所示：
![9.jpg](https://help.fanruan.com/core/style/lod.png)
系统会自动对地理角色进行匹配，若是某些字段无法自动匹配，可手动进行匹配或检查是否符合 FineBI 的匹配规则，详情请参见：[地理角色匹配规则](<https://help.fanruan.com/finebi7.0/doc-view-861.html>)
2）「省份」字段即转化为地理角色的经度、纬度度字段，如下图所示：
![10.jpg](https://help.fanruan.com/core/style/lod.png)
### 2.3 制作地图组件
点击「区域地图」，将「省份（经度）」和「省份（经度）」拖拽至分析区域，即可生成区域地图，如下图所示：
![](https://help.fanruan.com/core/style/lod.png)
注：维度字段的数据中不能有 / 或 \ 这种特殊符号，否则在转换为地理角色的时候匹配不到对应字段。
