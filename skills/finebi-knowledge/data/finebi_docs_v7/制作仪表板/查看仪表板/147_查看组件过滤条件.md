## 1\. 概述
### 1.1 应用场景
当用户想要知道一个组件目前展示的数据是否是已经被过滤后的数据，过滤的条件如何，可以使用「查看过滤条件」。
如果在组件编辑制作过程中做了过滤，没有编辑权限的「查看用户」也可以通过「查看过滤条件」知道进行了哪些过滤。  

### 1.2 功能说明
仪表板的预览界面和编辑界面都可以「查看过滤条件」。  

支持查看过滤组件、指标条件、字段过滤、过滤器、跳转、联动、钻取等交互功能作用在组件中的过滤条件。
### 1.3 前提条件
你已经制作了仪表板或者正在查看一张已经被分享的仪表板。
### 1.4 约束限制
对组件单独 [导出Excel](<https://help.fanruan.com/finebi7.0/doc-view-153.html>) 时，预览状态下依据预览的过滤条件导出数据，编辑状态下依据编辑的过滤条件导出数据。

![](https://help.fanruan.com/core/style/lod.png)
2）选中店号信息组件，点击「查看过滤条件」，如下图所示：
![](https://help.fanruan.com/core/style/lod.png)
