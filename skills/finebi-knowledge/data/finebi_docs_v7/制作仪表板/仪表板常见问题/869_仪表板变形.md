## 1\. 仪表板变形
### 1.1 问题描述 
制作好的仪表板中的组件变形了。变形前后的仪表板对比如下  

  * 原来的仪表板：


![image.png](https://help.fanruan.com/core/style/lod.png)
  * 变形后的仪表板：


![image.png](https://help.fanruan.com/core/style/lod.png)
### 1.2 原因分析
使用分辨率不同的电脑处理同一张仪表板，该仪表板就可能会变形。
例如：在分辨率为1920*1080的电脑中编辑仪表板，当切换到分辨率低于1920*1080的电脑中打开该仪表板的编辑模式，仪表板会按照低分辨率电脑重新适应。再次在分辨率为1366*768的电脑中查看时，如 1.1 问题描述，仪表板组件会压缩到一起。
### 1.3 解决方法
建议在使用分辨率不同的电脑编辑仪表板时，先进行另存为操作，不要在同一张模板上进行编辑。
