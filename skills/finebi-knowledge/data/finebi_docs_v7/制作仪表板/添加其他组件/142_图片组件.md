## 1\. 概述
### 1.1 应用场景
当用户在仪表板中需要使用到图片时，可以使用图片组件在仪表板中插入图片。  

例如，在仪表板中插入公司 logo ，如下图所示：
![7.png](https://help.fanruan.com/core/style/lod.png)
### 1.2 功能介绍
图片组件支持 JPG、PNG、BMP 以及 GIF 四种图片类型。
注：若图片是以 URL 的格式存储在数据库中，希望这些数据以图片形式展示，可参见：[设置表格以图片形式显示](<https://help.fanruan.com/finebi7.0/doc-view-1280.html>)
## 2\. 操作步骤
### 2.1 添加图片组件
在仪表板编辑界面，将「其他>图片组件」拖动至仪表板内指定区域。
![2.gif](https://help.fanruan.com/core/style/lod.png)
### 2.2 上传图片
1）添加完图片组件后，在组件内上传图片。选中需要上传的图片，即可上传。如下图所示：
上传图片有两种方式：
  * 点击右上角的按钮上传图片。若要更换组件中的图片，可点击![image.png](https://help.fanruan.com/core/style/lod.png)重新上传。
  * 双击组件上传图片。


注：已上传的图片保存在%FineBI%\webapps\webroot\WEB-INF\assets\temp_attach中。可依据大致上传日期查找到图片，路径中的图片可以点击打开直接查看。
![3.png](https://help.fanruan.com/core/style/lod.png)
2）上传图片后，拖动组件框调整组件大小及位置。
### 2.3 设置图片尺寸
点击![image.png](https://help.fanruan.com/core/style/lod.png)可设置图片尺寸为「原尺寸」、「等比适应」或「适应组件」，此处选择「适应组件」如下图所示：
  * 原尺寸：指不改变图片本身的大小进行导入。
  * 等比适应：指按照图片的长宽比例自动去适应组件的大小，图片的大小会随着组件的改变等比例拉伸。
  * 适应组件：指对导入的图片的尺寸大小始终与组件大小相同。


![4.png](https://help.fanruan.com/core/style/lod.png)
### 2.4 添加网页链接
1）点击![image.png](https://help.fanruan.com/core/style/lod.png)添加网页链接按钮，可在该图片上添加超级链接，如下图所示：
![5.png](https://help.fanruan.com/core/style/lod.png)
添加链接之后，点击图片，即可跳转到对应网址。如下图所示：
![6.gif](https://help.fanruan.com/core/style/lod.png)
### 2.5 悬浮
图片组件支持悬浮，使用详情请参考文档： [组件悬浮](<https://help.fanruan.com/finebi7.0/doc-view-157.html#5>) 。
