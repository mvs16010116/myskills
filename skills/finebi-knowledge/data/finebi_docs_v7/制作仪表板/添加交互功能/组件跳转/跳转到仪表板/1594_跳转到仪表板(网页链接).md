## 1\. 概述
### 1.1 应用场景
  * [跳转到分析模板](<https://help.fanruan.com/finebi7.0/doc-view-149.html>) 只能设置跳转到自己的仪表板。若用户想要跳转到别人的仪表板该如何呢？
  * 或者想要实现跳转到其他人的仪表板并传递值，例如选择「上五角场店」，则跳转后过滤组件「选择店名」默认过滤出上五角场店的相关数据，如下图所示：


![2026-05-14_15-06-57.gif](https://help.fanruan.com/core/style/lod.png)
### 1.2 功能简介
通过跳转到仪表板的「公共链接」实现跳转到别人制作的仪表板；
并通过在跳转链接后增加参数，实现传参。
仪表板公共链接：如何获取详情请参见文档： [创建公共链接](<https://help.fanruan.com/finebi7.0/doc-view-164.html>)
注：若跳转前的仪表板和跳转后的仪表板在**同一工程** 下，那么超链可使用相对路径，方便后续工程出现迁移时，跳转不失效。  

若绝对路径为：http://localhost:37799/webroot/decision/link/1KY4
则相对路径为：/webroot/decision/link/1KY4

## 3\. 跳转传值
有两种传值方式：
  * 参数传值：将点击的字段值传入目标组件的参数中，仅直连版本可使用此种传值方式。详细请参见：[跳转传递参数](<https://help.fanruan.com/finebi7.0/doc-view-729.html>)
  * 过滤组件传值：需要目标组件中有过滤组件，下文将详细介绍。  



点击某个字段值时，系统会将该字段值传入目标仪表板的过滤组件，得到的结果相当于过滤组件筛选该值后的结果。只需要在仪表板链接后面添加 ?过滤组件名=字段值。
### 3.1 操作步骤
1使用内置仪表板「门店销售状况分析」，找到文本过滤组件，过滤组件名为「选择店名」，我们将该过滤组件作为一个参数，参数名称就是过滤组件名称，如下图所示：
![14.png](https://help.fanruan.com/core/style/lod.png)
2）复制公共链接，如下图所示：
![15.png](https://help.fanruan.com/core/style/lod.png)
3）使用 2.1 中制作的表格组件，进入仪表板并点击跳转设置，选择添加「网页链接」，将「门店销售状况分析」的公共链接复制，并在后面加上 ?选择店名=店名，如下图所示：
注：URL 后添加内容说明：「 ? 」必须是英文格式；
![16.png](https://help.fanruan.com/core/style/lod.png)  

### 3.2 效果展示
点击「上五角场店」实现跳转后，目标仪表板中已经完成了传值过滤效果。相当于过滤组件「选择店名」筛选「上五角场店」的效果：  

![2026-05-14_15-06-57.gif](https://help.fanruan.com/core/style/lod.png)
### 3.3 过滤组件传值格式
支持传值的过滤组件类型以及写如下表所示：
过滤组件类型| 输入格式（预览 URL ）| 注意实现  
---|---|---  
文本下拉组件/文本列表组件数值下拉组件/日期系列单选组件| url？过滤组件名称=上七宝店| 
  * 过滤组件名字和参数中不能包含, & ? } $ {  <> / | \ > ' " `
  * 日期区间组件相当于要传两个参数， _s 意义为开始时间，_e 意义为结束时间

  
文本组件多选/数值下拉组件| url？过滤组件名称=上宝山店,上五角场,上七宝店  
日期区间组件/年月区间组件| url？过滤组件名称_s=2018-1-1&过滤组件名称_e=2019-1-1  
## 4\. 注意事项
### 4.1 「查询」和「重置」组件
当网页链接跳转后的仪表板有「查询」和「重置」组件时（详情请参见：[查询按钮](<https://help.fanruan.com/finebi7.0/doc-view-139.html>) ，[重置按钮](<https://help.fanruan.com/finebi7.0/doc-view-139.html>)）
  * 开启「预览时自动查询」，参数传值跳转后无需点击「查询」立即生效，过滤组件传值需要点击「查询」。
  * 不开启「预览时自动查询」，参数传值和过滤组件传值都需要点击「查询」才能生效。
  * 点击「重置」后 URL 传参和过滤组件过滤都不生效。
  * 如果跳转后的仪表板已经设置了过滤组件过滤条件，此时「重置」按钮不会在跳转后自动清除过滤组件的过滤条件，需要在跳转后的仪表板手动点击「重置」按钮才可清除。


### 4.2 URL 跳转成功后说明
跳转成功传值后，仪表板获得的数据是 URL 传值过滤后的数据和非传值过滤组件默认值筛选出的数据的交集。
若跳转后对过滤组件进行了筛选操作，URL传值即会失效。
### 4.3 编辑仪表板 URL
网页链接跳转也可以使用仪表板编辑 URL，但是不推荐使用，因为跳转后对仪表板的操作会被保存。
