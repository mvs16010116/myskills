## 1\. 概述
在线视频学习请参见：[过滤组件](<https://bbs.fanruan.com/edu/guide/finebi/18.html>)
### 1.1 应用场景
想要在查看仪表板时，可以灵活改变要过滤的值；或者需要同时对多个组件进行过滤。
例如想要同时过滤控制「库存周转率月度趋势」图表和「库存余量」等指标卡的数据，由于使用的都是「库存明细事实」数据表，因此可以使用过滤组件。  

选择「六味地黄丸」，并选择时间为 2016年，则对应组件仅显示「2016年六味地黄丸」相关的库存信息，如下图所示：
![2023-04-19_15-34-00.png](https://help.fanruan.com/core/style/lod.png)
### 1.2 功能简介
FineBI 中自带的过滤组件有时间过滤组件、文本过滤组件、数值过滤组件、树过滤组件、复合过滤组件、查询重置组件。
用户可根据需要进行设置。
