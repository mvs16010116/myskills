## 1\. 概述
### 1.1 版本
FineBI版本  
| 功能变动  
---|---  
6.0| -  
6.0.16| 新增配置项：1）手动开启/关闭，悬浮阴影效果，优化仪表板预览的组件悬浮阴影效果，见3.3.3节2）表格支持设置滚动条样式，见3.5节  
6.1.5| 仪表板样式可单独对图片组件的背景进行设置  
  
### 1.2 应用场景
制作好仪表板后，想要进行仪表板美化操作，希望能更改或者自定义仪表板样式；
或者希望在自定义样式保存后，能够复用于其他的仪表板制作。
### 1.3 功能说明
FineBI 提供了仪表板样式的设置，可设置整张仪表板的背景、标题、组件、图表/表格风格和配色、过滤组件主题等。
  * 支持直接选择「预设样式」的仪表板；
  * 支持设置「自定义」样式的仪表板；
  * 当前用户支持在其他仪表板使用该仪表板的自定义样式，点击「存为预设样式」实现。


三类仪表板样式设置说明如下表所示：
设置好的仪表板样式  
| 样式说明  
---|---  
自定义样式| 仅当前用户可添加，删除，重命名自定义样式。一个用户最多添加 3 个自定义样式注：若需要修改自定义样式可点击目标仪表板样式，设置自定义样式后「存为预设样式」，删除原先的仪表板样式。  
全局样式| 仅管理员可添加，删除，修改，重命名全局样式。管理员最多添加 5 个全局样式。  
仪表板默认样式为管理员设置的全局样式。详情参见：[BI全局样式](<https://help.fanruan.com/finebi7.0/doc-view-1068.html>)  
预设样式| 有 系统自带的预设样式，不可删除、修改、重命名。  
### 1.4 前提条件
你已经制作好组件并添加至仪表板中。
### 1.5 约束限制
  * 存为自定义样式的样式生效范围：当前你制作的所有仪表板，都可以选择之前保存的自定义样式。
  * 未保存的自定义样式生效范围：当前仪表板。
  * 当组件未添加至仪表板时，组件样式为默认样式；添加至到仪表板后，若设置了仪表板样式，则组件样式继承仪表板样式；
  * 仪表板样式生效优先级排列为：组件样式>仪表板样式>BI 全局样式。
  * 用户默认的仪表板样式仅可由管理员更改，步骤请参见：[BI全局样式](<https://help.fanruan.com/finebi7.0/doc-view-1068.html>)
  * 低版本的 IE 浏览器（一般 IE10 以下），部分组件背景样式和组件标题背景样式效果可能会受影响。


## 2\. 使用预设样式
选择对应的仪表板，并进入编辑界面点击，如下图所示：
![4.png](https://help.fanruan.com/core/style/lod.png)
FineBI 预设多种仪表板样式，在仪表板编辑界面点击「仪表板样式>预设」即可更换样式风格。如下图所示：
![](https://help.fanruan.com/core/style/lod.png)
## 3\. 设置自定义样式
在仪表板编辑点击界面「仪表板样式」，点击「自定义」，进入自定义样式编辑界面，如下图所示：  

![](https://help.fanruan.com/core/style/lod.png)
注：编辑后，自动在仪表板展示预览效果，点击「确定」才会生效自定义效果。若不存为自定义样式，则该样式仅在此仪表板生效。
自定义仪表板样式设置项，如下表所示：
样式 | 可设置项目   
---|---  
基础样式| 选择预设样式，在该样式基础上进行自定义  
存为预设样式| 点击存为预设样式，在「预设」tab页中显示。可以运用于其他仪表板中  
仪表板| 仪表板背景、组件间隙  
组件| 标题背景、标题文字、组件背景、组件边框  
图表| 图表的整体配色、图表中的文本格式  
表格| 表格风格、主题色和文字格式  
过滤组件| 标题背景、标题文字格式、组件背景、组件边框、主题色  
图片组件| 图片组件背景  
### 3.1 设置基础样式
选择自定义样式的基础样式为「冷静蓝灰」。在此基础上修改。如下图所示：
![](https://help.fanruan.com/core/style/lod.png)
### 3.2 设置仪表板样式
1）点击「仪表板」设置样式。可设置仪表板的「背景」和「组件间隙」。
背景颜色设置「蓝紫色」，组件间隙设置「12」，效果如下图所示：
注：若组件设置了 [组件悬浮](<https://help.fanruan.com/finebi7.0/doc-view-157.html#5>) ，那么尽管在仪表板样式处设置组件之间有间隙，但组件仍然可以重叠展示。
![](https://help.fanruan.com/core/style/lod.png)
2）仪表板设置说明如下表所示：
设置仪表板  
| 说明  
  
---|---  
背景  
| 仪表板背景可设置为「颜色」或者「图片」。
  * 颜色：点击可设置背景颜色。选择自定义颜色、透明、自动。
  * 图片：点击可上传图片，作为仪表板背景。

若想要达到图片大小与仪表板大小吻合的效果，图片尺寸参数为3840*2160。  
组件间隙| 设置组件间隙大小，设置为 0 则无间隙。  
### 3.3 设置组件样式
#### 3.3.1 组件标题  

标题可统一设置仪表板中组件标题的「背景」、「文字」。
![](https://help.fanruan.com/core/style/lod.png)
标题设置说明如下表所示：
标题设置  
| 说明  
---|---  
背景| 标题背景可设置为「颜色」或者「标题样式」。
  * 颜色：点击可设置背景颜色。选择自定义颜色、透明、自动。
  * 标题样式：支持自定义图片和各种风格的样式。自定义图片可上传图片作为标题背景，背景图片的大小和像素没有要求。

  
文字| 标题文字可设置「自动」或者「自定义」。详细说明可参见：[组件标题-编辑标题](<https://help.fanruan.com/finebi7.0/doc-view-152.html#5>)  
#### 3.3.2 组件背景  

组件中可统一设置仪表板中所有组件的背景，分为「颜色」和「组件样式」两种。
  * 颜色


颜色设置「自动」，组件边框设置圆角「6」px，边框「2」、「蓝色」。效果如图所示：
![2023-12-19_10-55-33.png](https://help.fanruan.com/core/style/lod.png)
  * 组件样式


组件背景设置如下图所示：
注：组件样式支持自定义图片和各种风格的样式。自定义图片可上传图片作为背景，背景图片的大小和像素没有要求。
![2023-12-19_10-57-43.png](https://help.fanruan.com/core/style/lod.png)

6.0.16 版本支持设置是否显示组件悬浮阴影。多悬浮组件的仪表板，可关闭阴影，美化仪表板效果。
![2023-12-19_11-01-41.png](https://help.fanruan.com/core/style/lod.png)
显示悬浮阴影，仪表板预览效果如下图所示：
![2023-12-19_11-03-56.png](https://help.fanruan.com/core/style/lod.png)
关闭悬浮阴影，仪表板预览效果如下图所示：
![2023-12-19_11-06-43.png](https://help.fanruan.com/core/style/lod.png)
### 3.4 设置图表样式
可设置仪表板中的图表「配色」和图表中的「文字」样式。如下图所示：
![](https://help.fanruan.com/core/style/lod.png)
图表设置的详细说明如下表所示：  

图表设置  
| 说明  
---|---  
配色| 1）可根据需要，选择修改图表中的组件元素配色风格。2）可自定义图表配色  
  
文字| 文字可配置组件中字体的样式，包含图表中的横纵轴、分类轴、值轴的文字等。标题文字可设置「自动」或者「自定义」字体设置详细说明可参见：[组件标题-编辑标题](<https://help.fanruan.com/finebi7.0/doc-view-152.html#5>)  
### 3.5 设置表格样式
1）在表格下可统一设置仪表板中所有表格组件的样式，包括「风格」、「主题色」、「文字」和滚动条。
其中文字自定义中可分别设置「表头」和「表身」的字体样式。
自定义文字样式后，效果如下图所示：
![2023-12-19_11-32-36.png](https://help.fanruan.com/core/style/lod.png)
表格设置详情说明如下表所示：
表格设置  
| 说明  
---|---  
风格| 可设置三种不同的表格整体风格  
主题色| 点击可设置表格组件的主题颜色。可选择自定义颜色、透明、自动实现不同效果  
文字| 文字可设置「自动」或「自定义」的字体样式，自定义中可分别设置「表头」和「表身」的字体样式。自定义字体样式说明可参见：[组件标题-编辑标题](<https://help.fanruan.com/finebi7.0/doc-view-152.html#5>)表身的维度、指标支持设置对齐方式。  
  
滚动条| 表格滚动条可设置：常驻显示、悬浮显示悬浮显示状态，当鼠标悬浮在表格上显示滚动条，否则不显示  
### 3.6 设置过滤组件样式
过滤组件中可统一设置该仪表板中所有过滤组件的样式。可设置标题背景、标题文字、组件背景、主题色。
将过滤组件标题背景设置「蓝色」，标题文字自动，组件背景设置为「蓝色」，组件边框设置为圆角灰色，边框粗细为「3」。并设置过滤组件选择框的主题色为「粉色」。效果如下图所示：
![](https://help.fanruan.com/core/style/lod.png)
过滤组件设置  
| 说明  
---|---  
标题背景| 标题背景可设置为「颜色」或者「图片」。
  * 颜色：点击可设置背景颜色。选择自定义颜色、透明、自动。
  * 图片：点击可上传图片，作为仪表板背景，背景图片的大小和像素没有要求

  
标题文字| 标题文字可设置「自动」或者「自定义」。详细说明可参见：[组件标题-编辑标题](<https://help.fanruan.com/finebi7.0/doc-view-152.html#5>)  
组件背景| 组件背景可设置为「颜色」或者「图片」，同标题背景。还可设置组件边框粗细，颜色，边框圆角程度  
主题色| 可设置过滤组件选择框的主题色  
### 3.7 设置图片组件样式
支持单独对图片组件的背景以及圆角边框进行自定义。
若上传一个背景透明的图片，背景默认是白色的。用户可在「仪表板样式」中，将图片背景调整为透明或其他颜色，也可另外上传图片作为背景。如下图所示：  

![24.gif](https://help.fanruan.com/core/style/lod.png)
另外还可以单独设置图片组件的圆角和边框。如下图所示：
![](https://help.fanruan.com/core/style/lod.png)
## 4\. 添加用户自定义样式
设置自定义仪表板样式后，如果需要反复使用于在其他仪表板，可点击「存为预设样式」。预设样式中即出现该自定义样式。如下图所示：
注：同一用户最多添加 3 个自定义样式。
![](https://help.fanruan.com/core/style/lod.png)
## 5\. 重命名自定义样式
在「预设」tab下，点击添加的自定义样式标题，即可重命名自定义样式，如下图所示：  

注：管理员的全局样式仅管理员可重命名，系统自带的预设样式 1-6 不可修改。
![](https://help.fanruan.com/core/style/lod.png)
## 6\. 删选用户自定义样式
鼠标悬停在用户保存的自定义样式上，左上角就会出现删除的按钮，点击后再次确认，点击「确定」即可删除。如下图所示：  

注：管理员的全局样式仅管理员可删除，系统自带的预设样式 1-6 不可修改。
![](https://help.fanruan.com/core/style/lod.png)
