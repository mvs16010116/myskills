## 1\. 概述
### 1.1 版本
FineBI 版本  
| 功能变动  
---|---  
6.0| -  
6.0.2| 「预览仪表板」文案更改为「预览」；「编辑仪表板」文案更改为「编辑」  
### 1.2 应用场景
在制作组件时，默认选择全部数据进行计算展示。如果取消勾选「查看所有数据」，仅显示部分数据，因此在创建并优化好仪表板后，想要查看制作好的仪表板展示全部数据时候的效果，就可以使用仪表板的预览功能。
注：编辑界面和预览界面的区别详情参见：[仪表板编辑与预览区别](<https://help.fanruan.com/finebi7.0/doc-view-457.html>)
### 1.3 功能说明
FineBI 支持预览仪表板，在仪表板预览界面显示全部数据，也就是显示分享或者发布到目录后其他用户的查看状态。
### 1.4 约束条件
如果将该预览链接分享给其他人，其他人登录 BI 后需要开启模板认证才能正常查看仪表板。
  * 若是该仪表板开启了 [模板认证](<https://help.fanruan.com/finebi7.0/doc-view-403.html>) 功能，其他用户认证成功后可以通过 URL 正常查看仪表板。  

  * 若是该仪表板未开启 [模板认证](<https://help.fanruan.com/finebi7.0/doc-view-403.html>) 功能，对于有仪表板内数据权限的用户，可以直接查看仪表板。若是没有相关的数据权限，仪表板内组件显示无权限查看。


## 2\. 功能介绍
### 2.1 在分析主题预览
在仪表板编辑界面点击右上角的「预览」，即可预览仪表板，如下图所示：  

![1.png](https://help.fanruan.com/core/style/lod.png)
进入该仪表板的预览界面，即可查看仪表板挂出或者分享后的样式（展示完整的数据），如下图所示：
![2.png](https://help.fanruan.com/core/style/lod.png)
在预览界面存在另存为主题、导出、刷新、编辑仪表板按钮，如下图所示：  

![1.png](https://help.fanruan.com/core/style/lod.png)
  * 另存为主题：点击可将仪表板另存，详情请参考 [另存为主题](<https://help.fanruan.com/finebi7.0/doc-view-1889.html#19>) 。
  * 导出：点击可将仪表板导出为 PDF 或 Excel，详情请参考 [仪表板导出](<https://help.fanruan.com/finebi7.0/doc-view-161.html>) 。
  * 刷新：点击即可刷新仪表板。
  * 编辑仪表板：点击可进入仪表板编辑界面。


### 2.2 仪表板预览链接
如果想要实现单个仪表板预览。需要拼接预览链接。
**http://ip:端口/webroot/decision/v5/design/report/此处放置仪表板ID/view**
1）首先点击仪表板，获取到「仪表板ID」。如下图所示：
![2023-11-30_16-14-11.png](https://help.fanruan.com/core/style/lod.png)
2）将仪表板ID根据预览链接格式放置到对应位置。效果如下图所示：
http://localhost:37799/webroot/decision/v5/design/report/68108484385743d3af0b020b2ff513f0/view
![2023-11-30_16-14-58.png](https://help.fanruan.com/core/style/lod.png)
### 2.3 隐藏按钮
如果用户希望预览链接不显示工具栏。可以在链接后面增加参数后缀 ?entryType=7 ，即可隐藏按钮，隐藏后效果如下图所示：
![2023-11-30_16-19-40.png](https://help.fanruan.com/core/style/lod.png)
