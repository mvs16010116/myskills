## 1\. 概述
语法| TRIM (text)| 清除文本首尾所有的空格  
---|---|---  
参数1| text| 需要清除空格的文本  
## 2\. 注意事项
支持使用一个文本参数。
## 3\. 示例
使用 TRIM 可以将文本数据两边多余的空格全部清除。
例如将「 software advice 」中的前后空格都去掉，可以新增计算字段，输入公式：TRIM(" software advice ")，如下图所示：
![](/core/style/lod.png)
将其拖入分析区域，如下图所示：
