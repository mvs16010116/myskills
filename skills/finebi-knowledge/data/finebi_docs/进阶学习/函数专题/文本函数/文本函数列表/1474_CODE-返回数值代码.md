## 1\. 概述
语法| CODE(text)| 计算文本串中第一个字符的数字代码。返回的代码对应于计算机使用的字符集。  
---|---|---  
参数1| text| 需要计算第一个字符代码的文本  
## 2\. 注意事项
支持使用一个文本参数
## 3\. 示例
公式| 结果| 备注  
---|---|---  
CODE("S")| 83|   
  
CODE("Spreadsheet")| 83|
