## 1\. 概述
### 1.1 概念
RFM 分析是美国数据库营销研究所提出的一种简单实用客户分析方法，发现客户数据中有三个神奇的要素：
  * 最近一次消费时间（R）：客户距离最近的一次采购时间的间隔。
  * 最近一段时间内消费频次（F）：指客户在限定的期间内所购买的次数。
  * 最近一段时间内消费金额（M）:客户的消费能力，通常以客户单次的平均消费金额作为衡量指标。


这三个要素构成了数据分析最好的指标。
### 1.2 解决的问题
RFM 分析就是通过三个关键指标对客户进行观察和分类，判断每类细分用户的价值。针对不同的特征的客户进行相应的营销策略。

3）通过和平均值比较，向量化三个指标。
4）根据特征向量客户分类。

### 2.2 计算客户的消费指标
计算每个客户的平均单次消费金额、消费次数、最后一次消费距今天数。
1）对数据进行分组汇总，如下图所示：
![2024-12-23_18-31-07.png](/core/style/lod.png)
  * 最近一次消费时间（R）：「DATE」的汇总方式选择「最晚时间」，可得到每个用户最近一次购买的时间；
  * 消费次数（F）：由于有一条记录代表该用户购买了一次，所以随意拖入一个「CUSTOMERNAME」求「记录个数」即可；
  * 平均单次消费金额（M）：「MONEY1」的汇总方式选择「平均」，可求到每个用户平均单次消费金额；
  * 「MONEY」的汇总方式选择「求和」，可求到每个用户消费金额。  



2）对字段重命名，方便之后理解，如下图所示：  

![2024-12-23_18-39-02.png](/core/style/lod.png)
3）求「最近一次消费距今天数」，新增一列计算时间差，如下图所示：
![1.jpg](/core/style/lod.png)

1）新增汇总列，计算「所有用户消费总金额」，如下图所示：  

![2.jpg](/core/style/lod.png)

3）新增公式列，计算「用户平均消费金额」，用户平均消费金额=所有用户消费总金额/消费总次数，如下图所示：
![4.jpg](/core/style/lod.png)
#### 2.3.2 用户平均消费次数
新增汇总列，计算所有用户的「平均消费次数」，如下图所示：  

![5.jpg](/core/style/lod.png)
#### 2.3.3 最近一次消费距今平均天数  

新增汇总列，求所有用户「最近一次消费距今平均天数」，如下图所示：  

![6.jpg](/core/style/lod.png)
如此我们便计算出了：每个用户的单次消费金额和所有用户平均后的单次消费金额；每个用户的消费次数和所有用户平均下拉的消费次数；每个用户最近一次消费距今天数和所有用户最近一次消费距今平均天数。
### 2.4 用户消费指标评价
根据关键指标是否大于客户总体平均值水平进行评价，其中在 IF(xxx>客户总体xxx平均值,1,0) 中，小于总体平均的设为 0，大于总体平均的设为 1 ，使得 1 都是保持正向特征，0 保持负向特征。
#### 2.4.1 次均消费金额评价
新增公式列「次均消费金额评价」，当用户平均单次消费金额大于用户总体平均值时，标记为 1 ，否则标记为 0 ，公式为IF(平均单次消费金额>用户平均消费金额,1,0)。如下图所示：  

![2024-12-23_18-44-46.png](/core/style/lod.png)
#### 2.4.2 消费次数评价
新增公式列「消费次数评价」，当用户消费次数大于用户总体平均值时，标记为 1 ，否则标记为 0 ，公式为IF(消费次数>平均消费频次,1,0)。如下图所示：
![8.jpg](/core/style/lod.png)
#### 2.4.3 最近一次消费距今天数评价
新增公式列「最近一次消费距今天数评价」，当用户最近消费时间距今天数小于用户总体平均值时，标记为 1 ，否则标记为 0 ，公式为IF(最近一次消费距今天数<最近一次消费距今平均天数,1,0)，。如下图所示：
![9.jpg](/core/style/lod.png)
### 2.5 划分客户类型
已经得到客户的特征向量值，根据以下表格可将客户划分分类：
**客户特征  
**| **客户分类**  
---|---  
重要价值客户（111）| 最近消费时间近、消费频次和消费金额都很高（VIP）  
重要发展客户（101）| 最近消费时间较近、消费金额高，但频次不高，忠诚度不高，很有潜力的用户，必须重点发展。  
重要保持客户（011）| 最近消费时间较远，消费金额和频次都很高。  
重要挽留客户（001）| 最近消费时间较远、消费频次不高，但消费金额高的用户，可能是将要流失或者已经要流失的用户，应当基于挽留措施。  
一般价值客户（110）| 最近消费时间近，频率高但消费金额低，需要提高其客单价。  
一般发展客户（100）| 最近消费时间较近、消费金额，频次都不高。  
一般保持客户（010）| 最近消费时间较远、消费频次高，但金额不高。  
一般挽留客户（000）  
| 都不高。  
#### 2.5.1 添加 RFM 指标
新增公式列「RFM」，使用 CONCATENATE() 函数将 RFM 向量化值拼接起来，顺序为：最近一次消费距今天数评价、消费次数评价、次均消费金额评价。公式为CONCATENATE(最近一次消费距今天数评价,消费次数评价,次均消费金额评价)，如下图所示：

## 3\. 方法二
示例数据与方法一相同。  

### 3.1 创建分析主题
1）新建分析主题并添加数据集「RFM明细数据」。详情请参见[5分钟上手FineBI](<https://help.fanruan.com/finebi6.X/doc-view-818.html>)。
2）添加数据，点击「字段设置」勾选以下几个字段，点击「保存」并「更新」，如下图所示：
![](/core/style/lod.png)
### 3.2 计算客户的消费指标
计算每个客户的平均单次消费金额、消费次数、最后一次消费距今天数。这些指标都使用DEF函数对CUSTOMERNAME分组计算。
  * 最近一次消费时间（R）：MAX_AGG(DATE)得到DATE的最大值，可得到每个用户最近一次购买的时间；
  * 消费次数（F）：由于有一条记录代表该用户购买了一次，所以记录数就代表了每个用户的消费频次；
  * 平均单次消费金额（M）：AVG_AGG(MONEY)得到每个用户购买金额的平均值，可求到每个用户平均单次消费金额；


1）新建一个组件。添加一个计算字段，字段名称设为「客户最晚购买时间」，公式为DEF(MAX_AGG(DATE),CUSTOMERNAME)，如下图所示：
![](/core/style/lod.png)
![](/core/style/lod.png)
2）添加一个计算字段，字段名称设为「M-客户购买金额」，公式为DEF(AVG_AGG(MONEY),CUSTOMERNAME)，如下图所示：
![](/core/style/lod.png)
3）添加一个计算字段，字段名称设为「F-客户购买频次」，公式为DEF(记录数,CUSTOMERNAME)，如下图所示：
![](/core/style/lod.png)
4）求「客户距离最后一次购买时间间隔」，增加一个计算字段，字段名称设为「R-客户距离最后一次购买时间间隔」，公式为DATESUBDATE(TODAY(),客户最晚购买时间,"d")，如下图所示：
![](/core/style/lod.png)
### 3.3 计算所有客户消费指标的平均值
#### 3.3.1 客户平均购买金额
SUM_AGG(MONEY)求出客户所有消费总金额，SUM_AGG(F-客户购买频次)得到客户消费总频次，两者相除得到客户平均购买金额。
添加一个计算字段，字段名称设为「客户平均购买金额」，公式为DEF(SUM_AGG(MONEY)/SUM_AGG(F-客户购买频次))。如下图所示：
![](/core/style/lod.png)
#### 3.3.2 客户平均购买频次
添加一个计算字段，字段名称设为「客户平均购买频次」，公式为DEF(AVG_AGG(F-客户购买频次))。如下图所示：
![](/core/style/lod.png)
#### 3.3.3 客户平均距最后一次购买时间间隔
添加一个计算字段，字段名称设为「客户平均距最后一次购买时间间隔」，公式为DEF(AVG_AGG(R-客户距离最后一次购买时间间隔))。如下图所示：
![](/core/style/lod.png)
如此我们便计算出了：每个客户的单次消费金额和所有客户平均后的单次消费金额；每个客户的消费频次和所有客户平均消费频次；每个客户距最后一次购买时间间隔和所有客户平均距最后一次购买时间间隔。
### 3.4 用户消费指标评价
根据关键指标是否大于客户总体平均值水平进行评价，具体评价要求可见2.4节。
#### 3.4.1 次均消费金额评价
添加一个计算字段，字段名称设为「M评价」，当用户平均单次消费金额大于用户总体平均值时，标记为 1 ，否则标记为 0 ，公式为IF(M-客户购买金额>客户平均购买金额,1,0)。如下图所示：
![](/core/style/lod.png)
#### 3.4.2 消费次数评价
添加一个计算字段，字段名称设为「F评价」，当用户消费次数大于用户总体平均值时，标记为 1 ，否则标记为 0 ，公式为IF(F-客户购买频次>客户平均购买频次,1,0)。如下图所示：
![](/core/style/lod.png)
#### 3.4.3 最近一次消费距今天数评价
添加一个计算字段，字段名称设为「R评价」，当用户消费次数大于用户总体平均值时，标记为 1 ，否则标记为 0 ，公式为IF(R-客户距离最后一次购买时间间隔<客户平均距最后一次购买时间间隔,1,0)。如下图所示：
![](/core/style/lod.png)
### 3.5 划分客户类型
具体划分客户类型标准可见2.5节。
#### 3.5.1 添加 RFM 指标
添加一个计算字段，字段名称设为「客户类型」，使用 CONCATENATE() 函数将 RFM 向量化值拼接起来，顺序为：最近一次消费距今天数评价、消费次数评价、次均消费金额评价。公式为CONCATENATE(R评价,F评价,M评价)，如下图所示：
![](/core/style/lod.png)
具体根据对应标准对向量化的RFM指标进行赋值划分可在制作相关组件时再进行进一步操作。
