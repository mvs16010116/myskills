## 1\. 概述
### 1.1 版本
FineBI服务器版本| 全局内存控制插件  
  
---|---  
6.0| V2.0.3  
### 1.2 功能简介
该插件默认内置在FineBI 产品中。
插件通过监控 BI 进程的内存使用情况、每个查询的内存使用情况，来判断当前的系统是否有宕机的风险。
当判断出有宕机风险时，中断可能会导致宕机的查询任务，来避免宕机。
## 2\. 插件简介
### 2.1 安装插件
全局内存控制插件已内置于产品中，如您删除后需要重新安装，请联系技术支持获取安装包。
插件安装方法参照：[插件管理](<https://help.fanruan.com/finebi6.0/doc-view-459.html>)
注1：插件安装后，必须重启 BI 工程，插件方可生效。  

注2：若 BI 工程版本回退到 5.1.14 之前版本，插件会自动禁用。当 BI 工程版本升级后，被禁用的插件无法自动启用，必须管理员手动启用。
### 2.2 功能简介
插件通过监控 BI 进程的内存使用情况、每个查询的内存使用情况，来判断当前的系统是否有宕机的风险。
当判断出有宕机风险时，中断可能会导致宕机的查询任务，来避免宕机。
触发了中断会跳出提示：错误代码:61300111 当前系统负载过高，为防止系统宕机；建议一段时间后刷新。
