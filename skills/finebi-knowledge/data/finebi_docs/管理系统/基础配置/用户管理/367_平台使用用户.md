## 1\. 概述
### 1.1 版本
BI服务器版本| 功能变更  
---|---  
6.0| -  
6.0.10| 查看用户移动端不显示「我的分析」，详情见 3.3.2 节  
### 1.2 应用场景
FineBI 提供多种不同类型的用户身份
查看用户：对仪表板进行查看，但是无法对数据进行处理，也无法编辑仪表板。
设计用户：可以对数据、组件、仪表板进行查看、调用、编辑、发布
### 1.3 注意事项
1）若系统未注册或系统注册信息中对用户数未进行限制，默认平台使用用户下所有设置都不限人数。
若不开启限制使用用户，则默认所有的用户均有平台使用、BI 查看、BI 设计及移动平台权限。 
2）超级管理员默认为BI设计用户。
3）一个用户既可以是PC端使用用户，也可以是移动端使用用户。
4）一个用户只能被添加到 BI 查看用户与 BI 设计用户中的一个。BI设计用户默认有查看的权限。
## 2\. 各种用户的区别
不同类型的用户，拥有不同类型的权限。用户和权限类型大致分为以下几种：
平台使用用户| 拥有的权限  
| 说明  
---|---|---  
PC端使用用户| PC端使用权限| 决定该用户能否在PC端登录FineBI系统  
查看用户| PC端使用权限| 决定该用户能否在PC端登录FineBI系统  
查看权限| 查看权限决定用户在PC端登录FineBI系统后，能否查看权限范围内的目录  
设计用户| PC端使用权限| 决定该用户能否在PC端登录FineBI系统  
查看权限| 查看权限决定用户在PC端登录FineBI系统后，能否查看权限范围内的目录  
设计权限| 设计权限决定用户在PC端登录FineBI系统后，能否拥有「我的分析」、「公共数据」和「回收站」节点的使用权限
  * 用户可在「我的分析」节点下创建文件夹、创建主题
  * 用户可在「我的分析」节点中的主题下，创建数据、组件、仪表板
  * 用户可将数据和仪表板发布到目录/共享/协作给他人
  * 用户可在权限范围内调用公共数据进行编辑
  * 用户可将数据、组件、仪表板删除到回收站/从回收站恢复  


  
移动端使用用户| 移动端使用权限| 移动端使用权限决定用户能否在移动端登录FineBI系统，并查看权限范围内的目录  
### 2.1 PC端使用权限
PC端使用权限，决定该用户能否在PC端登录FineBI系统。
若用户不属于PC端使用用户，则不拥有该权限，登录FineBI系统的时候，提示：用户名不可用。
![](/core/style/lod.png)
### 2.2 查看权限
查看权限，决定用户在PC端登录FineBI系统后，能否查看权限范围内的目录。
若用户不属于BI使用用户（查看用户或设计用户），即使管理员给该用户分配了对应目录的查看权限，
该用户登录FineBI系统后，虽然能在左侧看到对应目录，但是点击查看时，会提示：
非常抱歉，您无法查看该页面。没有权限，请检查平台使用用户设置
![](/core/style/lod.png)
### 2.3 设计权限
设计权限决定用户在PC端登录FineBI系统后，能否拥有「我的分析」、「公共数据」和「回收站」节点的使用权限。
若用户不属于设计用户，该用户登录FineBI系统后，左侧不显示「我的分析」、「公共数据」和「回收站」节点，无法进行数据、组件、仪表板的任何创作修改删除行为。
![](/core/style/lod.png)
### 2.4 移动端使用权限
移动端使用权限，决定用户能否在移动端登录FineBI系统，并查看权限范围内的目录。
若用户不属于移动端使用用户，该用户在移动端登录FineBI系统时，提示：你暂无权使用移动端，请联系管理员。
![](/core/style/lod.png)
## 3\. 设置查看用户
本章示例：将用户eoco设置为查看用户。  

### 3.1 设置PC端使用用户
若要设置用户eoco为查看用户，那么前提是该用户eoco必须是「PC 端使用用户」，首先需要将用户eoco添加到「PC 端使用用户」中。
1）管理员登录FineBI系统，点击「管理系统>用户管理>平台使用用户」，选择「PC端使用用户」，点击「编辑用户」。如下图所示：
![](/core/style/lod.png)
2）进入编辑用户页面。打开「限制使用用户」按钮，点击下方的用户eoco、Anna、demo，将其添加到「已选择用户」中，点击「完成」。
注1：若系统未注册或系统注册信息中对用户数未进行限制，则「限制使用用户」可关闭，表示所有用户都为 PC 端使用用户。  

注2：超级管理员默认是「PC 端使用用户」，不可移除。
![](/core/style/lod.png)
3）设置完成后，回到平台使用用户设置界面，可以发现用户eoco、Anna、demo已经被添加进「PC端使用用户」中。
![](/core/style/lod.png)
### 3.2 设置查看用户
管理员可以从「PC端使用用户」中选择用户成为「查看用户」。
1）管理员登录FineBI系统，点击「管理系统>用户管理>平台使用用户」，选择「PC端使用用户>BI使用用户>查看用户」，点击「编辑用户」。如下图所示：
![](/core/style/lod.png)
2）进入编辑用户界面。打开「限制使用用户」，点击下方的用户eoco，将其添加到「已选择用户」中，点击「完成」。
注1：若系统未注册或系统注册信息中对用户数未进行限制，则「限制使用用户」可关闭，表示所有PC 端使用用户都有查看用户的权限。
注2：一个用户只能被添加到 BI 查看用户与 BI 设计用户中的一个。
![](/core/style/lod.png)
3）设置完成后，回到平台使用用户设置界面，可以发现用户eoco已经被添加进「查看用户」中。
![](/core/style/lod.png)
### 3.3 效果预览
#### 3.3.1 PC端  

用户eoco（eoco，1）登录FineBI系统。
1）可以查看到权限内的目录仪表板
2）不显示「我的分析」、「公共数据」和「回收站」节点的使用权限，不能创建编辑数据、组件和仪表板。
如下图所示：
![](/core/style/lod.png)
#### 3.3.2 移动端
移动端查看用户不会显示「我的分析」。如下图所示：  

![1685088574190687.jpg](/core/style/lod.png)
