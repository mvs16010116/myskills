### 1.2 功能简介
FineBI 支持邮件的接收和发送。不论是邮件的接收还是发送，都需要邮箱账户信息。
1）支持设置多个系统发件人邮箱。支持设置默认发件人邮箱。
2）支持查看历史邮件发送记录。支持根据发件人、收件人邮箱、模板名称等条件查询发送记录。
## 2\. 设置发件人账户
设置发件人账户分为两步：
1）添加发件人。
2）从已添加的发件人中选择系统默认发件人。
注：若未配置「系统默认发件人」，则认为邮箱未配置。
### 2.1 添加发件人
管理员登录FineBI系统，点击「管理系统>系统管理>邮箱」，点击「添加发件人」，可以设置发件人账户，如下图所示：
![](/core/style/lod.png)
「发件人账户设置」各设置项说明如下表所示：
邮箱设置项| 简介  
---|---  
邮件服务器| 选择邮件服务器
  * 支持下拉选择适合的邮件服务器
  * 可手动输入邮件服务器，格式为SMTP.邮箱后缀

注：如果邮箱为腾讯企业微信邮箱，请手动修改为 SMTP.exmail.qq.com  
端口和加密方式| 设置邮件服务的端口和加密方式  

  * 默认使用25端口，加密方式为TLS加密。一般无需修改。
  * 在设置邮件服务器的时候，如果服务器端口不支持默认的 25 端口，或者 SMTP 服务器不支持 SSL 加密（例如新浪邮箱），那么就必须修改端口号，并设置加密方式。
  * 加密方式包括三种：SSL 加密、TLS 加密、不加密。

注1：建议用户使用更安全的 TLS 协议。  
注2：此处若设置加密方式，请确保加密的证书已加入 Java 证书受信任列表中，否则将导致客户端无法读取加密后的响应  
发件人地址| 填写发件人邮箱地址  

  * 每次只能添加一个发件人账户
  * 发件人地址邮箱名中支持包含符号‘#’和‘&’  


  
密码  
| 大部分邮箱输入邮箱密码即可QQ 邮箱和 163 邮箱需要填写「授权码」，详情请参见本文第三章  
显示姓名| 邮箱发件人的名称，可手动编辑填写  
发送测试邮件| 测试邮件服务器是否配置成功  
配置完「发件人账户设置」后，点击「发送测试邮件」，填写一个收件人邮箱，点击「确定」。  

收件人邮箱中收到测试邮件，内容为「恭喜您！您的邮件服务器已经配置成功」，代表邮件服务器已配置成功。
点击「确定」，该收件人添加成功，如下图所示：
注：「邮件正文」以 HTML 格式显示，部分字体不支持会显示为 SimSun 字体
不支持字体的具体特征为：字体名称中间含有空格、「-」等特殊符号，例如「Windding 3」。
一个FineBI系统支持配置多个发件人地址，支持编辑/删除发件人地址。
![](/core/style/lod.png)
### 2.2 设置默认发件人
添加完发件人后，管理员可在已添加的发件人中选择一个作为系统默认发件人，点击「保存」生效，如下图所示：
注：若系统默认发件人对应的发件人地址被删除了，那么系统默认发件人为空，邮箱配置未完成。
![](/core/style/lod.png)
## 3\. 开启 POP3/SMTP 服务与生成授权码
POP3/SMTP 服务开启可以用客户端收发邮件，若没有开启可能导致邮箱配置失败。
目前配置发件人账号，若是 QQ 个人邮箱和 163 邮箱需要通过授权码来验证。
### 3.1 QQ 个人邮箱
登录 QQ 邮箱，点击「设置>账户」，找到「POP3/IMAP/SMTP/Exchange/CardDAV/CalDAV服务>开启服务>POP3/SMTP服务」，如下图所示：
![](/core/style/lod.png)
点击「开启」，提示「验证密保」，按照提示发送短信，点击「我已发送」，验证成功即可。如下图所示：
![1564108991504137.png](/core/style/lod.png)
验证完成后，提示「成功开启 POP3/SMTP服务」，「数据决策系统>邮箱>密码」一栏需填入「授权码」，而不是邮箱密码。如下图所示：
![1564108788680098.png](/core/style/lod.png)
### 3.2 163 邮箱
登录 163 邮箱，点击「设置>POP3/SMTP/IMAP」，开启「POP3/SMTP服务」，如下图所示：
![](/core/style/lod.png)
点击「开启」，提示「账号安全验证」，按照提示发送短信，点击「我已发送」，验证成功即可。如下图所示：
![](/core/style/lod.png)
验证完成后，提示「成功开启 POP3/SMTP服务」，「数据决策系统>邮箱>密码」一栏需填入「授权码」，而不是邮箱密码。如下图所示：
注：该授权码仅显示一次，请牢记，以防日后需要。
![](/core/style/lod.png)
### 3.3 QQ 企业邮箱
**1）开启POP/SMTP服务**  

打开 QQ 企业邮箱，点击「设置>客户端设置」，找到「开启服务」。
确认勾选「开启POP/SMTP服务」并保存更改。
![](/core/style/lod.png)
**2）获取端口和加密方式**
打开 QQ 企业邮箱，点击「设置>客户端设置」，找到「设置方法>发送服务器」。如下图所示：
数据决策系统配置发件人账户时，加密方式和端口需要发送服务器一致（例如下图，端口为465，加密方式为SSL）。
![](/core/style/lod.png)
**3）获取客户端密码**
点击「微信绑定」，绑定微信。如下图所示：
![](/core/style/lod.png)
成功绑定微信后，需要「开启安全登录」。如下图所示：
开启后，须重新登录邮箱，无法使用原密码登录。网页版请使用微信扫码，客户端请使用「客户端专用密码」登录。
![](/core/style/lod.png)
之后，点击「设置>微信绑定」，首先绑定微信。开启安全登录后，点击「客户端专用密码>生成新密码」，如下图所示：
数据决策系统配置发件人账户时，密码输入下图的客户端密码，而非邮箱密码。
![](/core/style/lod.png)
### 3.4 Exchange 邮箱
在添加「发件人账户」前，请收集以下信息：  

  * 邮件服务器 (SMTP) ：邮件服务器所在 IP 地址
  * 发件人地址：Exchange 邮箱地址
  * 密码：Exchange 邮箱地址的登录密码


管理员登录数据决策系统，点击「管理系统>系统管理>邮箱」，点击「添加发件人」，设置发件人账户。填入提前收集的信息，加密方式选择「不加密」，如下图所示：
![](/core/style/lod.png)
配置完「发件人账户设置」后，点击「发送测试邮件」，填写一个收件人邮箱，点击「确定」。
收件人邮箱中收到测试邮件，内容为「恭喜您！您的邮件服务器已经配置成功」，代表邮件服务器已配置成功。
点击「确定」，该收件人添加成功，如下图所示：
![](/core/style/lod.png)
## 4\. 发送记录
用户可根据发件人、收件人邮箱、模板名称、邮件发送日期等条件，查询系统发送出的历史邮件发送记录。
发送记录显示发件人、IP地址、收件人地址、模板名称、被访问资源、发送事件、发送结果等信息。如下图所示：

## 5\. 注意事项
### 5.1 网络配置
使用邮箱需要确保 BI 工程和邮箱服务器之间可以连通。
1）使用外网的邮箱服务器，如 QQ 邮箱，163 邮箱等，需要保证工程能正常访问到外网。
2）使用用户自己的内网邮箱服务器，则无需连接到外网，保证 BI 工程和邮箱服务器之间连通即可。
### 5.2 未加入java受信任列表导致测试邮件发送失败
**问题描述：**  

内网服务器上，使用 foxmail 发送 SSL 加密过的邮件没问题，使用 finereport 有问题。改成不加密25端口是可以发送出来的。
报错 "Could not connect to SMTP host: SMTP.fanruan.cn, port: 465, response: -1" 。
![](/core/style/lod.png)
**原因分析：**
用户在内网自行搭建的邮箱服务器需要加入java证书信任列表，对于没有加入到java受信任列表中的证书是无法发送邮件的。其他的一些客户端例如 Foxmail 有自己的证书信任体系就可以正常发送。
**解决方案：**  

将证书导入到 java 证书受信任列表即可。
### 5.3 反垃圾机制
**日志报错：** com.sun.mail.smtp.SMTPSendFailedException: 554 DT:SPM 163
**原因分析：** 这个报错是 163 邮箱服务器的反垃圾机制，把标题为test的测试邮件当作垃圾邮件了，导致发送失败。
**解决方案：** 测试邮件不要写测试、test之类的字眼，可以发送成功，说明本身配置没有问题，只是服务器自身限制。
### 5.4 获取验证码出错
若在一分钟之内频繁发送邮件，会报错「获取验证码出错」，如下图所示：
一分钟之后继续发送即可。
