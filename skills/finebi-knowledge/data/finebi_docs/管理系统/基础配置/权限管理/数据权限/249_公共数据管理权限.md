## 1\. 概述
### 1.1 版本
BI 服务器版本  
| 功能变更  
---|---  
6.0| -  
  
### 1.2 应用场景
次级管理员需要能在「公共数据」指定文件夹下添加/编辑/删除数据库表、SQL数据集、Excel数据集。
### 1.3 功能简介
超管赋予次管业务包的管理权限，次管可在业务包下新建表。
超管赋予次管表的管理权限，次管可对有权限的表进行编辑/删除操作。
### 1.4 前置条件
由于只有「设计用户」可以编辑数据表，因此需要先为次管设置用户分类。  

超管登录FineBI系统，点击「管理系统>用户管理」，选择平台使用用户，将次管eoco添加至「设计用户」中，如下图所示：
![](/core/style/lod.png)
## 2\. 数据库表/SQL数据集
本章示例：给次管 eoco 分配权限，使 eoco 可以新建/编辑/删除数据库表/SQL 数据集。
次管不仅需要拥有「数据库表/SQL 数据集」的管理权限，还需要「数据库表/SQL 数据集」调用的数据连接的使用权限。
### 2.1 开启数据连接授权
超级管理员登录FineBI系统，点击「管理系统>权限管理>全局设置」，开启「数据连接控制」按钮，点击「保存」。如下图所示：
注：如不开启「数据连接控制」按钮，则默认用户不拥有任何数据连接的使用权限。
![](/core/style/lod.png)
### 2.2 分配数据连接使用权限
管理员登录FineBI系统，点击「管理系统>权限管理>普通权限配置」，选择权限载体「部门/角色/用户」，本示例选择用户 eoco。
选择「数据连接」Tab，为 eoco 配置数据连接「FRDemo、BIDemo、服务器数据集」的「使用」权限，如下图所示：
![](/core/style/lod.png)
### 2.3 分配数据权限
管理员登录FineBI系统，点击「管理系统>权限管理>普通权限配置」，选择权限载体「部门/角色/用户」，本示例选择用户 eoco。
选择「数据权限」Tab，为 eoco 配置「功能数据」的「管理」权限，如下图所示：
![](/core/style/lod.png)
### 2.4 效果预览
次管eoco登录FineBI系统，点击「公共数据」。  

1）可在「功能数据」文件夹及子文件夹内新建数据库表，仅支持有权限的数据连接和服务器数据集。
可在「功能数据」文件夹及子文件夹内新建SQL数据集，仅支持有权限的数据连接。
![](/core/style/lod.png)
2）可对「功能数据」文件夹及子文件夹内的、有数据连接权限的 SQL 数据集进行「修改SQL、编辑」操作。
可对「功能数据」文件夹及子文件夹内的数据库表进行「编辑」操作。
![](/core/style/lod.png)
## 3\. Excel数据集
本章示例：给次管eoco分配权限，使eoco可以新建/编辑/删除Excel数据集。  

### 3.1 分配数据权限
管理员登录FineBI系统，点击「管理系统>权限管理>普通权限配置」，选择权限载体「部门/角色/用户」，本示例选择用户 eoco。
选择「数据权限」Tab，为 eoco 配置「功能数据」的「管理」权限，如下图所示：
![](/core/style/lod.png)
### 3.2 效果预览
次管eoco登录数据决策系统，点击「数据准备」。
1）可在「功能数据」文件夹及子文件夹内新建Excel数据集。
2）可对「功能数据」文件夹及子文件夹内的Excel数据集进行编辑、更新等操作。
![](/core/style/lod.png)
