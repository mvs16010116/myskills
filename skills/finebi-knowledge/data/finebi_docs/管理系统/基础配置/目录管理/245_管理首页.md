## 1\. 概述
### 1.1 版本
BI 服务器版本| 功能变更  
---|---

### 1.2 应用场景
用户希望自定义设置并管理 PC 端或移动端的首页时，可在「管理首页」处进行设置。
### 1.3 功能简介
FineBI系统支持为 PC 端、手机端、平板端分别设置首页。PC 端首页如下图所示：
首页的类型可以选择FineReport模板、FineBI仪表板、平台目录或链接。
![](/core/style/lod.png)
## 2\. 添加首页示例
### 2.1 添加首页
管理员登录FineBI系统，点击「管理系统>目录管理>管理首页」，点击「添加首页」。
设置首页名称为「首页示例」，首页类型可选择「BI 模板/模板/平台目录/链接」，本示例选择「BI模板」。
  * 在 PC 端下拉框选择「分析模型/购物篮分析/购物篮分析」仪表板
  * 在手机端下拉框选择「分析模型/购物篮分析/购物篮分析」仪表板
  * 在平板端下拉框选择「分析模型/购物篮分析/购物篮分析」仪表板


注1：FineBI系统支持配置多个首页，可为不同用户配置不同的首页。详情请参见：[为不同用户配置不同首页](<https://help.fanruan.com/finebi6.0/doc-view-844.html>) 。
注2：若用户有多个首页的查看权限，按照目录列表的顺序，排在上面的首页优先生效显示。
注3：FineBI系统预先内置了一套默认首页，用户可新建，也可直接在该套首页的基础上进行修改。
![](/core/style/lod.png)
不同的首页类型，对应配置不同，具体如下表所示：
首页类型  
| 说明  
---|---  
BI模板  
| 若首页类型选择「BI模板」，则下拉框可选择的BI仪表板包括：1）当前登录用户自己的仪表板2）当前登录用户有管理权限的用户制作且申请挂出的仪表板  
模板| 若首页类型选择「模板」，则下拉框可选择工程%BI_HOME%\webapps\webroot\WEB-INF\reportlets文件夹和子文件夹下任意一张 FineReport 模板  
平台目录| 若首页类型选择「平台目录」，则下拉框可选择平台目录中的任意一个目录，无论挂载类型是BI模板/模板/链接  
链接| 绝对路径| 若首页为外部网址，首页类型可选择「链接」，填写绝对路径例如：https://www.fanruan.com/注意：地址里必须加上http://  
相对路径| 若首页为 HTML 页面、图片、动图，可以将文件保存到%BI_HOME%\webapps\webroot文件夹下首页类型可选择「链接」，填写相对路径例如：/webroot/demo.html注：图片、动图尺寸大小可根据不同电脑分辨率自行调整。  
### 2.2 分配首页查看权限
管理员登录FineBI系统，点击「管理系统>权限管理>普通权限配置」。
选择权限载体「部门/角色/用户」，本示例选择用户eoco，为其分配首页「首页示例」的「查看」权限，如下图所示：
![](/core/style/lod.png)
### 2.3 分配数据权限
若首页挂载的是BI模板，模板需要使用到一些数据，因此管理员还需要分配数据权限。
管理员登录FineBI系统，点击「管理系统>权限管理>普通权限配置」。
选择权限载体「部门/角色/用户」，本示例选择用户eoco，为其分配「场景数据>数据分析方法」的组件数据权限，如下图所示：
![](/core/style/lod.png)
### 2.4 分配模板认证权限
若系统未开启模板认证，请忽略本节。
若系统开启了 [角色权限认证](<https://help.fanruan.com/finebi6.0/doc-view-405.html>) ，需要给用户分配首页模板的查看权限。
管理员登录FineBI系统，点击「管理系统>模板认证>普通权限配置」。
选择权限载体「部门/角色/用户」，本示例选择用户eoco，为其分配「分析模型/购物篮分析/购物篮分析」仪表板的「查看」权限，如下图所示：
![](/core/style/lod.png)
