## 1\. 概述
### 1.1 版本
FineBI服务器版本  
  
---  
6.0  
### 1.2 问题简介
定时调度任务中会设置调度周期。调度周期中的「开始时间」根据「工程启动时的服务器时区」进行显示。
例如：浏览器时区是东八区，服务器时区是东七区。
如果定时调度任务设定在 2020-01-03 13:00:00 时执行，那么最终在东七区的 2020-01-03 13:00:00 ，也就是东八区的 2020-01-03 14:00:00 执行。
若FineBI工程服务器的时区和浏览器的时区不一致，出现提示：当前服务器时间为XXX，请注意时区对于定时调度触发时机的影响！如下图所示：
![](/core/style/lod.png)
本文将简单介绍修改服务器时区的方法，和如何换算不同时区的时间。
## 2\. 修改服务器时区
### 2.1 Windows 系统
管理员登录 Windows 服务器，点击「控制面板>时钟和区域>更改时区」，选择正确的时区，并点击「确定」，如下图所示：  

![](/core/style/lod.png)
### 2.2 Linux 系统
修改服务器下/etc/sysconfig/clock文件，修改内容为：
注：本示例以「上海」为例。
[code]
    ZONE="Asia/Shanghai"  
      
    UTC=false  
      
    ARC=false  
    
[/code]
修改完成后需要重启工程。
## 3\. 换算时区时间
例如服务器时区为西十区，希望定时调度任务在东八区的 2021-03-04 13:00:00 启动。  

西十区为 UTC-10，东八区为 UTC+8，西十区比东八区早 18 小时，则任务应当设定在西十区的 2021-03-03 19:00:00 启动。
