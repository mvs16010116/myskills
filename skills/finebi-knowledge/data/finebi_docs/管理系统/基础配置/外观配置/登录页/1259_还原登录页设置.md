## 1\. 概述
### 1.1 版本
FineBI服务器版本| 功能变更  
---|---  
6.0| -  
### 1.2 问题描述
用户修改FineBI系统登录页的登录方式为「设置登录网页」后，由于自定义HTML存在错误，导致用户无法打开登录页进行登录。
![](/core/style/lod.png)
### 1.3 解决思路
管理员通过单点接口登录决策系统之后，在平台内将自定义登录页面还原成系统默认的登录页面。
## 2\. 示例
### 2.1 访问单点接口
浏览器界面点击 F12 调用控制台，在 console 选项中输入：
encodeURI("http://ip:端口/webroot/decision/login/cross/domain?fine_username=XX&fine_password=XX&validity=-2&callback=") // xx分别替换为管理员用户名密码
点击回车，跳出访问地址，如下图所示：  

![](/core/style/lod.png)
点击访问返回的地址，当返回 callback 为 accessToken 表示登录成功。
![](/core/style/lod.png)
### 2.2 修改登录方式
单点成功之后，在浏览器端输入工程地址即可自动登录数据决策系统。
http://ip:端口/webroot/decision
点击「管理系统>外观配置>登录页」，将登录方式修改为登录页插件即可。  

![](/core/style/lod.png)
