## 1\. 概述
### 1.1 版本
FineBI服务器版本  
| 功能变更  
---|---

6.0.5| 公共数据检测内容新增「数据占用空间」、「影响用户数」公共数据管理支持次管使用

  * 「近30天访问次数」更名为「近期访问量」
  * 「创建时间」、「发布时间」合并为「创建/发布时间」

  * 删除字段：「引擎类型」、「创建者的部门职务」、「创建者角色」、「最后一次使用时间」、「最后一次编辑时间」

2）新增「检测近 N 天的访问情况」设置项，支持动态检测近 N 天的公共数据访问情况3）支持导出公共数据检测结果为 excel 文件

### 1.2 应用场景
随着系统使用时间的增加，公共数据和用户的分析中积累了大量的数据集。
其中很多数据表已被弃用或从未被使用，这样会导致公共空间十分混乱，服务器资源被大量占用，也不利于管理员进行监控管理。
如何有效管理这些数据，避免资源浪费和管理困难？
### 1.3 功能简介
FineBI提供「数据管理」功能，帮助管理员和用户高效管理数据。
  * **公共数据管理：** 对公共数据进行管理操作，包括：取消发布、停止更新、删除表。
  * **用户数据管理：** 对用户的分析下的数据进行管理操作，包括：删除表。

## 2\. 公共数据管理
超级管理员，可对公共数据进行检测操作，可对公共数据进行取消发布、停止更新、删除表等操作
次管可对检测出的、有管理权限的公共数据，进行取消发布、停止更新、删除表等操作
### 2.1 检测公共数据
**1）进行公共数据检测**
该操作仅支持 FineBI 超级管理员。
超级管理员登录 FineBI 系统， 点击「管理系统>数据管理>公共数据管理」，进入公共数据管理界面。
点击「立即公共数据检测」，系统即会对公共数据中的所有表进行检测。
  * 默认检测近 30 天的公共数据访问情况。
  * 可通过「检测近 N 天的访问情况」设置项修改动态检测范围。设置范围： 1~90 ，单位：天 。
  * 修改「检测近 N 天的访问情况」设置项后，系统会立即执行一次公共数据检测。


![](/core/style/lod.png)
**2）展示检测结果**
等待检测完成，即会自动在该页面显示最新检测结果。FineBI管理员可查看自己有管理权限的公共数据明细。
  * 检测完成后，以明细表形式展示检测结果。包含基础信息、业务使用程度信息、系统压力信息、影响程度。
  * 检测过程为后端执行，管理员可切换至其他页面进行工作。
  * 检测过程中，提供检测进度条，便于用户感知检测进度。
  * 页面显示「上一次数据检测时间」，方便管理员进行检测任务规划。


![2025-02-11_14-21-20.gif](/core/style/lod.png)
**3）对检测结果进行再过滤**
检测出的公共数据量可能非常庞大，因此建议对检测结果进行再过滤。
  * 支持点击「展开搜索面板」，选择需要搜索的内容，再点击「搜索」按钮，即可搜索出特定设置条件下的检测结果。
  * 支持通过点击明细表的表字段对检测结果进行排序。
  * 支持点击「导出为Excel」按钮，将当前搜索条件下的检测结果导出为 .xlsx 格式文件，以方便业务用户确认。


![](/core/style/lod.png)
### 2.2 管理公共数据
FineBI管理员，可选择列表中展示的公共数据表，进行操作。
操作内容包括：取消发布、停止更新、删除。
![](/core/style/lod.png)
各种操作的影响和生效范围如下表所示：
操作  
| 说明  
---|---  
取消发布| 1）仅对自助数据集类型的表生效，即用户的分析发布到公共数据中的表2）对其他类型的表进行取消发布，不生效  
停止更新| 1）仅对更新的表生效，对直连表、最简表不生效2）对于基础表进行停止更新操作后，该表停止更新。且「单表更新>文件夹更新时」设置项变更为「首次全量，此后不更新」，即该表会在下一次所在文件夹更新时，跟随进行一次全量更新，之后就不再更新了。3）对于自助数据集类型的表进行停止更新操作后，该表停止更新。且「单表更新」设置项变更为「不跟随父表更新」，即该表不会再跟随父表一起同步更新。  
删除| 1）仅对基础表生效，对于自助数据集类型的表不生效2）对基础表进行删除操作后，被删除的表会进入回收站中，3）在此处删除表的影响与正常删除表一致  
检测结果内容说明和管理建议如下表所示：
分类  
| 字段| 说明| 管理建议  
---|---|---|---  
基础信息| 表类型注：1）仅在表名称字段内以标识形式存在，不做为独立字段。2）导出的检测结果中不存在该字段。| 数据表的类型，包括：DB表：SQL表EXCEL表自助数据集：用户的分析发布到公共数据中的表其它：除以上四种表之外的数据表，例如产品内置的用户访问日志| -  
表名称| 数据表的名称| -  
创建者| 数据表的创建者，包括创建者用户名和姓名格式：姓名(用户名)| -  
位置| 数据表在「公共数据」中的位置格式：公共数据/文件夹/文件夹/文件夹| -  
创建/发布时间| 「基础表」显示数据表的创建时间  
「自助数据集」类型的表显示数据表从「用户的分析」发布到「公共数据」的时间格式：yyyy-MM-dd HH:mm:ss| 最近创建/发布的表可能是还没开始用，主要关注历史的表

更新模式| 自助数据集设置的更新模式，包括：跟随父表更新不跟随父表更新直连表、最简表、基础表的该字段值为 \--| -

系统压力信息| 数据占用空间| 计算当前表的数据量| 更新量很大的表，要想办法下架/或下沉至数据库  
影响程度| 影响用户数| 该表所有直接或间接子表/组件/仪表板的创建者数，包括创建者自己注：点击「影响用户数」，可在弹窗页面内进一步查看「影响子表数」、「影响组件数」、「影响仪表板数」。| 对于仍在使用、但准备下架/替换的数据表，可以查看哪些用户在使用，然后再进行沟通、确认、通知

## 3\. 用户数据管理
用户数据管理，仅支持 FineBI 超级管理员，无法开放给次级管理员。
### 3.1 检测用户数据
**1）进行用户数据检测**
超级管理员登录 FineBI 系统， 点击「管理系统>数据管理>用户数据管理」，进入用户数据管理界面。
点击「立即用户数据检测」，系统即会对 FineBI 所有用户的分析下的所有表进行检测。
  * 默认检测近 30 天的用户的分析下的所有表的访问情况。
  * 可通过「检测近 N 天的访问情况」设置项修改动态检测范围。设置范围： 1~90 ，单位：天 。
  * 修改「检测近 N 天的访问情况」设置项后，系统会立即执行一次用户数据检测。


![](/core/style/lod.png)
**2）展示检测结果**
等待检测完成，即会自动在该页面显示最新检测结果。超管可查看 FineBI 用户的分析下的所有表。
  * 检测完成后，以明细表形式展示检测结果。包含基础信息、业务使用程度信息、系统压力信息、影响程度。
  * 检测过程为后端执行，超管可切换至其他页面进行工作。
  * 检测过程中，提供检测进度条，便于用户感知检测进度。
  * 页面显示「上一次数据检测时间」，方便超管进行检测任务规划。


![2025-02-13_14-31-28.gif](/core/style/lod.png)
**3）对检测结果进行再过滤**
检测出的我的分析下的表数量可能非常庞大，因此建议对检测结果进行再过滤。
  * 支持点击「展开搜索面板」，选择需要搜索的内容，再点击「搜索」按钮，即可搜索出特定设置条件下的检测结果。
  * 支持通过点击明细表的表字段对检测结果进行排序。
  * 支持点击「导出为Excel」按钮，将当前搜索条件下的检测结果导出为 .xlsx 格式文件，以方便业务用户确认。


![](/core/style/lod.png)
