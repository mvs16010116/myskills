## 1、描述
**问题现象：**
  * 当管理员添加 SQL 数据集时，输入 SQL 语句后进行数据预览，数据预览区域提示预览失败，如下图：


![1.png](/core/style/lod.png)  

**操作简介：** 管理员碰到预览失败时，解决的操作步骤如下：
  1. 点击详细信息查看失败原因；
  2. 参考 [错误代码](<https://help.fanruan.com/finebi6.0/doc-view-530.html>) 说明，查看错误代码问题原因及解决方案，按照解决方案说明解决问题；
  3. 点击重新预览按钮预览数据；


**适用人群：** 管理员
## 2、管理员操作
### 2.1 详细信息
点击预览失败页面下的详细信息按钮，如下图，可以看到预览失败的错误代码及原因说明。
![1.png](/core/style/lod.png)  

此处预览失败原因即为该 SQL 数据集数据来源数据库连接失败，相应错误代码为：61300400。
### 2.2 错误代码
参考 [错误代码](<https://help.fanruan.com/finebi6.0/doc-view-530.html>) 文档，查询错误代码对应的原因及解决方案，可以看到针对该问题的方案即为检查数据连接。其他错误代码使用相同方法查询解决方案即可。
针对此处的数据库连接失败问题，管理员进入管理系统>数据连接，测试该SQL数据集使用的数据连接能否成功连接，若不能，则需解决连接不能成功的问题。
![](/core/style/lod.png)
确保 SQL 数据集使用的数据连接可以连接成功。
### 2.3 重新预览
进入之前的SQL数据集添加页面，点击预览失败下的重新预览按钮，对应问题解决完成，此时数据即可预览成功。
