## 1\. 概述
### 1.1 版本
FineBI 版本

### 1.2 应用场景
分析主题中的仪表板和分析文档，可制作成汇报的形式，分享主题后，使用链接直接进行演示汇报。
![2024-10-25_16-20-23.gif](/core/style/lod.png)
「进入演示模式」，可全屏展示分享的内容，提供沉浸式报告展示体验。
![2024-05-30_16-09-53.png](/core/style/lod.png)
## 2\. 操作步骤
### 2.1 制作分析报告
首先，在分析主题中，对数据进行可视化分析，大致得到结论后。使用 [仪表板](<https://help.fanruan.com/finebi6.X/doc-view-1514.html>) 或 [分析文档](<https://help.fanruan.com/finebi6.X/doc-view-2267.html>) 撰写报告。示例报告如下图所示：
用户可根据自身情况，对内容和布局进行调整。
![2024-05-30_15-40-56.png](/core/style/lod.png)
### 2.2 分享汇报内容
用户往往要对报告进行讲解，可将主题分享出去，汇报内容的同时，还支持使用仪表板的交互功能（筛选/跳转/联动）辅助讲解。  

  * 将分析主题发布到目录：[发布可视化资源](<https://help.fanruan.com/finebi6.X/doc-view-165.html>)
  * 创建分析主题的公共链接：[公共链接分享](<https://help.fanruan.com/finebi6.X/doc-view-164.html>)


例如，将示例DEMO主题中需要汇报的几个仪表板分享到目录。如下图所示：
![2024-05-30_15-22-52.png](/core/style/lod.png)
### 2.3 演示汇报内容
汇报内容时，点击已分享的分析主题右上方进入「演示模式」。即可全屏沉浸式展示汇报内容。
![2024-05-30_15-50-20.png](/core/style/lod.png)
演示过程中，支持左右切换仪表板TAB，上下滑动展示内容，演示完成后，可直接退出。如下图所示：
![2024-05-30_16-06-04.gif](/core/style/lod.png)
