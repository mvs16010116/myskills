## 1\. 概述
手动部署的智能问答升级有三个组成部分：语义解析小模型升级、FineAI服务升级、智能问答插件升级。  

本文列出了这三部分所有可能的升级方式，不同版本的升级需要**选做** 不同步骤，请配合 [FineChatBI 升级指南](<https://help.fanruan.com/finebi6.X/doc-view-2638.html>) 查看。
**本文档中的方案仅适用于非运维平台部署的用户。**
## 2.升级语义解析小模型
有两种升级情况：重新部署新版本或仅更新代码文件。  

### 一、部署新版本语义解析小模型
若用户当前所使用的为 3.22.0 之前的版本，期望能够体验 3.22.0 及之后版本的新功能，那么需要更新镜像。
在更新语义解析小模型镜像，共创用户请提供您日志文件（路径/root/encrypt_v1_5_1/pipeline/logs下的所有日志文件）给帆软运营团队。
1）终止运行中的 fine-chat-bi-parser-base 容器。
[code]
    docker stop fine-chat-bi-parser-base
[/code]
2）删除 fine-chat-bi-parser-base 容器。
[code]
    docker rm fine-chat-bi-parser-base
[/code]
3）使用最新安装包部署语义解析小模型，详情请参见：[部署语义解析小模型](<https://help.fanruan.com/finebi6.X/doc-view-2584.html#31c2906eb736e44b>)。
4）（可选）镜像升级测试成功后，删除老版本镜像，释放硬盘空间。
[code]
    docker rmi fine-chat-bi-parser-base:v1.6
[/code]
### 二、仅更新语义模型的代码文件
1）下载最新版本代码压缩包：[下载链接](<https://fanruan-ai.oss-cn-hangzhou.aliyuncs.com/customer/encrypt_fine_chat_bi_latest.tar>)
2）将下载的代码文件上传到服务器中，并解压
[code]
    tar -xvf 代码文件.tar
[/code]
3）将代码文件放置到容器中，通常容器名为 fine-chat-bi-parser-base。（V3.11.0 之前容器名为 chat2chart）
[code]
    docker cp 代码文件路径/代码文件名称 容器名称:/root/
[/code]
4）进入容器的 /bin/bash 文件夹中。
[code]
    docker exec -it 容器名称 /bin/bash
[/code]
5）进入最新的代码文件夹。
[code]
    cd /root/代码文件名称/pipeline/
[/code]
6）查看老版本服务的进程号。  

[code]
    ps -ef | grep app.py
[/code]
7）关闭老版本服务进程。  

[code]
    kill -15 进程号
[/code]
8）启动最新代码的服务。
[code]
    python app.py
[/code]
9）依次按下 Ctrl+P 和 Ctrl+Q 退出 Docker 容器。
## 3\. 升级 FineAI 服务
### 一、部署新版本 FineAI
需要重新部署 FineAI。  

1）中止 FineAI 容器
[code]
    docker stop fine_ai
[/code]
2）删除 fine_ai 容器。
[code]
    docker rm fine_ai
[/code]
3）重新下载并部署新版 FineAI，详情请参见：[部署 FineAI](<https://help.fanruan.com/finebi6.X/doc-view-2584.html#4f7ab745e9567b4e>)。
### 二、仅更新 FineAI 的代码文件
1）下载最新的 FineAI 代码文件：[FineAI 代码包](<https://fanruan-ai.oss-cn-hangzhou.aliyuncs.com/customer/encrypt_fine_ai_latest.tar>)。
2）将代码文件传输至服务器中。
![](/core/style/lod.png)
3）解压代码文件。
[code]
    tar -xvf encrypt_fine_ai_xxxxx.tar
[/code]
4）执行 docker cp 命令，将解压后的代码文件复制到容器路径 fine_ai:/root/ 中。
[code]
    docker cp encrypt_fine_ai_xxxxx fine_ai:/root/
[/code]
5）进入容器。  

[code]
    docker exec -it fine_ai /bin/bash
[/code]
6）进入到 /root 文件夹。  

[code]
    cd /root
[/code]
7） 查看正在运行的服务进程 ID。  

[code]
    ps -ef | grep app.py
[/code]
8）杀掉进程。  

[code]
    kill -15 进程ID
[/code]
9）进入最新版本的 FineAI 代码包。  

[code]
    cd /root/encrypt_fine_ai_xxxxx/pipeline
[/code]
10）启动服务。  

[code]
    python app.py
[/code]
11）依次按下 Ctrl+P 和 Ctrl+Q 退出 Docker 容器。
## 4\. 更新BI智能问答插件
1）获取最新版本的插件安装包：[下载链接](<https://fanruan-ai.oss-cn-hangzhou.aliyuncs.com/customer/fr-plugin-BI%E6%99%BA%E8%83%BD%E9%97%AE%E7%AD%94.zip>)
2）超管登录管理平台，选择「管理系统>插件管理>我的插件」。
3）选择「从本地更新」，更新插件。  

4）清空缓存并刷新页面。
![1.png](/core/style/lod.png)
4）进入智能问答配置，手动刷新预加载，即可完成镜像升级
![2.png](/core/style/lod.png)
