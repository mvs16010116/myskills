## 1\. 概述
FineBI 支持 [添加 EXCEL 数据集](<https://help.fanruan.com/finebi6.0/doc-view-891.html>) ，用户可上传 csv、xls、xlsx 三种格式的 Excel 数据，在导入时 BI 会自动判断字段类型。
本文说明在上传 Excel 时，三种 Excel 文件格式上传后能被识别成正确类型的数据格式。
