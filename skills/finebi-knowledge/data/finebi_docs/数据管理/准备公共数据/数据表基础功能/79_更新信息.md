## 1\. 概述
### 1.1 版本
FineBI 版本  
| 功能变动  
---|---  
6.0  
| -  
  
6.0.2| 对于应该更新却由于异常情况未能更新的表新增提示：相关表因为异常情况未按预期更新，非最新状态  
6.0.4| 
  * 增加历史更新耗时提示
  * 增加等待更新的原因提示  


  
6.0.8  
| 更新状态新增「无需更新」  
6.0.12  
| 数据不活跃的表，更新状态更改为「暂不抽取」  
### 1.1 应用场景
当用户需要查看表的更新记录、所占用的空间、更新数据条目数的变动等，就可以通过更新信息查看。
### 1.2 功能介绍
数据表的更新记录都会保存在更新信息中。
直连属性的数据表由于不需要更新，所以没有「更新信息」tab。
## 2\. 更新信息
选择一张表后，用户可以点击「更新信息」查看该张表的更新情况。如下图所示：
![44.png](/core/style/lod.png)
A 单表更新：详情可参见 [基础表单表更新](<https://help.fanruan.com/finebi6.0/doc-view-90.html?source=4>)、[自助数据集单表更新](<https://help.fanruan.com/finebi6.0/doc-view-1498.html?source=4>) ；
B 数据占用空间：展示该表所占磁盘空间大小；
C 鼠标触碰感叹号图标，系统会提示该表此时的更新状态：
  * 等待更新中：显示等待更新的原因；
  * 正在更新中：若 SQL数据集 或 DB表 更新，系统会提示此表更新的历史平均耗时以及当前更新进行到了哪个阶段，用户可以通过是否超过了历史耗时来判断更新是否卡住了；
  * 已更新完成：显示是否更新成功，以及最新一次成功更新的时间；


![14.png](/core/style/lod.png)
D 更新信息记录：
更新记录项  
| 描述  
---|---  
更新开始时间/更新完成时间| 记录更新开始结束的时间  
更新状态| 1）记录是否更新成功2）若更新失败会显示报错原因3）若数据表不活跃，则提示「暂不抽取」  
数据条目数| 记录每次更新增加或减少的数据条目数，以及总数据条目数  
该表属于的更新任务| 记录每次表更新是在哪个任务中更新的  
涉及到的基础表信息仅自助数据集拥有此项| 点击即可看到该自助数据集的基础表及其更新信息![16.png](/core/style/lod.png)若自助数据集的基础表是 Excel ，则「涉及到的基础表信息」页面会显示为空。  
（最多展示100条并且是最近一个月的更新信息）
