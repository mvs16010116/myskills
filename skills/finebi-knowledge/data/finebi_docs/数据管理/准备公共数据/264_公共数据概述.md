## 1\. 概述
### 1.1 应用场景
「公共数据」顾名思义，就是用户可以公共使用的数据存放的地方。
可以将复用度很高的表，添加或发布到公共数据集中。
### 1.2 功能介绍
公共数据下，可以添加：
  * Excel数据集：将本地的 Excel 表上传到 FineBI 中；
  * SQL数据集：可以在 FineBI 中写简单的 SQL 语句对数据库中的数据简单处理后添加到 FineBI 中；
  * 数据库表：将数据库里的整张表不做处理直接添加到 FineBI 中；
  * 被发布的自助数据集：用户可以将主题中的自助数据集发布到公共数据中供其他用户使用。
