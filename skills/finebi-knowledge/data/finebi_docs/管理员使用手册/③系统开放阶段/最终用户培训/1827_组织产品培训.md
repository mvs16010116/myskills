## 1\. 概述
### 1.1 应用场景
BI 系统仅仅为企业提供了一个可以实现数据充分利用、自助分析的技术工具基础，但是如果没有扎实的人才体系，仍然是不能够让数据充分发挥价值的。  

例如，某公司已经搭建好了 BI 系统，但是信息部门不知道如何使用 BI 进行数据的维护更新、权限下放；业务人员由于不了解 BI 的仪表板、数据准备功能，无法自主的制作数据集和仪表板，那么这个公司仍然是不可能实现数据驱动，让真正懂业务的人员自主的进行分析。
因此就需要进行「人才体系」的建设，其中最重要的一个方法就是通过「举办培训」，培养不同类型的人才，让专业的人做专业的事。
### 1.2 预期效果
  * 不同角色、部门都有满足企业需求人数的数据人才。
  * 熟练使用 BI 产品：“工欲利其事必先利其器”，让不同的角色可以都可以熟练地使用 BI 产品去做不同的事；
  * 增强数据分析思维：增强企业员工的数据分析思维，在熟练使用工具的基础上，有良好的数据分析思维，才能更好发挥工具的价值。
  * 达成数据驱动业务：让企业员工重视数据，用数据说话，营造数据驱动的企业文化，真正达成数据驱动业务，充分发挥数据价值。


### 1.3 实现思路
既然「举办培训」的目的是为了培养人才，那么首先需要确定希望培养的人才有哪几类。
由于在 BI 系统中的人员大致可以分为「数据开发人员」、「数据分析师/产品/运营」、「业务人员」
注：数据开发人员人数较少，可单独进行讲解学习，这里不做培训详细说明。
因此可以针对不同人员进行根据其需求进行培训：
阶段| 培训内容| 面向对象| 培训形式| 培训目的| 推荐时长  
---|---|---|---|---|---  
  
系统开放后| 产品基础培训| 业务人员、数据分析师| BI 基础功能讲解+课后习题+课堂实践| 面向没有接触过产品或者只是略有了解的用户，让其了解 BI 基本功能。| 1d（4h-6h）  
产品进阶培训| 业务人员、数据分析师| BI 专题功能讲解+课堂实践| 面向对于产品整体功能框架有一定了解，希望系统性的学习产品，后续有计划要应用到业务中去的用户。| 1d（4h-6h）  
定制场景培训| 业务人员、数据分析师| 特定场景讲解+课后习题+课堂实践| 面向对于产品功能都有一定了解，希望学会如何实现自身的典型场景，期望按照企业内部的数据场景来学习的用户。| 1d（4h-6h）

## 2\. 培训内容
「产品基础培训」>「产品进阶培训」>「定制场景培训」是一个由浅入深，引导学习人员不断深入了解 BI ，最后能够熟练使用 BI 完成自己业务分析需求的过程。
注：推荐不同类型的培训间隔大概一周左右。
### 2.1 产品基础培训
基础培训的目标主要是向没有接触过 BI 的用户介绍 BI 的基础功能，帮助其入门并了解要实现某个需求应该使用 BI 中的哪个功能，了解使用 BI 进行分析的流程。

### 2.3 定制场景培训
当业务用户学会基础的功能后，就可以使用 BI 进行一些简单的分析了，但此时用户希望能够通过 BI 将自己所需要分析的实际业务场景展现出来；但是由于对 BI 接触不足无法实现复杂的业务需求，因此需要培训人员收集实际的场景并制作成仪表板展示；并通过培训让业务用户一步步将场景实现出来，让业务学会如何连通 BI 与业务场景。

## 3\. 培训流程
了解了培训的几个阶段，那么该如何举办一个培训呢？
培训具体的执行事项如下所示：  

### 3.1 培训预沟通
在培训前需要确认以下事务：  

1）获取参与人员信息（1.人数 2.人员部门 3.日常分析方式 4.分析基础_工具)。
2）确定培训内容，如果进行定制场景培训需提前收集场景（收集场景>场景数据处理>场景制作）。
3）确定培训起止时间（建议上班时间往后推迟 30min，方便人员到位）。
4）确定培训地点（1.地点 2.网络并发 3.电源插座 4.投屏 ）。
5）通知参与人员带电脑。
6）准备 BI 系统环境（在 BI 中添加参训人员的账号并设置对应用户类型、授予培训内容相关的数据权限、系统使用（例如仪表板分享、目录挂出等等）相关权限）。
7）发送培训内容，对应参训用户可提前自行查看预习。
### 3.2 培训前准备（现场检查）
1）确认当日参训人员的账号、权限、数据包是否配置妥善。  

2）确认投影设备、网络、演示所需要的账号，数据。
### 3.3 开展培训
1）前情回顾，讲下培训目的，给大家带来的价值。
2）按照培训课件内容完成当日培训。
3）时常超过2h的培训，中间停留5~10min休息。
4）培训内容结束后与大家进行交流答疑。
### 3.4 培训收尾
培训结束后，获取参训人员的学习质量和对培训的满意度建议也十分重要。
1）布置随堂练习题目。
2）培训问卷收集满意度及改进意见，在培训结束当天发送给参训人员。问卷形式可以参考下图：
