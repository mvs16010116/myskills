## 1\. 概述
### 1.1 版本

### 1.2 功能变更
帆软免费提供 [FineBI 软件](<https://www.finebi.com/product/download>) ，用户可使用该软件进行功能测试和试用。  

  * 直接下载的 FineBI 软件包含了所有功能，但是限制了并发数，使用部分功能时会存在试用信息标志。
  * 用户可联系帆软商务，根据自己的需求购买功能点并注册。注册了的功能点可以使用，未购买的功能点无法使用。


注1：为保证正常使用，建议用户购买注册，FineBI 注册步骤请参考：[FineBI服务器注册步骤](<https://help.fanruan.com/finebi6.0/doc-view-188.html>)   

注2：注册是有功能点区分的，即使注册了，如果没购买对应功能点，相关功能就无法使用，如果有需要可联系销售增购。

## 3\. 未注册的影响
### 3.1 版权信息
如果 FineBI 未注册或者注册许可已经过期，用户通过 IP 或域名访问模板或数据分析，就会在模板底部显示版权信息：上BI选帆软，专注BI十七年，Powered by 帆软 试用模式。
如下图所示：
![](/core/style/lod.png)
### 3.2 并发数
并发数指的是允许同时访问报表服务器的接入数量，详情请参见：[注册并发原理](<https://help.fanruan.com/finereport/doc-view-276.html>)
未注册的并发数固定为 2 。如下图所示：
![](/core/style/lod.png)
如正在访问服务器的并发数已达到最高并发数，后登录的用户将无法访问。
注：公共链接访问模板，占用并发数，关闭页面后释放占用。
### 3.3 Web 应用服务器
未注册版本 Web 应用服务器每七天会暂停运行，仪表板无法正常访问，此时需要重启 Web 应用服务器如 Tomcat 。
如果您的项目正在进行中，上述未注册出现的暂停运行问题可能会对项目产生比较大的影响，甚至于出现不必要的损失。  

因此，我们建议您购买 FineBI 软件，注册后再使用。
### 3.4 注册提醒
如果 FineBI 未注册或者注册许可已经过期，用户通过 IP 或域名访问模板或数据分析，每天弹出一次注册提醒，如下图所示：
注：用户通过 localhost 或 127.0.0.1 访问模板或数据分析，未注册时不会显示注册提醒。

## 4\. 注册的优势
企业使用 FineBI 工程时，我们建议企业购买 FineBI 软件，并进行注册。
注册后，可为企业内成员带来自由、安全、流畅的数据分析体验。详情如下：
### 4.1 服务器部署
个人用户在本地电脑安装使用 FineBI ，当个人电脑内存和磁盘空间较小时，运行性能受限，严重时出现卡顿或电脑发热等问题。
企业在使用 FineBI 时，若将 FineBI 部署在企业服务器上，则企业内成员无需本地安装启动 FineBI ，可以通过浏览器直接访问、使用企业 FineBI 进行数据分析，不受时间和设备的限制。
同时，企业服务器管理员通过配置合适的服务器软硬件，能有效保障企业内成员使用 FineBI 进行数据分析时的流畅体验。
FineBI 官方 Demo 采用服务器部署方式，带来更流畅的分析体验，可点击 [在线Demo](<https://pcdemo.finebi.com/webroot/decision>) 进行体验，如下图所示：
服务器部署详情请参见：[工程部署](<https://help.fanruan.com/finebi6.X/doc-view-1869.html>)
![](/core/style/lod.png)
### 4.2 在线共享仪表板
个人用户在本地电脑安装使用 FineBI 时，无法随时随地将制作好的仪表板分享给其他用户，具有以下限制：  

  * 只能通过公共链接的形式进行分享，且需要保证被分享用户的 IP 和自己的 IP 在同一局域网内；
  * 同时访问仪表板的 IP 个数限制为 2 个；
  * 当个人电脑关闭 FineBI 工程后，原分享链接失效，被分享用户无法继续访问仪表板。


企业在使用 FineBI 时，通过给企业内部成员开通使用账号，可以实现企业内部成员在线分享数据分析报告，分享的方式有多种，包含：
  * 分享仪表板，即被分享者可以访问、编辑、另存为该分析报告；
  * 公共链接分享，即获取公共链接的用户，可以通过该链接访问分析报告，适用于会议汇报场景。
  * 发布仪表板，即将 FineBI 内用户制作好的仪表板发布到平台目录中。
  * 协作，即将文件夹或者分析主题协作给其他设计用户，使其可以查看、使用、协同编辑分析主题的内容。


详情请参见：[分享仪表板概述](<https://help.fanruan.com/finebi6.X/doc-view-1854.html>)
### 4.3 数据自动更新
个人用户在本地电脑安装使用 FineBI 时，一般将从 ERP、OA 等业务系统中先导出 Excel 数据，再将其上传到 FineBI 中进行分析。当数据更新时，需手动追加上传 Excel 数据，才能在分析报告中看到最新的数据。
企业在使用 FineBI 时，通过连接企业数据库，可以直接获取业务数据，无需用户手动导出 Excel 表再上传分析，同时可以实现数据的自动更新，保证业务数据的时效性。
详情请参见：[数据更新方案](<https://help.fanruan.com/finebi6.X/doc-view-1823.html>)
![](/core/style/lod.png)
### 4.4 权限管理
作为企业数据管理员，经常会担心数据安全问题，重要的、隐私的数据泄露将会给企业经营带来严重威胁，如何在满足业务分析需求的同时保证数据安全呢？
FineBI 提供完善的权限管理体系，支持细化到数据表行、列级别的权限管控：
  * 保证数据安全，防止数据泄露；
  * 千人千面，一个分析报告不同的人看到不同内容，  
如：在集团和分子公司场景下，集团用户能看到总体数据，分子公司的用户只能看到分子公司下的数据；
  * 便捷分配与维护数据权限，缩短维护时间。


权限管理体系请参见：[权限](<https://help.fanruan.com/finebi6.X/doc-view-726.html>)  

![](/core/style/lod.png)
### 4.5 资源交接
当企业中有用户离职或者转岗后，经常导致原有的分析资产丢失，需要重新制作，进而产生低效的、重复的工作量。
FineBI 支持资源交接，将离职或转岗用户的分析资产全部或部分交接给各个在职用户，使其可以继续使用和编辑分析资产，以便分析资产得到有效保留和继承。
详情请参见：[资源交接](<https://help.fanruan.com/finebi6.X/doc-view-980.html>)
![](/core/style/lod.png)
