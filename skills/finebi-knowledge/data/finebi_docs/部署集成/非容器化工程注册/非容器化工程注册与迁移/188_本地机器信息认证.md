## 1\. 概述
### 1.1 版本
FineBI服务器版本  
  
---  
6.0  
  
### 1.2 功能简介
本地机器信息认证是最常见的认证方式，操作简单，十分方便。
FineBI 工程所在服务器的物理信息固定，用户通过导出 rif 文件，获取 mac 地址和机器码，来生成一个唯一标识的 license 文件。
### 1.3 注意事项
1）本地机器信息认证，需要 FineBI 工程所在服务器的物理信息固定。如不固定，不适合使用该注册方法。
例如要 FineBI 工程部署在虚拟机环境下，虚拟机环境下物理信息可能变化，造成注册失败，请选取其他注册方式。
2）一个正式 license 文件在一台机器上只能注册一次，若需要在同一台机器上注册多个工程，则需要购买多个 license 。
3）一个正式 license 文件只适用于一台服务器，如需更换服务器，需要进行注册迁移。  

4）同一服务器下跨大版本升级（5.0 升级5.1）后，需要进行注册迁移。
5）请确保工程使用 JDK 1.8 且小版本需在 JDK8u200 以上。
6）Mac地址不允许设置为空，不允许不限。因为正式 license 文件强制校验Mac地址，为空则一定会注册失败。
## 2\. 注册步骤
### 2.1 确认工程名
打开 FineBI 工程所在服务器%Tomcat_HOME%\webapps\目录，确认FineBI Web 工程名，默认为webroot。
用户可在注册前根据自身需要修改工程名，注册后将无法修改。
注：此工程名的修改可能会影响模板的超链等设置，请谨慎修改。
修改工程名就是改这个文件夹的名称，修改后，访问工程的地址就变成了http://IP:端口/工程名/decision
![image.png](/core/style/lod.png)
### 2.2 导出注册信息
管理员登录FineBI系统，点击「管理系统>注册管理>立即注册」，如下图所示：
![](/core/style/lod.png)
认证方式选择「本地机器信息认证」，点击「导出注册信息」，如下图所示：  

导出的文件名为RegistrationInformation.rif，该文件中存储了 FineBI 工程的版本信息。
![](/core/style/lod.png)

## 4\. 注册失败
### 4.1 现象描述
若注册失败，页面将出现提示弹窗，如下图所示：
  

![](/core/style/lod.png)
### 4.2 失败原因
点击详细信息即可查看注册失败的原因，根据具体失败原因进行排查。
失败原因  
| 具体提示  
  
---|---  
证书已过期| 过期时间：2019-02-22  
版本不匹配| 认证应用版本：9.0本地应用版本：10.0  
MAC 地址不匹配| 认证 MAC 地址：xxx本地 MAC 地址：xxx  
机器码不匹配| 认证机器码：xxx本地机器码：xxx  
应用名不匹配| 认证应用名：xxx本地应用名：xxx  
已达可授权数量上限| 证书已被同服务器上其他工程使用  
工程内容不匹配| 认证工程内容：xxx本地工程内容：xx  
注：除上述外失败原因外，其他统一报错：证书内容不正确。
有多个失败原因时，平台中会全部显示出来。
