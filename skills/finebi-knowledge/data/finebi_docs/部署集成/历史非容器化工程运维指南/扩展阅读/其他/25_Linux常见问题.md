2| Linux 服务器中系统的编码默认设置为 en_US.UTF-8 ，而 FineBI 的中文编码默认为 zh_cn.UTF-8 ，因此在 BI 工程中导出 Excel 会出现乱码的情况本文介绍如何将 Linux 系统的编码改成 zh_CN.UTF-8 | [Linux系统编码修改](<https://help.fanruan.com/finebi6.0/doc-view-27.html>)  
  
3| 在 Linux 中使用 FineBI，系统使用过程中 FineBI 的进程异常关闭，查看 BI 的日志并没有任何的异常信息，本文介绍出现此问题的原因及解决方案| [Linux中BI进程异常关闭](<https://help.fanruan.com/finebi6.0/doc-view-380.html>)  
  
4| 在使用 Linux 系统时，出现 Resource temporarily unavailable 报错时，可参考本文查看问题原因及解决方案| [修改 Linux 最大进程数](<https://help.fanruan.com/finebi6.0/doc-view-691.html>)

6| 使用第三方工具查看数据，与工程取数不一致| [Linux系统时区调整 ](<https://help.fanruan.com/finereport/doc-view-3891.html>)  
  
7| 使用 Linux 系统时，有时我们会遇到中文乱码。出现这个情况一般是由于没有安装中文语言包或者设置的默认语言有问题导致的，可参考本文方法进行排查和解决| [Linux 系统安装中文语言包](<https://help.fanruan.com/finereport/doc-view-2028.html>)
