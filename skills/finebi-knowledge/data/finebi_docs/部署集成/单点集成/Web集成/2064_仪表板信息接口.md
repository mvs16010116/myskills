## 发布管理节点所有仪表板信息
**接口简介**
  
|   
  
---|---  
**接口作用**|  获取发布管理节点下的仪表板信息  
**接口URL**|  /v5/api/dashboard/search  
**请求类型**|  GET  
  
**注意事项**|  使用该接口的用户，必须有发布管理节点权限  
**请求参数-Query参数**
参数名  
| 参数值| 是否必填  
---|---|---  
page| 发布管理的页面页码| 是  
count| 每页信息数量| 是  
  
**响应实例**
  
|   
  
---|---  
**请求示例

## 获取仪表板信息
**接口简介**
  
|   
  
---|---  
**接口作用**|  获取仪表板的信息  
**接口URL**|  /v5/api/platform/dashboard/reports/info  
**请求类型**|  GET  
******请求参数-**Query** 参数**
参数名  
| 参数值| 是否必填| 描述说明  
---|---|---|---  
info| {"index":[ { "id":"仪表板ID" }] }注：参数值格式为JSON，使用时需要进行编码 encodeURIComponent()| 是| id：仪表板ID
