### 功能简介
本文讲解FineBI中仪表板编辑相关接口。
## 分享仪表板给其他用户
**接口简介**
  
|   
  
---|---  
**接口作用**|  通过调用该接口，用户可以将仪表板分享给指定用户  
**接口URL**|  /v5/api/dashboard/share/user/result  
**请求类型**|  GET  
**请求参数-**Query** 参数**
参数名  
| 参数值| 是否必填| 描述说明  
---|---|---|---  
entityId| 仪表板ID| 是| 多个仪表板，可用「,」隔开  
全部仪表板，值为空即可  
userId| 用户ID| 是| 多个用户，可用「,」隔开  
全部用户，值为空即可  
**响应实例**
  
|   
  
---|---  
**请求示例  
**|  http://172.17.0.25:37799/webroot/decision/v5/api/dashboard/share/user/result?entityId=d76fdf3cfb1446aaa450d4668eb18196,b9947708a22e4c58a175019f07e443af&userId=b2e6d799-6a91-4779-aa08-a6d033cefeb5,9ffcfece-80d7-49b2-ac3e-d1f1224bb808&fine_auth_token=xxx注：使用接口时需要登录，需要传递token参数。  
**响应成功**|  callback({ "data": "success"})  
**截图示意**| ![](/core/style/lod.png)

## 仪表板分享给哪些用户
**接口简介**
  
|   
  
---|---  
**接口作用**|  获取该仪表板分享给了哪些用户  
**接口URL**|  /v5/api/dashboard/share/user  
**请求类型**|  GET  
**请求参数-**Query** 参数**
参数名  
| 参数值| 是否必填  
---|---|---  
entityId| 仪表板ID| 是  
page| 页码| 是  
count| 每页数量| 是  
keyword| 关键字| 否  
**响应实例**
  
|   
  
---|---  
**请求示例  
**|  http://172.17.0.25:37799/webroot/decision/v5/api/dashboard/share/user?entityId=6aae904df9284bef823921fac05fb247&page=1&count=2&fine_auth_token=xxx注：使用接口时需要登录，需要传递token参数。  
**响应成功**|  callback({ "success": true, "code": "200", "message": "success", "data": [ "d0fa9ed7-f37c-474a-a157-c4809f4f0c28", "1453b447-5dc8-4d9b-a5ac-20f02db3e9dc" ], "errorCode": null, "detailErrorMsg": null, "errorMsg": null})
