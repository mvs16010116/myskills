### 1.2 应用场景
使用 [后台单点登录插件](<https://help.fanruan.com/finebi6.0/doc-view-1625.html>) 加密用户名登录时，需要手动加密用户名生成 ssoToken 后，再通过浏览器访问http://ip:port/工程名/decision?ssoToken=xxx进行单点登录。用户希望能够免去手动加密的过程，提升加密效率。
### 1.3 功能简介
本文介绍如何通过代码自动生成 ssoToken，并给出 Java 示例代码。  

### 1.4 使用前提
需安装后台单点登录插件，该插件具体介绍请参见：[后台单点登录插件](<https://help.fanruan.com/finebi6.0/doc-view-1625.html>)
