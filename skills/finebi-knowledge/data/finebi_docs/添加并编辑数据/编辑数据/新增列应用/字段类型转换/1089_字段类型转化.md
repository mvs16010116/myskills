## 1\. 概述
### 1.1 预期效果
有时用户需要将「文本」字段转换为「数值」字段类型，例如需要将「购买数量」文本字段转换为数值字段，转换后如下图所示：
![](/core/style/lod.png)
### 1.2 实现思路
对数据进行新增公式列操作，修改字段类型即可。
## 2\. 操作步骤
示例数据：[合同事实表.xlsx](<doc-download-/finebi6.X/uploads/file/20230821/合同事实表.xlsx> "下载资料")
### 2.1 新建分析主题
1）下载示例数据，新建分析主题，添加数据集「合同事实表」；
2）点击「字段设置」，选择对应数据集下的「合同类型」、「购买的产品」文本字段，如下图所示：
![](/core/style/lod.png)
### 2.2 新增列
添加「新增公式列」，命名字段名称为「购买的产品-数值」，选择「文本字段」下的「购买数量」字段，点击字段类型，选择「数值」，点击「确定」，如下图所示：
![](/core/style/lod.png)
### 2.3 效果预览
详情参见本文 1.1 节。
