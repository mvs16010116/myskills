## 1\. 概述
### 1.1 应用场景
用户在进行数据处理时，多个数据表数据经常是分散的，有时候就希望能通过数据表间的某一字段（主键）或者多个字段（联合主键）实现数据表之间的数据匹配查找。
例如，有两张数据表：「互联网_用户信息表」和「互联网_访问统计表」
「互联网_用户信息表」只储存了用户ID，并不知道对应用户的访问时间、访问次数、停留时间等信息，可通过使用左右合并进行关联和查找数据，将数据合并在一张数据表中，方便后续对用户访问数据进行分析。
注：用户 ID 不重复。
![](/core/style/lod.png)
### 1.2 功能简介
在 BI 中可以通过 [左右合并](<https://help.fanruan.com/finebi6.0/doc-view-512.html>) 实现，类似于 Excel 中的 VLOOKUP 函数。
## 2\. 操作步骤
示例数据：[示例数据.zip](<doc-download-/finebi5.1/uploads/file/20210429/示例数据.zip> "下载资料")
### 2.1 新建分析主题
新建分析主题，上传下载的示例数据，如下图所示：
![](/core/style/lod.png)
### 2.2 进行字段匹配
1）选择「互联网_用户信息表」，点击「字段设置」，选择「用户ID」、「用户名称」、「年龄」、「性别」、「用户类型」字段，如下图所示：  

![](/core/style/lod.png)
2）添加「左右合并」步骤，选择「互联网_访问统计表」下的「用户ID」、「访问平台」、「统计日期」、「浏览量」、「访问次数」、「跳出次数」、「总停留时间」，点击「确定」、如下图所示：  

![](/core/style/lod.png)
选择合并方式为「左合并」，合并依据为「用户ID」，则会将不同用户的访问时间、访问次数、停留时间等信息根据「互联网_用户信息表」中「用户ID」进行匹配，并合并在一张表中，如下图所示：
![](/core/style/lod.png)
注：左右合并详情请参见：[左右合并基础功能](<https://help.fanruan.com/finebi6.0/doc-view-512.html>)。
保存数据并更新。  

### 2.3 效果预览
得到将不同用户的访问时间、访问次数、停留时间等信息根据「互联网_用户信息表」中「用户ID」进行匹配后的表，如下图所示：
![](/core/style/lod.png)
