## 1\. 概述
### 1.1 问题现象
用户在编辑数据时使用了一些特殊字符后，出现功能无法使用或报错的现象。
### 1.2 原因分析
数据处理部分特殊字符影响功能使用。
## 2\. 编辑数据不支持的特殊字符
特殊字符  
| 不支持功能  
| 不支持表现  
  
---|---|---  
}| [过滤](<https://help.fanruan.com/finebi6.0/doc-view-507.html>)>公式/函数[新增列](<https://help.fanruan.com/finebi6.0/doc-view-509.html>)>公式/函数| 提示公式不合法  
${xxx}| [选字段](<https://help.fanruan.com/finebi6.0/doc-view-506.html>)  
| 选字段右侧预览区域显示计算结果为空  
. （输入法英文）  
| 添加表中有特殊字符的关联表字段做数据处理| 基础表关联字段名带有 .会导致关联生成失败，在处理数据时无法选择关联表字段。  
## 3\. 使用时需处理的特殊字符
### 3.1 问题描述
添加 [新增列](<https://help.fanruan.com/finebi6.0/doc-view-509.html>) 使用 [FIND](<https://help.fanruan.com/finebi6.0/doc-view-1468.html>) 公式，在查找”符号输入 FIND（"""），显示公式不合法，如下图所示：
![2022-11-23_16-23-20.png](/core/style/lod.png)
### 3.2 解决方法
在使用 Find 公式查找一些特殊符号时，需要在符号前面加\进行转义。
例如需要使用 [FIND](<https://help.fanruan.com/finebi6.0/doc-view-1468.html>) 函数找到 " 在数值中的位置，则可以使用 FIND("\"",字段名)，其中\"代表一个双引号字符，如下图所示：
![2022-11-23_16-25-25.png](/core/style/lod.png)
可以看到新增列中显示 ID 字段中 " 存在的位置，没有则显示 0 ，如下图所示：
![2022-11-23_16-28-00.png](/core/style/lod.png)
