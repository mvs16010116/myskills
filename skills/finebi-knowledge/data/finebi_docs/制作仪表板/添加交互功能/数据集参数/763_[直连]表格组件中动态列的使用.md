## 1\. 概述
### 1.1 预期效果
用户可以根据需要动态切换列，灵活查询。可切换出三个维度下的指标数据。
例如，通过文本下拉控件切换出「用户 ID」、「统计日期」和「访问平台」的「浏览量统计」。如下图所示：
![11.gif](/core/style/lod.png)
### 1.2 实现思路
使用过滤组件和动态参数配合，可以实现动态列切换。过滤组件参数的使用请参见：[过滤组件的参数用法](<https://help.fanruan.com/finebi6.0/doc-view-381.html>)
## 2\. 示例
示例数据：[互联网访问统计表 .xlsx](<doc-download-/finebi6.X/uploads/file/20220928/互联网访问统计表 .xlsx> "下载资料")
### 2.1 添加维度名称数据集
1）若同时拥有「抽取数据」和「直连数据」功能，则需要在数据列表中切换为「直连数据」。然后在公共数据中，点击「新建数据集 SQL 数据集」，如下图所示：
注：只有 [数据处理用户](<https://help.fanruan.com/finebi6.0/doc-view-370.html?source=4##5>) 可以创建 SQL 数据集。
![21.png](/core/style/lod.png)
2）设置表名为「访问数据统计」，输入 SQL 语句：SELECT COLUMN_NAME FROM information_schema.columns WHERE table_name='互联网_访问统计表' ，如下图所示：
![5.png](/core/style/lod.png)
### 2.2 添加直连参数 SQL 数据集
1）添加 SQL 数据集，命名为「动态参数」，输入SQL 语句：select 浏览量 ,<parameter> ${col} </parameter> as 动态列 from 互联网_访问统计表或 SELECT COLUMN_NAME FROM information_schema.columns WHERE table_name='互联网_访问统计s表' 设置参数类型为文本，默认值手动输入一个类型为文本的维度名，如下图所示：
注：若是维度中有日期类型的字段，不要将其设置为默认值。  

![6.png](/core/style/lod.png)  

将表添加分析主题。如下图所示：
![2023-12-21_10-29-58.png](/core/style/lod.png)
### 2.3 制作分组表
注：先添加需要动态列的图表组件，再添加过滤组件。  

1）使用「动态参数」数据制作一张分组表，拖入字段，如下图所示：
![2023-12-21_10-29-19.png](/core/style/lod.png)
### 2.4 过滤组件绑定参数
1）添加仪表板，将制作的分组表拖进仪表板中。并新增「文本下拉」过滤组件，如下图所示：
![2023-12-21_10-29-12.png](/core/style/lod.png)
2）设置文本下拉过滤组件，字段选值「COLUMN_NAME」，参数选择动态参数「col」，点击确定，。
注：要为过滤组件选择一个默认值。如果是空值的话，未进行筛选前表格组件的动态列为空值，会显示报错，在过滤组件选值后才会恢复正常状态。
![2023-12-21_10-32-11.png](/core/style/lod.png)
3）若是只需要在「统计日期」、「访问平台」、「用户ID」三个维度之间切换，可以对字段「COLUMN_NAME」进行过滤，如下图所示：
![2023-12-21_10-33-51.png](/core/style/lod.png)
### 2.5 效果查看
切换文本下拉框的值，可以切换表格组件的维度，如下图所示：
![11.gif](/core/style/lod.png)
