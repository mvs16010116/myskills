##  1\. 概述
### 1.1 应用场景
在很多分析场景下，用户想要直观展示不同省份和地区的数据，分析不同省份和地区的数据情况，同时需要实现不同省份和地区对于某特定指标的程度进行区分。
例如：年度总结时，用户需要在地图上展示各省市的销售额，点击省份可查看该省下不同地区的销售额，且地图根据销售额大小程渐变效果。
### 1.2 功能简介
用户可根据实际需求可以实现由省到市的逐级钻取，并对不同省份和区域的数据进行展示。如下图所示：
![9.gif](/core/style/lod.png)
## 2\. 中国地图钻取
示例数据：[客户维度表.xlsx](<doc-download-/finebi6.X/uploads/file/20230821/客户维度表.xlsx> "下载资料")
### 2.1 创建钻取目录
1）使用 「客户维度表」添加组件，创建从省份钻取到城市的客户分布数据，选择维度下的「省份」字段，将其转换为地理角色，详细操作步骤可参考 [维度转化为地理角色](<https://help.fanruan.com/finebi6.0/doc-view-105.html>) 。如下图所示：
![1.png](/core/style/lod.png)
2）选择「城市」字段转换为地理角色，生成城市的经纬度字段，如下图所示：
![2.png](/core/style/lod.png)
3）经纬度字段转化好以后，将城市字段拖至省份字段处，创建「省份-城市」的钻取目录，自动生成钻取目录的名称，点击确定保存。如下图所示：
![3.gif](/core/style/lod.png)
省份和城市将会自动生成经纬度的钻取目录，如下图所示：
![4.png](/core/style/lod.png)
注：目前 BI 地图中的北京市、上海市、天津市、重庆市、台湾省、香港特别行政区、澳门特别行政区都是算作省份级别的，若需要实现钻取，需要在直辖市和特别行政区下新增区/县的json文件，具体情况参见：[直辖市匹配地理角色(城市)](<https://help.fanruan.com/finebi6.0/doc-view-847.html>)
### 2.2 创建图表
1）在图表类型中选择「区域地图」，将「省份，城市（经度）」和「省份，城市（纬度）」字段拖至横纵轴中，如下图所示：
![](/core/style/lod.png)
2）图表中显示了客户覆盖的省份，但还没能实现钻取的效果，需要我们将创建的钻取目录字段拖至图形属性下「颜色、标签、提示、细粒度」中的其中任意一个即可。如将该字段拖至细粒度下，如下图所示：
![](/core/style/lod.png)
### 2.3 设置数据
1）将指标下的「记录数」拖入图形属性中的「颜色」栏，如下图所示：
![](/core/style/lod.png)
2）点击「颜色」栏，渐变类型选择「区域渐变」，渐变方案选择「秋落」。如下图所示：
![8.png](/core/style/lod.png)
### 2.4 效果预览
如本文 1.2 节所示。
## 3\. 世界地图钻取
想要制作一张国家-省份-城市的城市钻取地图，国家有两个：中国和法国。  

### 3.1 准备条件
法国的 json 文件：[法国](<doc-download-/finebi6.X/uploads/file/20220809/法国 json 文件.zip> "下载资料")
示例数据：[示例数据.xlsx](<doc-download-/finebi6.X/uploads/file/20220922/示例数据.xlsx> "下载资料")
存放 json 文件的路径：%FineBI_HOME%\webapps\webroot\WEB-INF\assets\map\geographic\world\中国\
1）下载并解压法国的 json 文件，复制文件名为「法国」中所有的数据至「中国」文件夹下，如下图所示：
![1.png](/core/style/lod.png)
2）用编辑器打开「法国-area.json」文件和「中国-area.json」文件，将「法国-area.json」文件中 **[ ]** 之间的内容全部复制到「中国-area.json」中，保存一下，如下图所示：
![5.png](/core/style/lod.png)
3）管理员在「管理系统>地图配置」中点击「同步地理文件」使之前的配置生效，如下图所示：
![](/core/style/lod.png)
### 3.2 创建钻取目录
1）使用示例数据[创建分析主题](<https://help.fanruan.com/finebi6.0/doc-view-1889.html>)，选择维度下的「国家」字段，将其转换为地理角色，详细操作步骤可参考 [维度转化为地理角色](<https://help.fanruan.com/finebi6.0/doc-view-105.html>) 。如下图所示：
![4.png](/core/style/lod.png)
2）选择「省份」字段转换为地理角色，如下图所示：
  

![6.png](/core/style/lod.png)
3）选择「城市」字段转换为地理角色，如下图所示：
![7.png](/core/style/lod.png)
4）经纬度字段转化好以后，将「省份」字段拖至「国家」字段处，创建「国家-省份」的钻取目录，自动生成钻取目录的名称，点击确定保存，将「城市」加入创建的钻取目录。如下图所示：
![8.gif](/core/style/lod.png)
### 3.3 创建图表
1）在图表类型中选择「区域地图」，将「省份，城市（经度）」和「省份，城市（纬度）」字段拖至横纵轴中，如下图所示：
![9.png](/core/style/lod.png)
2）现在还没能实现钻取的效果，需要我们将创建的钻取目录字段拖至图形属性下（颜色、标签、提示和细粒度中的其中任意一个即可）。如将该字段拖至细粒度下，如下图所示：
![10.png](/core/style/lod.png)
### 3.4 设置数据
将指标下的「数值」拖入图形属性中的「颜色」栏和「标签」栏，如下图所示：
![11.png](/core/style/lod.png)
