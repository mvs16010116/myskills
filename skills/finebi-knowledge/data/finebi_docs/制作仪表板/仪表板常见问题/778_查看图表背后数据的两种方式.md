## 1\. 概述
### 1.1 预期效果
模板中只显示图表，相关表格需要点击后才显示。如下图所示（以下为方案2的效果展示）：
![跳转.gif](/core/style/lod.png)
### 1.2 实现思路
实现思路如下表所示：  

  
| 实现思路| 优缺点  
---|---|---  
方法一| 通过FineBI自带的查看明细功能显示隐性数据。| 方便快捷，用表格展示组件全部数据详情。  
方法二| 通过仪表板之间的跳转显示隐性数据。| 应用广泛，可自定义显示内容。  
## 2\. 方案一：查看明细
组件查看明细详细请参考：[组件查看明细](<https://help.fanruan.com/finebi6.0/doc-view-190.html>)
### 2.1 操作方法
使用 Demo 数据表销售Demo>地区数据分析，制作一张仪表板，并进入预览界面，如下图所示：  

![](/core/style/lod.png)
### 2.2 效果查看
点击组件，选择下拉>查看明细，即可出现图表所用的原始数据表。如下图所示：
![仪表板预览.gif](/core/style/lod.png)
## 3\. 方案二：设置跳转
使用多个仪表板，点击图表跳转到表格所在仪表板，实现表格的隐性显示。
### 3.1 新建仪表板
1）使用 Demo 数据「地区数据分析」新建「仪表板」，如下图所示：  

![](/core/style/lod.png)
2）使用 Demo 数据「KPI指标项」新建「仪表板1」，如下图所示：
![](/core/style/lod.png)
### 3.2 设置跳转
1）编辑「仪表板」，选择组件，点击下拉>跳转设置，如下图所示：
![](/core/style/lod.png)
2）弹出跳转设置页面，选择跳转到「仪表板1」，如下图所示：
![](/core/style/lod.png)
### 3.3 效果查看
点击「仪表板1」中的一个字段，再点击跳转到分析模板，即可实现跳转到表格，如下图所示：
![跳转.gif](/core/style/lod.png)
组件跳转还可以实现传值功能，在跳转的同时实现过滤功能。比如说点击北京柱形，可以跳转到表格并将表格北京市数据筛选出来，详细请参考：[组件跳转](<https://help.fanruan.com/finebi6.0/doc-view-149.html>)
