## 亮点功能上新
### 数据表可查看血缘层级
当数据表的血缘层级变得很深的时候，我们会发现这张表：
  * 出现问题很难找到原因，维护很困难；
  * 溯源困难，难以阅读和理解这张表；
  * 父表特别多，它的一张父表出现问题，这张表就不能用，稳定性和可用性极其脆弱；


为了解决这个问题，我们推出了一下新功能：  

  * 血缘层级数显示：我们在血缘分析数据表的信息中新增了血缘层级数，用户可以轻松查看当前数据表所在的层级。这个功能可以帮助用户更好地理解和使用数据表；
  * 血缘层级限制：新版本对数据表层级进行了限制，最高层级不超过 16 ，避免不当操作导致的血缘层级过深；
  * 发布管理和公共数据管理界面增加血缘层级显示：帮助用户更好的管理公共数据的血缘关系；


除了新功能，本次更新也增加了使用规范和建议，帮助用户进一步简化血缘层级，详情请参见：[血缘层级](<https://help.fanruan.com/finebi6.X/doc-view-77.html>)
![](/core/style/lod.png)
### 移动端优化
1）移动端 web 组件优化，点击 web 组件右上角按钮，可以打开新页面并跳转到对应链接，如下图所示：  

详情请参见：[Web组件](<https://help.fanruan.com/finebi6.X/doc-view-143.html>)
![](/core/style/lod.png)
2）优化移动端表格的自动换行：之前单元格中只能显示两行内容容易显示不全；优化后单元格中最多可展示 10 行内容；
3）表格冻结列自适应优化：在移动端中表格冻结列无法自动调整，有时候占据整个组件不方便查看；优化后冻结列总宽度最多不超过组件宽度的 60%，优化查看体验。
