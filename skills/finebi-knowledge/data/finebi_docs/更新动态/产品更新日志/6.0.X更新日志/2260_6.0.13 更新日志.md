## 3\. 公共数据
### 3.1 活跃表逻辑优化
优化之前：当一张表更新完成之后，才会修改它的状态为「活跃」。
优化之后：当一张表触发更新时，就会修改它的状态为「活跃」，如此可以避免重复触发该表的更新。另外定时调度推送的仪表板在 6.0.13 中也会加入活跃逻辑。
详情请参见：[自助数据集更新](<https://help.fanruan.com/finebi6.X/doc-view-1498.html>)
## 4\. 我的分析
### 4.1 DEF 合计行逻辑优化
优化前：当「合同签约时间」收起时，DEF_ADD 和 DEF_SUB 会使用图表中所有维度包括「合同签约时间」进行计算。
合计行值是使用所有维度求得的结果进行合计，所以得到的合计值常常不是我们需要的合计值。  

![](/core/style/lod.png)
优化后：当「合同签约时间」收起时，DEF_ADD 和 DEF_SUB 函数的计算也不会使用到「合同签约时间」，自动使用当前图表中用到的维度进行计算。
最后得到的结果更符合我们的使用习惯。
![](/core/style/lod.png)
详情请参见：[DEF_ADD](<https://help.fanruan.com/finebi6.X/doc-view-1987.html>)
### 4.2 点击数据可取消联动
若组件上只设置了联动，联动生效后，再次点击数据点直接取消联动效果。
详情请参见：[联动](<https://help.fanruan.com/finebi6.X/doc-view-150.html>)
![1.gif](/core/style/lod.png)

详情请参见：[组件设置联动](<https://help.fanruan.com/finebi6.X/doc-view-150.html>)

## 5\. 平台
### 5.1 支持显示备案信息
管理员可以控制登录页底部是否显示备案信息，默认关闭。
详情请参见：[登录页](<https://help.fanruan.com/finebi6.X/doc-view-986.html>)
![2.png](/core/style/lod.png)
### 5.2 新增 URL 分号过滤机制
Tomcat 解析用户请求的 URL 时，若 URL 中含有分号，则会过滤掉分号与斜杠之间的内容并标准化处理。攻击者可利用此特性绕过权限验证，危害系统安全。  

6.0.13 及之后版本，FineBI 新增 URL 配置项，可以禁止在 URL 中使用分号，以防止路径遍历、权限绕过、URL混淆和欺骗等安全问题，提升系统的安全性。
详情请参见：[安全防护](<https://help.fanruan.com/finebi6.X/doc-view-781.html>)
![](/core/style/lod.png)
### 5.3 平台日志优化
1）「访问统计-系统访问次数」中，支持统计移动端访问模板的记录
2）「管理日志」新增记录场景，如：清除所有用户、新建脱敏规则等操作场景
详情请参见：[平台日志](<https://help.fanruan.com/finebi6.X/doc-view-677.html>)
## 6\. 移动端
### 6.1 移动端样式优化
1）PC端设置的组件样式，支持在移动端显示。比如说：组件圆角效果、边框效果、标题居中等；
2）优化移动端适配的样式：展示完整的气泡图、图例位置优化、分组表分页行数继承 PC 端行数设置；
3）支持数据门户中组件高度自适应
### 6.2 钻取效果优化
组件需只有单个钻取选项且单个钻取目录，直接进行钻取，不需要进行选择，简化操作。
若有多个钻取选项，或者多个钻取目录，则依旧会出现提示框。
注：若一个组件同时存在跳转、联动、钻取任意两个或三个，则同样会出现提示框。
![1.gif](/core/style/lod.png)
### 6.3 钉钉管理插件支持自定义请求头内容
为满足用户对身份验证、数据加密、访问控制等定制化场景的需求，钉钉管理插件支持通过「键-值」自定义多个请求头内容，以实现更灵活的集成方式。
详情请参见：[钉钉管理插件](<https://help.fanruan.com/finebi6.X/doc-view-351.html>)
![](/core/style/lod.png)
## 7\. 引擎
在直连数据模式下，加速引擎可以提高大数据场景下数据应用的效率，实现更高的性能和满足大规模数据处理的需求。
如要使用加速引擎，可以在「加速引擎」功能下配置加速库，并监控加速库中的数据性能 。
用户可以配置 StarRocks 加速库，并监控数据性能。  

  * 加速引擎：配置一个数据库作为加速库，并监控加速库的状态（仅支持 StarRocks 数据库作为加速库）；
  * SQL分析：监控 FineBI 中 SQL 的执行速度和性能；
  * Excel 上传记录：查看 Excel 的上传情况；


详情请参见：[加速引擎](<https://help.fanruan.com/finebi6.X/doc-view-2258.html>)
