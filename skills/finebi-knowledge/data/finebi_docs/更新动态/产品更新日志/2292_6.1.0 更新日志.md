## 4\. 分析主题框架 | 一站式分析，制作提升效率
![2024-05-10_14-01-29.png](/core/style/lod.png)  

业务人员或分析师，在进行数据分析的过程中，一定会遇到需要调整数据的情况。
  * FineBI 6.0： 数据经过编辑后需要保存，更新后要等待更新，才能使用新字段。如果更新时间长，分析思路会被打断，分析的效率也会大大降低。
  * FineBI 6.1： 提供主题级别的分析体验。主题内数据编辑到可视化分析无需等待，结束后「保存」并「更新」主题即可。


![2024-05-10_11-40-18.png](/core/style/lod.png)
例如，在编辑数据中新增的毛利额，无需更新，直接在组件中拖入即可查看毛利情况。如下图所示：
![2024-05-10_11-37-16.gif](/core/style/lod.png)
完成主题编辑后，退出前「保存」分析主题即可，解决仪表板发布之后，任何实时编辑会直接被用户看到的问题。
如果您的主题仅供个人分析使用，没有发布、公共链接等共享场景，则完成后「保存」分析主题，无需「更新」数据。
详情可参见：[保存分析主题](<https://help.fanruan.com/finebi6.X/index.php?doc-view-2288>)
![2024-06-13_10-36-08.png](/core/style/lod.png)

### 4.3 新增版本管理
**应用场景**
1）历史溯源：例如，数据分析需要尝试不同的处理方式，提前“存档”有助于回到最初的状态部门的业务逻辑变化。
2）内容暂存：在修改发布内容时，短时间无法处理完，可以存档以便下次续写
**功能简介**
在分析主题上方点击「...」即可将当前主题「保存为版本」，或者对已保存的版本进行管理。如下图所示：
![2024-05-11_13-54-50.png](/core/style/lod.png)
  * 「保存为版本」：将当前主题的所有临时配置另存一份；相当于一个配置备份。
  * 「版本管理」：能够修改版本名称、备注，读取、删除已保存的版本。


![2024-05-11_13-53-11.gif](/core/style/lod.png)
详情请参见：[主题版本](<https://help.fanruan.com/finebi6.X/doc-view-2291.html?source=4>)
### 4.4 数据量优化
主题编辑过程中，数据量是主题层面的功能限制，对直连/抽取类型、数据集/组件/仪表板/分析文档都有影响。


1）主题内所有资源的来源表只受到当前主题的数据量限制，不会再受到父表更新状态的影响，导致没有数据；
2）数据量设置入口变化。从编辑数据页面改到分析主题顶部。
详情请参见：[数据量说明](<https://help.fanruan.com/finebi6.X/doc-view-1959.html>)

## 6\. 可视化分析
### 6.1 新增过滤器
这次新版本组件仪表板中过滤与计算层级专题优化，组件内支持指标在「过滤器」内明细过滤。  

用户在分析区域做的过滤设置（胶囊下拉，表头过滤等）都会集中在这里显示，实现交互入口统一，方便用户明确当前设置了哪些过滤。
详情请参见：[过滤器](<https://help.fanruan.com/finebi6.X/doc-view-2403.html>)、[过滤层级是什么](<https://help.fanruan.com/finebi6.X/doc-view-2405.html>)
![2024-05-10_17-31-19.png](/core/style/lod.png)
**常见问题：**
**1）当前版本的过滤器和之前的结果过滤器的区别：**
过滤器和结果过滤器是包含关系，结果过滤器的效果被包含在过滤器中，过滤器可以设置所有的过滤。
**2）如何去使用过滤器：**
所有的待分析区域字段的过滤都推荐通过拖入过滤器进行过滤的方式进行。
### 6.2 新增 CLEAN 函数
分析函数新增 CLEAN 函数，可以与 DEF 函数配套使用。在执行计算时清除指定字段的过滤效果。
语法：CLEAN(字段1,字段2,字段3....)/CLEAN("ALL")。
例如，过滤某月的产品订单最高金额，同时希望和历史情况进行对比。在 DEF 函数中使用 CLEAN 函数，即可忽略掉「过滤器」和仪表板中的过滤效果。得到历史的产品订单最高金额=DEF_ADD(MAX_AGG(订单金额﻿}),[],[CLEAN(﻿订单日期﻿)])
组件中：  

![2024-05-08_14-27-07.png](/core/style/lod.png)
仪表板中：
![2024-05-08_14-29-35.png](/core/style/lod.png)
注：待分析区域的指标条件过滤无法清除。
函数详情请参见：[CLEAN函数](<https://help.fanruan.com/finebi6.X/doc-view-2407.html>)、 [CLEAN_WIDGET函数](<https://help.fanruan.com/finebi6.X/doc-view-2408.html>)

## 8\. 平台
### 8.1 系统资源限制配置项
BI软件在作为自助分析平台推广时，一大问题是业务分析时太过自由，他们很有可能在无意中建立了超出平台性能的分析内容，例如：血缘过深的数据集，嵌套多层的def公式计算.....
从而进一步导致整体平台卡顿，性能下降，甚至出现宕机风险。这对IT管理员来说是非常头疼的。
FineBI 6.1在「系统管理」界面提供参数以及白名单功能，方便管理员对”查询计算“、“数据更新”、“数据访问”，三个模块进行限制。提前规避不规范的使用带来的平台宕机风险。
详情请参见：[BI/Spider参数](<https://help.fanruan.com/finebi6.X/doc-view-312.html>)
![2024-05-11_16-39-38.png](/core/style/lod.png)
