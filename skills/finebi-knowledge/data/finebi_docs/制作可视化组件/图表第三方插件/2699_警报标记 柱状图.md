## 1\. 概述
插件警报标记/柱状图（Alert Markers/Column Chart）可展示任务状态、业务执行情况，通过“标记 + 柱状图”两层结构，让用户快速发现异常、任务完成情况等。
图表可分为两层：
  * 第一层（顶层）：展示标记（Marker）图标/表情/交通灯/动画等，用于表达状态（如完成/未完成、好/差），这些标记也会随着数据变化自动更换图片。
  * 第二层（展开层）：柱状图点击某个标记（Marker）后进入，展示详细数据。支持通过调整图标的条件格式（例如：达标为绿色，不达标为红色）来自定义。

### 3.2 创建图表
点击左下角「组件」按钮，在图表类型下选择「Alert Markers / Column Chart」，将左侧待分析区域的字段依次拖入对应下图的属性栏中。如下图所示：
![2025-12-03_10-13-45.png](/core/style/lod.png)
### 3.3 图表设置
1）点击「组件样式」，向下找到「图片标记1」，此处用于调整第一张图片的显示。在编辑框中将原有字段按照实际表进行修改。
图像选择公式 1 ：（当满足条件时使用对应的图片）
[code]
    =IFS(  
      SUMIF([实际销量];[品类]="冰箱")>=SUMIF([目标销量];[品类]="冰箱");1;  
      SUMIF([实际销量];[品类]="冰箱")>=0.9*SUMIF([目标销量];[品类]="冰箱");2;  
      SUMIF([实际销量];[品类]="冰箱")<0.9*SUMIF([目标销量];[品类]="冰箱");3  
    )  
    
[/code]
提示内容公式 1 ：（当满足条件时使用对应的悬浮提示信息）
[code]
    =IFS(  
      SUMIF([实际销量];[品类]="冰箱")>=SUMIF([目标销量];[品类]="冰箱");"达成目标，一切正常，点击查看详情";  
      SUMIF([实际销量];[品类]="冰箱")>=0.9*SUMIF([目标销量];[品类]="冰箱");"接近未达成，高风险区，查看详情";  
      SUMIF([实际销量];[品类]="冰箱")<0.9*SUMIF([目标销量];[品类]="冰箱");"未完成计划，点击查看详情"  
    )  
    
[/code]
![2025-12-03_13-48-43.png](/core/style/lod.png)
公式解释：
SUMIF([实际销量];[品类]="冰箱")>=SUMIF([目标销量];[品类]="冰箱");1;| 当冰箱实际总销量 >= 冰箱目标总销量时，显示图片 1，否则向下执行判断。在提示内容公式中，如果满足条件，则输出「达成目标，一切正常，点击查看详情」。  
---|---  
SUMIF([实际销量];[品类]="冰箱")>=0.9*SUMIF([目标销量];[品类]="冰箱");2;| 当冰箱实际总销量 >= 0.9 * 冰箱目标总销量，显示图片 2 ，否则向下执行判断。  
SUMIF([实际销量];[品类]="冰箱")<0.9*SUMIF([目标销量];[品类]="冰箱");3| 当冰箱实际总销量 < 0.9 * 冰箱目标总销量，显示图片 3 。  
IFS()| 从左到右依次判断条件并返回值。
