## 1\. 概述
插件表图（Table）比传统表图具备更强的数据表达力和交互能力，具有丰富的可视化元素、超过 70+ 的可视化调节参数，支持条件格式、动态图标与图片嵌入。
### 1.1 版本
FineBI 版本| 插件版本| 功能变动  
---|---|---  
6.1| 1.0. X| -  
### 1.2 应用场景
下图为 F1 车手综合表现榜单。该榜单基于 2023–2024 两个赛季的核心竞技数据，通过图标、进度条等，构建出一套高度可读且专业的排行榜。
![Snipaste_2025-12-05_18-09-09.png](/core/style/lod.png)

## 3\. 示例
### 3.1 准备数据
1）用户登录 FineBI 系统，点击「我的分析」，点击「新建分析主题」。如下图所示：
![2025-11-12_11-09-02.png](/core/style/lod.png)
2）点击「本地Excel文件>上传数据」，上传数据。如下图所示：
示例数据：[table_data.xlsx](<doc-download-/finebi6.X/uploads/file/20251118/table_data.xlsx> "下载资料")
![2025-11-12_11-05-18.png](/core/style/lod.png)
### 3.2 创建图表
1）点击左下角「组件」按钮，在图表类型下选择本图标，然后按照下图拖入对应的字段，如下图所示：
![Snipaste_2025-12-05_17-44-54.png](/core/style/lod.png)
2）设置图表第二列的显示。在「组件样式 > Column 2 > Replace value」输入代码：
=ONLINE( TABLEPICS([@车手姓名];"Max Verstappen";1;"Lando Norris";2;"Charles Leclerc";3;"Oscar Piastri";4;"Carlos Sainz";5;"George Russell";6;"Lewis Hamilton";7;"Sergio Perez";8;"Fernando Alonso";9;"Pierre Gasly";10;"Nico Hulkenberg";11;"Yuki Tsunoda";12;"Lance Stroll";13;"Esteban Ocon";14;"Kevin Magnussen";15;);[@Pilot name])
![Snipaste_2025-12-05_17-50-04.png](/core/style/lod.png)
3）设置图表的第三列显示。在「组件样式 > Column 3 > Replace value」输入代码：
=ONLINE( TABLEPICS([@车手姓名];"Max Verstappen";17;"Lando Norris";19;"Charles Leclerc";19;"Oscar Piastri";18;"Carlos Sainz";19;"George Russell";20;"Lewis Hamilton";20;"Sergio Perez";17;"Fernando Alonso";21;"Pierre Gasly";22;"Nico Hulkenberg";23;"Yuki Tsunoda";24;"Lance Stroll";21;"Esteban Ocon";22;"Kevin Magnussen";23;))
![Snipaste_2025-12-05_17-51-46.png](/core/style/lod.png)
4）设置图表的第四列显示。在「组件样式 > Column 4 > Replace value」，取消勾选「Calculate the value using the formula」，如下图所示：
![Snipaste_2025-12-05_18-21-04.png](/core/style/lod.png)
5）设置图表第六、第七列显示。在「组件样式 > Column 6 > Replace value」，取消勾选「Calculate the value using the formula」，与第四列操作相同，固不在提供配图。设置之后如下图所示：
![Snipaste_2025-12-05_18-09-09.png](/core/style/lod.png)
