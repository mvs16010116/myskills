## 1\. 概述
插件误差图（Error Chart）用于可视化数据的波动情况，以直观展示偏差。  
误差图可以显示数据分布（如标准差、置信区间、测量误差）、辅助评估统计显著性、避免对平均值的误读，并清晰呈现结果中的不确定性程度。
### 1.1 版本
FineBI 版本| 插件版本| 功能变动  
---|---|---  
6.1| 1.0. X| -  
### 1.2 应用场景
以下图表主要展示了在多个服务（Service）中所需要花费的天数，蓝色柱体表示办理服务的平均天数，红色和绿色线表示每个服务对应时间的最大值和最小值波动范围。通过条件格式设定安全值，当超出安全值时，可以实现醒目提示：红色波动较大，绿色为可接受波动。

## 3\. 示例
### 3.1 准备数据
1）用户登录 FineBI 系统，点击「我的分析」，点击「新建分析主题」。如下图所示：
![2025-11-12_11-09-02.png](/core/style/lod.png)
2）点击「本地Excel文件>上传数据」，上传数据。
示例数据：[error_data.xlsx](<doc-download-/finebi6.X/uploads/file/20251204/error_data.xlsx> "下载资料")
### 3.2 创建图表
在组件编辑界面完成基础数据的映射。进入组件编辑：点击底部的 组件 标签页。选择图表类型：在图表类型面板中，选择 Error Chart（插件图标）。并按照下图拖入数据字段：
![2025-12-03_16-47-31.png](/core/style/lod.png)
### 3.3 配置图表
1）配置误差线颜色。切换到组件样式面板，置条件格式：点击 Conditional formatting (条件格式)，输入公式来定义红绿误差线的显示逻辑。
公式：CONDFORMAT("Color of Error";[@办理时长波动率 (%)]>50;"red")
![2025-12-03_16-47-21.png](/core/style/lod.png)
2）设置 X 轴标题。在「X-axis > Name (名称)」文本框中输入 公共服务名称。设置颜色为自动，如下图所示：
![new 2025-12-03_17-08-13.png](/core/style/lod.png)
3）设置 X 轴数据标签，显示柱状图的具体数值。在「X-axis > Signatures (标签/数值)」勾选 Display 复选框，使数值显示在柱体上。然后设置颜色及字号大小，如下图所示：
![2025-12-03_17-08-13.png](/core/style/lod.png)
4）设置 Y 轴标题。在「Y-axis > Name (名称)」文本框中输入 个工作日。设置颜色为自动，将 Position 设置为 Above (轴上方)，以便清晰展示单位。设置旋转 Turn (旋转角度) 为 0。如下图所示：
![2025-12-03_17-00-50.png](/core/style/lod.png)
5）设置 Y 轴数据标签。在「Y-axis > Signatures (标签/数值)」勾选 Display 复选框，然后设置颜色及字号大小，如下图所示：
![2025-12-03_17-03-08.png](/core/style/lod.png)
6）设置悬浮提示。点击「Tooltip (提示) > Contents of the hint (提示内容)」，框中可自定义想要展示的字段组合，如下图所示：
公式：=[@公共服务名称]& ": 办理时长波动率"&[@办理时长波动率 (%)] & "%"
![2025-12-03_16-52-11.png](/core/style/lod.png)
7）隐藏图示。点击 Legend (图例)，取消勾选 Display，如下图所示：
![2025-12-03_17-38-02.png](/core/style/lod.png)
8）最终效果如下图所示：
![PixPin_2025-12-03_17-26-04.png](/core/style/lod.png)
