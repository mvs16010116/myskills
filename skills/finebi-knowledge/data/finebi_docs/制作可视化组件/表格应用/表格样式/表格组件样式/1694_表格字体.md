## 1\. 概述
### 1.1 版本
FineBI 版本| 功能变动  
  
---|---  
6.0| -  
### 1.2 应用场景
需要对表格的字体样式进行设置时。  

例如，设置表格字体为「黑体」，表头和表身的维度字段为「居中」显示，表身的指标字段为「居左」显示，如下图所示：
![](/core/style/lod.png)
### 1.3 功能简介
使用「组件样式>表格字体」功能，即可对表格的字体、颜色、字号、是否居中显示、加粗显示等进行设置。
## 2\. 操作步骤
### 2.1 准备数据
1）用户登录 FineBI 系统，点击「我的分析」，选中某个文件夹，点击「新建分析主题」。如下图所示：
![](/core/style/lod.png)
2）点击「本地Excel文件>上传数据」，上传表数据。如下图所示：
示例数据：[地区数据分析.xlsx](<doc-download-/finebi6.X/uploads/file/20240408/地区数据分析.xlsx> "下载资料")
![](/core/style/lod.png)
3）上传后，点击「确定」按钮。如下图所示：
![](/core/style/lod.png)
4）点击「保存并更新>退出并预览」，数据创建成功。
![](/core/style/lod.png)
### 2.2 创建组件
1）点击左下角「组件」按钮。
2）在图表类型下选择「分组表」。
3）将待分析区域的「省份」「城市」拖入维度栏，「合同金额」「回款金额」拖入指标栏，如下图所示：
![](/core/style/lod.png)
### 2.3 设置表格字体
表格字体样式有两种选项：  

样式  
| 说明  
---|---  
自动| 按照系统默认设置表格字体和样式
  * Mac 系统下默认使用苹方
  * Windows 系统下默认使用微软雅黑

  
自定义| 可对表格的「表头」和「表身」字体自定义设置  
1）点击「组件样式>表格字体」，选择「自定义」。
2）设置表头和表身的字体均为「黑体」，表头和表身的维度字段均为「居中」显示，表身的指标字段为「居左」显示，如下图所示：
![](/core/style/lod.png)
3）支持自定义的表格字体样式：
设置项| 说明  
---|---  
字体| 默认、黑体、宋体、仿宋、楷体、优设标题黑、庞门正道标题体、Arial、Helvetica Neue、Verdana、Times New Roman、液晶数字字体、Poppins Bold  
字号| 12-128  
加粗| -  
斜体| -  
下划线| -  
字体颜色| -  
居中、居左、居右显示| -  
### 2.4 创建仪表板
1）点击分析主题编辑界面下方添加仪表板。
2）进入仪表板编辑界面，将组件拖入至仪表板中。如下图所示：
![](/core/style/lod.png)
3）下拉选择「编辑标题」，样式选择「自定义」，设置标题为「表格字体」，点击「确定」。如下图所示：
![](/core/style/lod.png)
