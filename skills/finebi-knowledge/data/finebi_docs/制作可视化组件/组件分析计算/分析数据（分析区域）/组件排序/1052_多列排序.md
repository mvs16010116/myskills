## 1\. 概述
### 1.1 预期效果
多列排序就是先按照条件 1 对 A 列进行总体排序，再对按照条件 2 在满足 A 列排序的前提下，对 B 列进行组内排序。
例如，在商品订单详情中，需要按照「订购日期」升序，再满足这一排序前提下，再对「订购日期」内每天的商品订购「数量」进行降序排列。效果如下图所示：
![](/core/style/lod.png)
### 1.2 实现思路
1）先实现总体排序：设置「商品订购日期」升序。
2）再实现组内排序：通过对「商品」按照「数量」降序排列，实现商品「数量」降序。
## 2\. 仪表板操作步骤
示例数据：[多列排序-商品订单.rar](<doc-download-/uploads/file/20200904/多列排序-商品订单.rar> "下载资料")
### 2.1 新建分析主题
新建分析主题，上传下载的示例数据，如下图所示：
![](/core/style/lod.png)
### 2.2 添加组件
添加数据后，点击右下角「添加组件」，如下图所示：  

![](/core/style/lod.png)
### 2.3 添加分组表
添加组件后跳转至组件编辑界面，添加分组表。图表类型选择「分组表」，将待分析区域字段拖入维度指标栏。如下图所示：  

![](/core/style/lod.png)
### 2.4 多列排序
1）先对「订购日期」实现升序排序。点击「订购日期」旁边的「![image.png](/core/style/lod.png)>升序」，完成分组表按「订购日期」升序排列。如下图所示：
![](/core/style/lod.png)
2）再对每日的各商品订购「数量」进行降序排列。点击「商品」字段旁边的「![image.png](/core/style/lod.png)>降序>数量（求和）」，实现数量组内降序排列。如下图所示：
![](/core/style/lod.png)
3）添加仪表板，将组件拖拽到仪表板查看效果。如下图所示：
![](/core/style/lod.png)

#### 2.5.1 PC端
仪表板效果详情可参见本文 1.1 节。
#### 2.5.2 移动端
移动端展示效果详情，如下图所示：

## 3\. 分析数据实现步骤
注：数据集不支持移动端查看。  

### 3.1 添加数据
与 2.1 节相同。  

### 3.2 去除重复数据
添加「分组汇总」步骤，将「订购日期」、「商品」拖入分组栏，将「数量」拖入汇总栏，如下图所示：
![](/core/style/lod.png)
### 3.3 对日期字段进行升序排列
添加「排序」步骤，点击「添加排序列」，对「订购日期」进行升序排列，如下图所示：
![](/core/style/lod.png)
### 3.4 对商品按照数量降序排列
继续在当前步骤中点击「添加排序列」，汇对「数量」进行降序排列，如下图所示：  

![](/core/style/lod.png)
保存并更新数据。
### 3.5效果查看
点击「退出并预览」查看效果，如下图所示：  

![](/core/style/lod.png)
