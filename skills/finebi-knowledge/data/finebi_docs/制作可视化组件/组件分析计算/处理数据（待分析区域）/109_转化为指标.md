### 1.2 应用场景
若是需要得到一个文本/日期字段的去重计数值，可以使用「转化为指标」功能。
### 1.3 功能介绍
有两种情况：  

  * 直接将字段（日期和文本类型的字段）转化为指标，获得指标为该字段的去重计数值，详见本章 2.1 。
  * 通过 [转换为维度](<https://help.fanruan.com/finebi6.0/doc-view-114.html>) 获得的字段（数值字段），再将其转化为指标，可以将它恢复到原始的指标字段，详见本章 2.2 。


注：如果字段是计算字段，则转化后的指标字段不支持指标条件。
## 2\. 操作步骤
### 2.1 选择数据
新建分析主题并添加数据集：[门店销售数据统计.xlsx](<doc-download-/finebi6.X/uploads/file/20250326/门店销售数据统计 \(6\).xlsx> "下载资料")。详情请参见[5分钟上手FineBI](<https://help.fanruan.com/finebi6.X/doc-view-818.html>)。
2.2 获得去重计数  

将字段直接转化为指标字段，则可获取依赖该字段的去重计数。
1）在组件编辑界面，选择「店名」，点击「下拉 > 转化为指标」，如下图所示：
![1.jpg](/core/style/lod.png)
2）得到新指标字段「店名（去重计数）」，将「店风格」字段拖入维度栏，将「店名」字段拖入指标栏，可以看到不同风格有多少店铺，如下图所示：
![2.jpg](/core/style/lod.png)
### 2.3 从指标转化来的字段
通过 [转换为维度](<https://help.fanruan.com/finebi6.0/doc-view-114.html>) 获得的维度字段，再进行「转化为指标」，即可恢复到最初的指标字段，如下图所示：
![3.gif](/core/style/lod.png)
