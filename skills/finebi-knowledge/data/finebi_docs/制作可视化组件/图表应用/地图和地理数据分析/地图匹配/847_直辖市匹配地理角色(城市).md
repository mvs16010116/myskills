## 1\. 概述
### 1.1 问题描述
目前 BI 地图中的北京市、上海市、天津市、重庆市、台湾省、香港特别行政区、澳门特别行政区都是算作省份级别的。
用户制作地图时想把这些地区跟地级市放在一起，但是作为省份级别是无法跟地级市进行匹配的。如下图所示：
![](/core/style/lod.png)
那么如何才能让这些地区可以直接匹配地级市呢？本文将详细介绍。
![](/core/style/lod.png)
### 1.2 解决思路
存放地图 JSON 文件的路径：%FineBI_HOME%\webapps\webroot\WEB-INF\assets\map\geographic\world\中国\下，给这些地区再新增 JSON 文件，作为地级市。
## 2\. 方案一：下载 json 文件解决
### 2.1 json 文件下载
1）json 文件下载：[JSON文件包.rar](<doc-download-/finebi5.1/uploads/file/20211102/JSON文件包.rar> "下载资料")
2）将压缩包解压，把「JSON文件包」文件夹内的文件。
  * 单机版：将解压后的文件放到%FineBI_HOME%\webapps\webroot\WEB-INF\assets\map\geographic\world\中国下
  * 集群版：将解压后的文件放到集群文件服务器的 \WEB-INF\assets\map\geographic\world\中国 下


![20.png](/core/style/lod.png)
### 2.2 使 json 文件生效
管理员进入平台，点击「管理系统>地图配置>同步地理文件」即可。如下图所示：  

![](/core/style/lod.png)
## 3\. 方案二：自定义某个直辖市的 json 文件
以澳门特别行政区为例，其他地区同理操作即可。  

### 3.1 新建 JSON 文件
BI 安装目录%FineBI_HOME%\webapps\webroot\WEB-INF\assets\map\geographic\world\中国\下，新增 2 个空白的 JSON 文件，如下图所示：
![10.png](/core/style/lod.png)
### 3.2 编辑 JSON 文件
1）使用编辑器打开澳门-area.json和澳门-point.json，在这 2 个空白文件中都新增同一段代码，如下图所示：
![Snag_1a60a0d.png](/core/style/lod.png)
代码如下：
[code]
    {  
      "type": "FeatureCollection",  
      "features": []  
    }
[/code]
2）返回目录%FineBI_HOME%\webapps\webroot\WEB-INF\assets\map\geographic\world\，打开中国-area.json，将澳门特别行政区的 feature 结构选中拷贝到澳门-area.json的features: []数组内，保存文件。如下图所示：
![8.png](/core/style/lod.png)
3）返回目录%FineBI_HOME%\webapps\webroot\WEB-INF\assets\map\geographic\world\，打开中国-point.json，将澳门特别行政区的 feature 结构选中拷贝到澳门-point.json的features: []数组内，保存文件。如下图所示：
![9.png](/core/style/lod.png)
4）完成操作后，参考本文 2.2 节内容使 json 文件生效。
### 3.3 效果预览
#### 3.3.1 地图配置
进入 FineBI 决策平台，「管理系统>地图配置>地理信息>区域」下新增地级市级别的澳门。如下图所示：
![](/core/style/lod.png)
#### 3.3.2 匹配地理位置(城市)
1）使用内置数据「销售DEMO>地区数据分析」，在组件中，维度字段「城市」下拉选择「地理角色>城市」，如下图所示：
![12.png](/core/style/lod.png)
2）可以看到，城市字段中的澳门可以跟地级市级别的澳门特别行政区进行匹配。如下图所示：  

![](/core/style/lod.png)
