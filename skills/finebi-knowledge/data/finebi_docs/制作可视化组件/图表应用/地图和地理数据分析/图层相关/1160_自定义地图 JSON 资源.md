## 1\. 概述
### 1.1 应用场景
设置地图边界目前有 2 种方式：地理信息和自定义图片。  

其中地理信息就是实际的地理地图，而自定义图片的自由度就比较高了，可以将任意一张图片作为地图的边界。
FineBI 内置了一些地理信息和自定义图片的资源，用户可以直接拿来用，但是如果想自己自定义这 2 种资源，那么该如何做呢？
![Snag_19af71a8.png](/core/style/lod.png)
### 1.2 功能简介
  * 自定义地理信息的方法参见文档：[地理信息](<https://help.fanruan.com/finebi6.0/doc-view-375.html>)，生成的 JSON 文件保存到%FineBI_HOME%\webroot\WEB-INF\assets\map\geographic\world路径下。
  * 自定义图片的方法参见文档：[自定义图片作为地图边界](<https://help.fanruan.com/finebi6.0/doc-view-376.html>)，生成的 JSON 文件保存到%FineBI_HOME%\webapps\webroot\WEB-INF\assets\map\image路径下。


注：生成的 JSON 文件均可直接拷贝到其他工程中使用，拷贝后重启 BI 工程或者在平台点击地图配置界面的「[同步地理文件](<https://help.fanruan.com/finebi6.0/doc-view-375.html>)」按钮，即可生效。

## 4\. 注意事项
  * 当手动在工程目录中添加 JSON 文件时，若为地理信息下的文件，需要同时编写 XXX-area.json 和 XXX-point.json ，并将其放置在同一层目录下。若为自定义图片地图中的文件，只需编写 XXX.json 即可。
