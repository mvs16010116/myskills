##  1\. 概述
### 1.1 问题现象
用户在仪表板中使用了一些特殊字符后，出现功能无法使用或报错的现象。
### 1.2 原因分析
仪表板部分特殊字符影响功能使用。  

## 2\. 不支持的字符
特殊字符| 影响范围| 详细描述  
---|---|---  
}和${| 计算指标、跳转| 在以下情况下不支持：  
计算指标使用包含该特殊字符的字段；URL 跳转手动输入特殊字符；跳转字段包含特殊字符  
< / > ' " （）| 标题和文本组件| 这些特殊字符会影响 html 解析。标题或者文本组件中包含特殊字符会展示异常，无法正常插入或提示字段被删除等  
` (键盘1左侧)| 原始的字段名和表名  
| 直连状态下：数据准备界面提示预览失败，仪表板报错抽取状态下：正常
