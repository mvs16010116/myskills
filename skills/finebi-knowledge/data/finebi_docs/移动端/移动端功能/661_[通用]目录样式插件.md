## 1\. 概述
在移动端查看模板时，我们可以通过使用插件来改变目录的结构样式。
### 1.1 版本
FineBI版本| APP 版本| HTML5 移动端展现插件| 插件名称| 插件版本| 预览方式  
---|---|---|---|---|---  
6.0| V11.0.68| V11.0.68| 分类导航目录树| V11.0.64| AppHTML5  
卡片式目录  
折叠式目录  
Tab标签目录  
注：上述插件不兼容老版本。在使用前请更新相应的 App 和 HTML5 移动端展现插件版本。
### 1.2 插件下载
与目录结构相关的插件有以下 4 个，点击即可下载：
  * [分类导航目录树插件](<https://market.fanruan.com/plugin/a70ed7e2-7d9e-43d2-8d4d-245dcb52b0b9>)  

  * [Tab 标签目录插件](<https://market.fanruan.com/plugin/7253de41-4141-4560-b163-0fb94d6c705b>)
  * [折叠式目录插件](<https://market.fanruan.com/plugin/4ceea309-9463-4173-ad8e-1da0b5090b2b>)
  * [卡片式目录插件](<https://market.fanruan.com/plugin/00725140-d2c1-4784-9ea7-384d799d8498>)


安装插件方法参照 [插件管理](<https://help.fanruan.com/finebi6.0/doc-view-459.html> "插件管理") 。
### 1.3 功能简介
插件下载安装后，进入 FineBI 系统，点击「管理系统>移动平台>目录」，在「目录结构」右侧会新增所安装的目录结构，可在平台切换目录样式。
下图为安装四个插件后的目录结构图：
![目录结构.png](/core/style/lod.png)
