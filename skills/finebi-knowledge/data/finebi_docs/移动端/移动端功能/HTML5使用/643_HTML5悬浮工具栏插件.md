### 1.2 应用场景
FineBI 提供了移动端 HTML5 访问 BI 的功能，方便使用手机来查看 BI 应用。
但当集成到微信、钉钉等 App 中查看 BI 应用或者使用移动端浏览器查看 BI 应用时，本身APP或者浏览器中就有工具栏，而 HTML5 页面也有底部工具栏，这就导致 BI 分析界面展示效果欠佳。
那么使用该悬浮工具栏插件可实现优化移动端 HTML5 页面查看 BI 应用的展示效果，使得界面更加清晰、分析更方便快速。
### 1.3 功能简介
1）安装 HTML5 悬浮工具栏插件可将 HTML5 页面底部的工具栏位置更改到页面右侧。
2）该插件在当前工具栏按钮大于 4 个时自动收起，可通过点击展开工具栏，使得页面更加清晰。
注：该插件仅支持移动端 HTML5 ，不支持移动端 App 。

### 2.2 使用示例
1）以移动端浏览器直接打开 FineBI 数据决策系统为例。
在安装 HTML5 悬浮工具栏插件之后，使用 HTML5 主页链接，格式为：http://ip:端口号/webroot/decision/url/mobile#/login，详情可参见：[HTML5端访问FineBI](<https://help.fanruan.com/finebi6.0/doc-view-452.html>) 。
移动端浏览器输入链接，跳转 HTML5 登录界面，输入用户名和密码登录数据决策系统。如下图所示:
![1234.png](/core/style/lod.png)
2）打开任意一张模板，可查看工具栏状况，安装插件前后的对比图如下所示：
![anzhuanagqian.png](/core/style/lod.png)
![anzhuanghou.png](/core/style/lod.png)
3）当工具栏按钮超过四个时，默认工具栏为收起状态，如下图所示：
![shouqia.png](/core/style/lod.png)
4）可点击收起按钮，手动展开工具栏，如下图所示：
