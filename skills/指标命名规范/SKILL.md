# 指标命名规范

## 核心原则

1. **可读性优先**：见名知意，避免缩写和拼音
2. **唯一性原则**：全局唯一，一处定义
3. **稳定性原则**：发布后禁止随意修改

## 四段式命名结构

```
[业务域/主题域] + [修饰词] + [核心指标词] + [时间周期/聚合方式]
```

| 部分 | 说明 | 必填 | 示例 |
|------|------|------|------|
| 业务域/主题域 | 指标所属业务板块 | 建议必填 | 销售、用户、库存、财务、广告 |
| 修饰词 | 限定说明（维度、口径、状态） | 可选 | 新增、净、累计、同比、环比、日均 |
| 核心指标词 | 指标的业务本质 | 必填 | 销售额、订单量、用户数、转化率 |
| 时间周期/聚合方式 | 统计周期或计算方式 | 建议必填 | 日、周、月、年、累计、均值 |

**示例**：`销售额_月`、`新增注册用户数_日`、`库存周转天数_月`

## 修饰词规范

| 类型 | 规范用词 |
|------|---------|
| 时间修饰 | 累计、新增、历史、同比、环比、日均、周均、MTD、QTD、YTD |
| 状态修饰 | 有效、无效、已支付、已退款、已发货、活跃、流失 |
| 计算修饰 | 净（扣除退款）、总（全量）、均（平均值）、占比、人均、笔均 |
| 渠道修饰 | 线上、线下、ToB、ToC、自营、第三方 |

## 比率/占比类命名

| 类型 | 命名模式 | 示例 |
|------|---------|------|
| 率（≤1，体现效率） | `XX率` | 转化率、毛利率、退货率 |
| 占比（部分/整体） | `XX占比` | 新增用户占比、ToB渠道销量占比 |
| 比（任意比值，可>1） | `XX比` | 广告花费比(ROI)、产销比 |

> 比率指标必须注明分子分母。

## 原子/派生/复合指标

| 类型 | 定义 | 命名特征 | 示例 |
|------|------|---------|------|
| **原子指标** | 不可拆分的基础度量 | 简洁，直接表达度量对象 | `销售金额`、`订单数量` |
| **派生指标** | 原子指标+修饰/时间限定 | 原子指标名+修饰/时间后缀 | `销售额_月_同比`、`订单量_月均` |
| **复合指标** | 指标间四则运算结果 | 体现计算关系，常见率/比/占比 | `毛利率`、`客单价`、`广告ROI` |

## 维度命名规范

| 规范 | 正确示例 | 错误示例 |
|------|---------|---------|
| 时间维度统一用词 | 日期、年月、季度、财年 | 时间、dt、day |
| 地域维度统一用词 | 省份、城市、区县、大区 | area、省 |
| 状态类维度明确枚举值 | 订单状态（待付款/已付款/已发货） | status、flag |
| 不加"维度"二字后缀 | 日期、省份、商品类目 | 时间维度、地区维度 |

## 命名反模式（禁止项）

| 反模式 | 反例 | 正确做法 |
|--------|------|---------|
| 拼音/拼音首字母 | `xse`、`khdj` | 使用标准中文名称 |
| 中英文混用 | `支付order量`、`user新增数` | 统一中文 |
| 指标名绑维度值 | `华东区销售额`（应拆成维度筛选） | `销售额` + 维度筛选 |
| 以报表/页面命名 | `首页销售额` | 按业务含义统一命名 |
| 版本号后缀 | `销售额_v2`、`销售额_new` | 走变更流程，旧版标记废弃 |
| 以人名命名 | `张三的销售额` | 按业务含义命名 |
| 临时口径不清理 | `618活动销售额_2024` | 活动结束归档清理 |
| 词序混乱 | 同类型指标风格不统一 | 统一：[业务域]+[修饰词]+[核心词]+[周期] |
| 额/率不区分 | `毛利`（是额还是率？） | 明确：`毛利额` 或 `毛利率` |

## 全生命周期管理

| 阶段 | 操作 | 关键规则 |
|------|------|---------|
| 创建 | 按规范新建指标，填写完整元数据 | 严禁临时命名 |
| 评审 | 审核命名合规性、唯一性、口径 | 避开了反模式检查 |
| 发布 | 发布到公共目录，锁定名称 | 发布即锁定，禁止随意修改 |
| 使用 | 监控使用频率，收集反馈 | 高频标记，低频待清理 |
| 变更 | 填写变更原因，通知所有使用者 | 保留历史版本记录 |
| 废弃 | 标记「已废弃」，说明替代指标 | 废弃不删除，保证历史报表正常运行 |

## 对比工具

当需要评估现有指标命名时，按照以下步骤检查：

1. 是否符合四段式结构？
2. 核心词是否准确反映业务含义？
3. 是否有冗余词（如"库存"重复：`采购_在库库存数量` → `采购_在库数量`）？
4. 是否有中英文混用或拼音？
5. 修饰词顺序是否统一？
6. 废弃指标是否已标记？
